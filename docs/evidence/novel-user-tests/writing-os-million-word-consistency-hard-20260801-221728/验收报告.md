# Writing OS 百万字人物一致性加固验收报告

## 最终裁决

**VERIFIED_WITH_BOUNDED_GUARANTEE**

现在的软件已经能让不熟悉项目的 AI 按机械流程安全参与长篇写作，并在约 101 万字符、500 个目标章的真实顺序循环中持续维护正文身份、时态正典、人物状态、知情边界、required cast、写者租约、状态裁决和旧章 retcon 恢复。它能对 AI 写长篇产生显著帮助，也足以作为百万字任务的“写章 OS”。

但“保证人物绝对一致、文学质量永不崩”仍不能成立。软件能保证的是可计算边界和失败关闭；人物魅力、心理真实、对白质感、节奏与文风仍须独立模型和人工审稿。本轮没有调用外部写作模型，也没有把机械 PASS 冒充文学审读。

## 百万字顺序验收

本轮不是一次性伪造 499 个 completion，而是对 500 个目标章逐章执行：

`formal prepare + lease → CAS save → evidence-bound state candidate → human owner accept`

决定性结果：

- 500/500 原始写章循环完成；受管工程共 501 章（含 bootstrap），正文 1,014,334 字符。
- 在第 200 章制造 retcon 后，严格顺序重建 200–500，共 301 章；rebuild 清空并恢复到第 500 章。
- 在第 250 章和重建第 350 章使用新 JSON CLI 进程恢复，退出码均为 0。
- 双 writer、空 delta、未知实体、错 cast、Agent 自批、重建越序六类故障全部按预期失败关闭。
- 抽样 cutoff oracle 全部一致，未来秘密未进入 Context Pack。
- 最终保存 801 个不可变候选、801 个不可变裁决、501 个 completion；租约清理后仅余 1 条记录。
- 规模夹具源文件前后 SHA 完全相同。

性能边界如实保留：首次顺序循环 p50 4.80 秒/章、p95 8.16 秒/章、最大 9.59 秒/章，峰值 RSS 589,037,568 bytes（约 562 MiB）。这不阻断实际逐章生产，但当前不应宣传为“瞬时批量生成 500 章”；累计 state/CAS 是后续 P1 性能项。

## 陌生 AI 的唯一推荐流程

完整提示词与失败处理见 [08-writing-os-v2-unfamiliar-ai-quickstart.md](../../../novel-mode/08-writing-os-v2-unfamiliar-ai-quickstart.md)。主路径固定为：

1. `doctor_novel_agent`：只读诊断，不自行绕过 blocker。
2. `prepare_novel_chapter_write`：获取 Context Pack 2.0、preflight 与唯一 write lease。
3. `execute_command:novel_save_chapter`：携带 lease token、fence、revision、SHA 和 pack fingerprint 做 CAS 保存。
4. `probe_novel_chapter_consistency`：machine conflict 必须修；review required 交审稿员，不自动改正典。
5. Agent 只 stage 状态候选；human owner 接受或拒绝后才算完章。
6. 再次 doctor 下一章；存在 rebuild queue 时只能处理精确 nextChapter。

## 尚未完成但不构成本轮软件阻断

- 《黑页》正式生产数据尚未锁版：需把 baseline 从 provisional 升为 locked，为后续章补 chapter brief/required cast，并给实际出场角色补齐结构化 profile 和动态状态。
- 未做真实 Grok/Kimi/DeepSeek 等外部模型的 20–50 章文学 A/B；本轮验证的是它们可安全调用的协议、门禁、恢复和证据链。
- 未做真人文学质量验收；`LITERARY_QUALITY=NOT_REVIEWED`。
- retcon 当前是单 active 线性 rebuild queue，不是任意分支合并或完整事件溯源 DAG。

## 回滚与兼容边界

- 旧 V1 状态保持只读兼容；缺少可信 history base 的旧工程不会被猜测性 rewind，而是返回 `state_rebuild_history_gap`。
- 候选、裁决与 rebuild before snapshot 均为追加式证据；回滚源码不要求删除这些工件。
- immutable MCP 候选没有覆盖安装版；current 启动器只选择与当前源码完全匹配的候选，源码回退时仍会失败关闭或选中对应旧候选。
- 本轮未 stage、commit、push、创建 PR、部署、发布、调用付费模型或修改正式小说源。
