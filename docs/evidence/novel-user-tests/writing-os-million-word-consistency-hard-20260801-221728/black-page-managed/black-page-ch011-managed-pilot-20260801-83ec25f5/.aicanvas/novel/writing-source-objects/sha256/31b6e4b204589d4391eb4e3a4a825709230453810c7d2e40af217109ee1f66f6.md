# 易航

## 基础
- 姓名：易航
- 性别/年龄感：男 · 23–25
- 身份职业：市三院第三方派驻护工 → 清算中心编外/外勤 → 记账的人
- 所属势力：个人 → 清算中心（紧箍）→ 港湾
- 首次出场：卷一第001章

## 外形记忆点
1. 洗旧卫衣/护工外套，指尖常有消毒液味
2. 说话慢，带「您」；急也不怎么抬高音
3. 叠缴费单边角；收账前问「您再想想。」

## 性格
- 核心：怂着忍、内里算账；求活与救母优先
- 口癖：您再想想。；少骂人
- 绝不会：无代价卖队友；当众称王；主动造假契

## 动机
- 要：救易秀；搞清黑页；拒绝被善意收割
- 怕：母死；自己变成收割者；捷径成瘾失控
- 底线：页不能假洗白；证据不毁

## 能力/资源/把柄
- 看价/认债/过手/烧应收；黑页明细涂黑；到期字段（如-7天）
- 资源：阿大、肖龙、后邓依/檀溪
- 把柄：从业契；黑页本身；母担保链
