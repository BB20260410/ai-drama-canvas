# 阿大

## 基础
- 姓名：阿大（本名可后补；正文默认「阿大」）
- 性别/年龄感：男 · 约 45–52，中年
- 身份职业：市三院门口看车/跑腿；**前地下账贩**；腿有旧伤
- 所属势力：无编制；医院门口灰色烟火区；与清算中心、灰市均有旧隙不入伙
- 首次出场卷/章：卷一 · 约第 003–004 章（医院后门抽烟；教「别硬」）

## 外形记忆点（3条内，正文少堆）
- 腿脚不利索，靠墙才稳；旧伤天阴发作
- 旱烟味，口袋常备散烟；递烟当「过手费」
- 说话损人，眼神先看人腕/手背再看脸

## 性格
- 核心：损人护人；信规矩不信情分；用刻薄挡住真心
- 口癖/习惯动作：
  - 「免费的都标过价」
  - 「账是刀，算错先砍自己」
  - 递烟、敲烟盒边、看完人腕才开口
- 绝不会做的事：
  - 不收「干儿子」、不收徒弟跪礼
  - 不为情分白算账
  - 不主动进清算中心大门当刀

## 动机
- 要什么：把自己当年没算清的教训传给「下一个蠢到要沾手的人」；换口烟、换个不被清算系统点名的晚年
- 怕什么：再信一次「情分能顶账」；怕易航走成当年的自己（腿伤 + 被卖）
- 底线：关键时刻可替易航挡一刀（身价/寿元/名价），但事后仍要「过手费」——香烟与方便面，不许感动式白嫖

## 能力/资源/把柄
- **资源**：半套街头账经（认债、证据、过手边界）；医院门口人脉（保安/护工/车贩消息）；对清算中心「人来过」的嗅觉
- **能力边界**：无金手指；不能见债纹；全靠经验与旧伤记忆
- **把柄**：当年账贩旧账未清；曾因信情分被坑；腿伤可能与某次「算错」或挡刀有关（卷一不揭底，旧伤线可挂 F14）
- **对应旧功能**：方案「瘸三」位

## 与易航
- 关系类型：街头导师 + **镜像结局**（易航若学坏/学软，就是阿大）
- 关键债务/人情：
  - 易航给过手费（烟、面、跑腿钱），阿大给规矩与挡刀
  - 不欠「父子债」；只欠「过了手的账」
- 对手戏功能：
  - 卷一：教证据、劝别硬、挡刀疤；递「中心的人来过」
  - 中期：劝退从业契/脏单；拒绝一次性说透旧事
  - 卷六：可替易航挡致命一击（师徒高潮）
  - 母线：可证半句「你妈曾逃出过某条线」（卷三挂）

## 弧光（S1）
- **起点**：别沾清算；你腕上那数在跳，退还来得及  
- **中点**：你既然沾了，就别学我当年信情分；教半套规矩，藏半套旧伤  
- **终点/挂线**：挡刀后残或不残均可；仍不进编制；可活成「港湾门口的老人」——记账的人不称王，看门的也不称师

## 知情范围（开场）
- 知：
  - 账是刀；免费好事必有价
  - 清算中心半官方、账不一定给人看
  - 易航腕上有「在跳的数」（凭经验感觉，非见纹）
  - 春禾/催收类套路的皮面
- 不知：
  - 易航金手指完整规则与四价结算细则
  - 易秀担保伪签/陈宏远扩债全貌（卷八前）
  - 郭周堂废签动机的完整版
- 误信：
  - 曾误信「情分能顶账」（旧伤根源）
  - 可能误以为易航只是「护工急疯」，低估其算法

## 禁写
- 阴司/阴差人设；「地下账贩」= 活人灰市旧业，不是鬼差
- 突然开挂见债纹
- 鸡汤导师长篇说教；每句教训最好挂烟/旧伤/当场账
- 收干儿子、泪奔拜师戏
- 无代价挡刀（挡了就要见血/见伤/见名）

## 短剧名场面（2）
1. **后门递烟**：「免费的都标过价」；看一眼易航腕——「你这数……在跳。」  
2. **挡管钳**：刀疤砸来，阿大前臂/旧伤位见血，缴费单上滴红；事后仍伸手要烟——「过手费。」
