# 梁景衡

## 基础
- 姓名：**梁景衡**（正典；原方案名「李易峰」已废，**禁止写回**）
- 性别/年龄感：男 · 约 32–38，镜头年龄感偏年轻、会保养
- 身份职业：**春禾互助基金**公关总监 / 对外「慈善明星脸」；康济系对外发言人
- 所属势力：春禾/康济系门面 → 真后台 **陈宏远**；与 **信汇资产**有关联交易话术链
- 首次出场卷/章：卷一 · 黄金三章**只闻名**（「**梁总**会来谈」话术；**本人不出场**）→ **029+** 救助确认书主戏 / 约 ≥028 可出影 → 卷三–五门面反派

## 外形记忆点（3条内，正文少堆）
- 爱出镜：西装或基金工装干净得像广告；袖口永远齐
- 会说话：笑时露整齐牙，镜头灯一亮声线自动软半度
- 习惯动作：讲话时食指轻点桌面/合同角，像在给「善意」打拍子

## 性格
- 核心：人模人样、台词漂亮；**最恨被当众拆穿**；镜头前做好人，镜头后导流催收与担保
- 口癖/习惯动作：「我们先把人救起来再说。」/「善意也要有闭环。」/ 拍肩、递名片、对镜头说「困难群众」
- 绝不会做的事：在直播/公开场合亲口认「恩债农场」；主动对陈宏远叫板；把真后台暴露给媒体

## 动机
- **要什么**：门面稳、KPI（救助曝光量/签约数）、社会名声；被上头（陈宏远）看见「能压得住场」；最终仍想往上坐半格，不当永远的脸
- **怕什么**：直播翻车；名表/合同夹层/录音小字被当众念出；被邓依程序钉死；被檀溪内鬼翻出总账；被陈宏远弃用后变成下一个「李强」
- **底线**：可以脏、可以弃子、可以假救助——**不能**在镜头前变成「恶人脸」。脸没了，他整个人设归零

## 与易航
- 关系类型：假救助 → 对立 → 门面战（名价主战场）；中期 clearest 反派脸
- 关键债务/人情：卷一用「无偿援助」试探易航/易秀线；合同夹层与担保导流；可间接碰易秀账（第三方收账影子）
- 对手戏功能：
  1. 把「善意」做成易航最过敏的诱饵（对位金手指算法第 5 条：有没有免费的好事？）
  2. 逼易航在**名价**与**证据**上成长（邓依程序 × 檀溪内鬼 × 易航看价）
  3. 倒后让位给陈宏远，证明「门面≠真债主」

## 弧光（S1）
- **起点（卷1）**：海报脸/视频脸；递救助、约签字；尚未亲自下场
- **中点（卷3–5）**：直播战、助学套/恩债农场公关；追杀檀溪；名表与老人债被易航/邓依/檀溪当众拆穿（F25）
- **终点/挂线（卷5后）**：门面崩或半崩；被陈宏远切割或降用；可残喘为「已翻车的前公关」侧影，**禁止**洗白成改邪归正导师

## 知情范围（开场）
- **知**：春禾对外话术与夹层合同怎么签；信汇可当「合法手臂」；名单如何导流；陈宏远要什么 KPI；檀溪一度是「自己人」
- **不知**（或假装不知）：易航黑页的真正含义；易秀担保的深层（卷8级）；债纹四价底层改律；陈宏远全部底牌
- **误信**：镜头与通稿能永远盖住小字；易航只是好拿捏的护工家属；弃几个李强级棋子无成本
