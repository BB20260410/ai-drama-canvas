# 刀疤

## 基础
- 姓名：刀疤（街头外号；正典正文默认「刀疤」。户籍名可后补，不抢戏）
- 性别/年龄感：男 · 约 28–35（比李强更「动手的人」）
- 身份职业：**信汇资产**催收组打手 / 外勤「协助执行」；无编制，吃风险金与私单
- 所属势力：**信汇资产**（执行末梢）← 春禾外包指令可越级（卷一 025 任务语音）；上游可被弃
- 首次出场卷/章：**卷一 · 黄金三章**（002 级堵门侧翼）→ 021–027 暴力线主戏；中后期可回收为灰爪牙/证人

## 外形记忆点（3条内，正文少堆）
- 眉骨或颧骨一道旧疤（外号来源）；说话时疤会扯动
- 常携**管钳**/短棍式工具，不先拔刀——像修管道的人误入病房后巷
- 皮鞋底粘红漆/灰（015 红漆线可蹭边，勿抢李强主戏）

## 性格
- 核心：**暴力实用主义**——信「账是要拿身体记的」；怕文斗、怕录像、怕自己变成弃子
- 口癖/习惯动作：「签字比喊疼快」；动手前先吐一口痰或甩腕；被反杀时先骂李强不是先骂债
- 绝不会做的事：在直播镜头前主动当门面；为梁景衡的漂亮话卖命到底；无报酬替信汇背整条链

## 动机
- 要什么：**活着拿钱**；不被写成「个人违规」唯一背锅人；中期可要一份「不被再过手」的喘息
- 怕什么：上游追责落到自己账户；债纹/过手让暴力成本回流；牢狱与被灭口同等恐惧
- 底线：可打可跪可交账户；**不主动当人肉炸弹替陈宏远挡终局**（层级不够也轮不到）

## 能力/资源/把柄
- 能力：院外堵门、后门伏击、冷库/废墟限制级场面的**肉体压迫**；不懂合同深层，懂「人在哪、监控死角在哪」
- 资源：信汇排班、外包电话、私收款账户、管钳与临时工同伙
- 把柄：
  - 收款记录 / 未发出的**任务语音**（发件方＝**外包号**，有暗语、**无春禾抬头**——卷一只见末梢；升级春禾链靠后期补链）——易航 026 认债过手关键物证
  - 现场监控与阿大挡刀血证
  - 可被过手：暴力与私收的结算压力显回其责任节点

## 与易航
- 关系类型：卷一**暴力敌** → 可降为**可反水的灰爪牙 / 恐惧证人**
- 关键债务/人情：
  - 对易航：无恩；有伤（阿大前臂等）
  - 反水条件：上游要弃他 + 易航能把账钉死在他身上/或给他「交账户换活命」的出路（026 原型）
- 对手戏功能：
  - 短剧血点：医院后门管钳、冷库蒙棍、吊钩刮腕等（黑暗清单，Grok 可写限制级）
  - 智斗配合：文斗救不了李强后他转向灭证，反而掉落语音，成春禾链的钉子
  - **可反水**：交出收款账户、指认外包端、中期给易航递刀；禁止无代价铁杆忠犬

## 弧光（S1）
- **起点**：李强手下的「管钳」；黄金三章堵门侧翼
- **中点（021–027）**：反咬期暴力补刀 → 伏击失败 → 被过手逼退 → 李强失联后他成为可交易的弃子
- **终点/挂线**：卷 2–3 可再出场递刀/灭证边缘；卷 3 护檀溪逃时「刀疤级」暴力可复用功能位；**不当卷 5+ 主 BOSS**；反水后仍可脏、可叛、可再卖

## 知情范围（开场）
- 知：李强私收套路；哪几条巷子好动手；春禾有时直接派活（不完全明白壳层）
- 不知：陈宏远是谁；清算中心与基金的收益闭环全貌；易航黑页真相
- 误信：只要打服家属、砸掉证据，文斗那套就碰不到自己

## 禁写
- 禁止写成无敌杀手或江湖盟主；他是**催收末梢打手**
- 禁止阴司/鬼差/超自然主动能力（可被债纹反噬，自己不施法）
- 禁止医院病区内持械行医式作恶；堵门在接待区/后门/院外（P0 §5）
- 禁止无铺垫突然心善；反水必须绑「弃子恐惧 + 账压到自己」
- 禁止抢李强「黄金三章话术脸」与梁景衡「镜头脸」的功能

## 短剧名场面（2）
1. **后门管钳**（约 025）：管钳砸向易航，阿大**现实重伤**挡下前臂；血滴在缴费单上；掉落外包任务语音（**无春禾抬头**）。
2. **过手逼退**（约 026）：易航用监控+语音元数据+收款记录认债过手；刀疤当场感到上游追责将落到自己——交账户、松手、骂着退去（反水伏笔落子）。
