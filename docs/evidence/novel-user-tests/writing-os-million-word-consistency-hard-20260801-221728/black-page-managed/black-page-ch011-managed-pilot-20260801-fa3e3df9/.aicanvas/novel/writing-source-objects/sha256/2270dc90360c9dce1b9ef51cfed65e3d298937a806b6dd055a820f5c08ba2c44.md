# 角色卡分级与动态协议（正典 · 2026-08-01）

> 长篇双轨：**基础角色卡**（固定人设，目录 `单卡/` / 总表）+ **动态角色卡**（每章末更新，`追踪/角色状态.md`）。  
> 派笔/多模验收/Opus 终润写前必读本文件 + 当章动态状态。

---

## 0. 双轨分工

| 轨 | 存什么 | 何时改 | 路径 |
|----|--------|--------|------|
| **基础卡** | 身份、性格、欲望/恐惧、秘密、声口、行为模式、弧线、信息边界、一致性规则 | 人设裁决时；禁止每章改性格 | `设定/人物/单卡/` + `00_角色总表.md` |
| **动态卡** | 身体/情绪/已知未知/关系进度/新增目标/心理变化/未解决矛盾 | **每章写完勾账时** | `追踪/角色状态.md`（按「第 N 章结束后」） |

- 冲突时：**基础卡 > 动态卡的「性格推断」**；动态卡的「已知/未知」优先于细纲旧句。  
- 动态卡**不得**偷改 P0 数字、人名、日历 `-N`、四价规则。

## 1. 四级深度

### L1 核心角色 · 完整角色卡

**适用**：主角、核心反派、重要感情对象、贯穿主线配角、明显成长线人物。  
**字段**（见 `单卡/_模板_L1完整.md`）：身份、外貌识别、性格、欲望、恐惧、秘密、关系、语言习惯、行为模式、成长弧线、信息边界、一致性规则/禁写。  
**本书默认 L1**：易航、易秀、邓依、檀溪、梁景衡、陈宏远、郭周堂、阿大、李飞。

### L2 重要配角 · 中型角色卡

**适用**：朋友/同事/亲人；单卷重要人物；常出场但不扛主成长；有独立目的。  
**字段**（`_模板_L2中型.md`）：姓名、身份、剧情作用、外貌识别点、核心性格、当前目标、与主角关系、隐藏立场/秘密、说话特点、行为底线、不能知道的信息、最终去向。  
**本书默认 L2**：肖龙、李强、刀疤、崔七、石头、顾棠、赵姐、吴姐（可升级）。

### L3 功能型 · 迷你角色卡

**适用**：客栈式一次性信息源、证人、小反派、店员/门卫/司机等。  
**字段**（`_模板_L3迷你.md`）：称呼、身份、本场功能、识别特征、性格特征、说话方式、对主角态度、知道什么、不知道什么。  
**本书默认 L3**：缴费处刘姐、周主管、外包窗小陈、保安老马、何叔、肾内主治侧写、何助理（梁侧）、镜头组临时工 等。

### L4 路人/群众 · 标签即可

一句话场景标签；**禁止**家庭背景、童年创伤、完整弧线、十余条关系。  
**模板**见 `_模板_L4临时.md`（需控戏时用「临时角色」块）。

## 2. 路人升级条件（任一即升 L3+）

- 后面还会再出现  
- 掌握关键证据  
- 决定会改变剧情  
- 与主角建立持续关系  
- 有独立利益/立场  
- 需要读者记住  
- 未来揭示真实身份  
- 死亡/背叛/选择产生明显影响  

**三问快速判级**

1. **会否再出场？** 否→L4；可能→L3；常出场→L2/L1  
2. **有无自己的选择？**（说不说真话/帮不帮/叛不叛/收不收钱）有→至少 L3  
3. **删掉剧情变不变？** 不变→L4；缺信息→L3；改方向→L2；主线崩→L1

## 3. 推荐配置（S1 量级）

| 级别 | 大致数量 | 深度 |
|------|----------|------|
| L1 核心 | 2–9（本书略扩因双女+导师+体制） | 完整卡 |
| L2 重要配角 | 5–15 | 中型卡 |
| L3 功能 | 按卷需要 | 迷你卡 |
| L4 路人 | 不限 | 标签 / 不入总表 |

**红线**：不要让十几个角色同时拥有同等复杂人设 → AI 会混淆称呼与关系。

## 4. 动态角色卡模板（章末）

对 **当章出场的 L1/L2** 必填；L3 仅当信息边界变化时补一行。

```markdown
### 【第N章结束后 · {姓名}】

- **身体状态**：
- **情绪状态**：
- **已知信息**：
- **未知信息**：
- **关系进度**：
- **新增目标**：
- **心理变化**：
- **未解决矛盾**：
```

**勾账时机**：`设定/文风/每章多模产线.md` 步骤 ⑥ —— 与台账、STATUS 同批更新。  
**只保留**：最新章全量动态卡 + 上一章差分（或滚动保留近 5 章）；全文备份可放 `追踪/角色状态_归档/`。

## 6. 禁写（角色卡层）

- 路人写完整童年/深层创伤抢戏  
- 动态卡提前解锁卷 8 母线真相等 **禁揭** 项  
- 用动态卡改基础性格（如把邓依改成恋爱脑）  
- 把 L4 反复写成有姓名有弧光的假核心
