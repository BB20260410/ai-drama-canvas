# 李强

## 基础
- 姓名：**李强**
- 性别/年龄感：男 · 约 35–45，嗓门比年龄先老
- 身份职业：**信汇资产**催收组长；合法外衣讨债头目
- 所属势力：信汇资产催收条线；手下可带 **刀疤**；话术与导流可挂 **春禾/梁景衡** 链；怂真正的上司与后台
- 首次出场卷/章：**卷一 · 黄金三章**（堵门/封科室/对峙主敌）→ 卷一中后被上头切割 → 中期可回收「递刀换活命」

## 外形记忆点（3条内，正文少堆）
- 嗓门大、爱拍桌；进门先用体积占走廊
- 催收马甲/夹克，文件夹拍门框当鼓点
- 怂的时候笑得比凶的时候难看——电话一接上司，音量自动降两档

## 性格
- 核心：**嗓门大、爱拍桌、怂上司**；对下威、对上软；合法话术挂嘴边，私收藏袖子里
- 口癖/习惯动作：「别逼我走程序！」/「这是债权转让，懂不懂？」/ 砸暖壶、拍桌、用文件夹扇风；败时「上面叫我」
- 绝不会做的事：主动扛锅替真债主出镜；在证据链闭合后还硬刚（会逃/会卖）；对梁景衡/信汇高层叫板

## 动机
- **要什么**：收债 KPI、私收外块、在组里说了算；不被信汇开掉；必要时换条命——中期可把刀递向易航换活命
- **怕什么**：被过手反杀把私收引到自己脸上；被信汇切割后当弃子；刀疤反水；梁景衡/春禾把他当「脏手样本」甩出去；牢狱与行业封杀
- **底线**：可以砸门、可以吓病人家属——**尽量**不在医院核心区真出人命（医院不作恶边界）；真被钉死就跪、就卖线索

## 能力/资源/把柄
| 类型 | 内容 |
|------|------|
| 资源 | 信汇债权材料、合法催收身份、刀疤等打手、与春禾导流接口（可不知全貌） |
| 能力 | 堵门、话术施压、围观叙事（把债务人说成老赖）；卷一暴力戏发动机 |
| 把柄 | **私收**黑纹（易航看价主打点）；尾号/转账痕迹；与春禾关联可被拼图；被切割后的怨气（回收燃料） |
| 下属 | **刀疤**（可转易航灰爪牙） |

## 与易航
- 关系类型：卷一主对立面（催收脸）→ 小胜后被切割的残敌 → 中期可选「递刀」工具人
- 关键债务/人情：堵易秀相关账/医药债外围；病房与科室门口施压；被易航**过手**引私收；名价反噬（易航被说成串通黑钱时，李强是推手之一）
- 对手戏功能：
  1. 黄金三章「合法讨债」压迫感；逼出易航看价/过手第一次真用
  2. 演示四价与证据：私收被引到该承担者链上
  3. 用完可扔：信汇切割 → 证明门面（梁景衡）与真手臂都可弃卒；中期递刀回收人情账

## 弧光（S1）
- **起点（卷1 初）**：堵门、刀疤、拍桌；春禾职员侧写「**梁总**明日来」把他垫在梁景衡影前
- **中点（卷1 中后）**：过手反杀、合同/转账露馅、刀疤动手、阿大挡；李强被上头叫走骂废物 → 信汇切割
- **终点/挂线**：降为残党（卷2 可再刷一次）；或中期出场给易航递刀/线索换活命；**禁止**无铺垫黑化成终局Boss（终局门面是梁景衡，真债主是陈宏远）

## 知情范围（开场）
- **知**：手里这单债权怎么催、私收怎么藏、刀疤听谁的、信汇要回款数字；春禾有时会「配合救助」话术
- **不知**：债纹底层；易航黑页；梁景衡/陈宏远的完整恩债结构；自己只是弃子
- **误信**：嗓门和合法外衣够用；易航只是护工好吓；私收永远查不到自己头上

## 禁写
- 禁止写成智商为零的纯嘴炮——要会合法话术，脏在私收
- 禁止医院核心区无意义屠杀；遵守「医院不作恶」边界
- 禁止与李飞功能合并（李飞=同期刃/编制竞争，李强=信汇催收）
- 禁止长期霸屏；黄金三章用尽后必须降频，回收需有「换命」代价
- 禁止阴司；禁止无故升华成悲剧英雄（递刀可以，洗白成义士不行）

## 短剧名场面（2）

### 1. 科室门口堵门（卷一 · 黄金三章）
- **场面**：李强+刀疤在**接待区/院外**；合法催收话术 + 拍桌；易航看私收红黑纹；春禾职员**口头转介**（无完整确认书）
- **钩**：「**梁总**最迟会来谈」（本人不来；真影≥028）；易航第一次把催收当「可过手」的活靶
- **短剧 comm**：文件夹砸门框；暖壶碎（可选）；易航低声「您再想想」对嗓门

### 2. 过手反杀 · 私收上脸（卷一中后）
- **场面**：合同/转账/围观；易航过手成功，把私收引向该承担链；刀疤动手、阿大挡；李强露馅后被上头电话骂废物带走
- **钩**：信汇切割预告；易航付名价（被说成串通）；小反派闭环，门面梁景衡接手
- **短剧 comm**：李强拍桌的手僵在半空；手机屏幕「上来」两字比刀疤更吓人
