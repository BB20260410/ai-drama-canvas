# 李飞

## 基础
- 姓名：**李飞**
- 性别/年龄感：男 · 约 24–27，与易航同龄段
- 身份职业：**清算中心**与易航**同期外勤**；竞争编制；账市对手苗
- 所属势力：清算中心编制线（郭周堂体系内）→ 后期向**免债会/销账捷径**倾斜；S2 可升主对手
- 首次出场卷/章：卷二 · 同期入职/第一单抢功起 → 卷四腕异常侧写 → 卷九免债会边缘站队

## 外形记忆点（3条内，正文少堆）
- 工牌挂得比易航正；鞋面总比别人亮半档（要强写在细节里）
- 笑时嘴角上扬、眼神先算分；输了会先整理袖口
- **长线标记**：腕上可呈**「无负数」体感**（F06：免债会**销登记**产物，**非改律消债**）——旁人看不出；易航看价应见**登记空 + 本源淡纹仍在**（更怪，非真干净）

## 性格
- 核心：要强、爱面子、手腕比易航**脏半寸**；不是天生大恶，是「不想当第二」把捷径走穿
- 口癖/习惯动作：嘲讽版「你再装呢？」；抢功时拍肩「这次我来」；学易航「您再想想」反过来阴阳（F20）
- 绝不会做的事：当众承认自己技不如人；在编制竞争里主动让功；轻易承认腕上「无负数」是交易来的

## 动机
- **要什么**：编制名额、案绩、被郭周堂看见；证明自己比易航「更适合干这行」；后期要**账干净**（免债会承诺的洗白/销账）
- **怕什么**：永远当易航的影子；腕上异常被当众验出「假干净」；奶奶/家中旧债被翻成把柄（可挂家旧债线）；S2 被石头线反噬前的道德真空
- **底线**：可以阴招、抢功、落井——**初期**仍假装「我也是按规定办」；一旦走上销账，底线改为「数字干净比人干净重要」

## 与易航
- 关系类型：同期同事 → 竞争刃 → 对立镜 → 免债会边缘站队；**长线镜像**（易航关系核里的「镜」）
- 关键债务/人情：同批案子抢功（V2）；拍卖/证物同场（V4）；无纹期落井（V6）；免债会对峙（V9）
- 对手戏功能：
  1. 照出「脏半寸」与「您再想想」两种外勤哲学
  2. **无负数 vs 黑页**：捷径干净 vs 扛着明细黑的真实
  3. S1 终局逼易航拒销账；S2 可升格为主对手苗（与石头线可挂）

## 弧光（S1）
- **起点（卷2）**：同期外勤；要强、抢第一单；阴招争编制，两败或记恨
- **中点（卷4–7）**：腕上异常被易航看见却嘲讽遮过；无纹空窗期踩易航；越来越信「干净数字」
- **终点/挂线（卷9–10）**：免债会边缘；销账诱惑兑现为「无负数」；与易航对峙（口癖对撞 F20）；可未死，挂 S2 宿敌苗；奶奶/旧债线可露一角

## 知情范围（开场）
- **知**：中心外勤规矩、抢功门道、易航「您再想想」的刺耳处；市面上有销账/洗白传闻（中后期坐实）
- **不知**：黑页与易秀担保真相；陈宏远全貌；自己「无负数」的全部代价（可误以为真免）
- **误信**：编制=安全；脏半寸只要不被抓就不算；销登记后就真的「没债」（实为本源仍在，漏证加倍反弹）

## 禁写
- 禁止开局即不可理喻反派；要先「像同事」再脏
- 禁止无铺垫突然腕上无负数；须经 F06 埋点（卷4–9）再收
- 禁止阴司鬼差人设；禁止与李强混成同一功能（李强=催收脸，李飞=同期刃/长线）
- 禁止无代价洗白成好兄弟；和解若有，必须付名/人/物价
- 禁止把「无负数」写成无敌 buff——它是**假干净**与剧情炸弹

## 短剧名场面（2）

- **场面**：合规清算小胜边缘；李飞抢在易航前结案/抢署名；事后阴阳「你再装呢？」
- **钩**：编制竞争开战；李飞记恨或易航第一次把「同期」标成刃
- **短剧 comm**：两份工牌同框；签字笔只一支，李飞先够到

### 2. 腕无负数 +「您再想想」对撞（卷9 · F06 + F20）
- **场面**：免债会边缘或对峙厅；易航看价——李飞腕上**登记空转/淡纹怪**；李飞用学来的「您再想想」嘲讽；易航点破**销登记假干净**
- **钩**：捷径的假干净当场破产或半破产；S2 对手苗钉死；黑页母题「拒销」对位
- **短剧 comm**：双腕特写——一侧总额红黑，一侧空白得吓人
