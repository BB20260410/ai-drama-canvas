# 崔七

## 基础
- 姓名：崔七（市井名；可称「七哥」；禁止取阴差/判官式称号）
- 性别/年龄感：男 · 约 35–45（比阿大更「成气候的灰市人」）
- 身份职业：**活人灰市**掮客；对外名片/话术——「特殊资产撮合 / 不良债权咨询」；旧码头账市规矩人
- 所属势力：**地下账市**（临川旧码头场子）；与春禾/信汇/清算中心有**买卖接口**但非编制；洗白方向可碰「合规处置」外壳
- 首次出场卷/章：**卷四** 入市（V4-U1）；卷三末可侧写场子/规矩半句；卷一鬼市摊仅氛围，**不提前正名绑架主线**

## 外形记忆点（3条内，正文少堆）
- 手指常沾粉笔灰或记号笔味（标拍品编号）；指甲缝干净——碰的是纸不是土
- 半旧皮衣或工装外套，内袋永远有两支笔、一叠便利贴价签
- 笑的时候先问「你带什么进场」——不问天气

## 性格
- 核心：**规则贩子**——信「灰市比黑拳公平，因为价签写在明面上」；冷血撮合，但护自己定的规矩
- 口癖/习惯动作：「门票先结」；「这单打包了」；用指腹蹭价签角；谁坏规矩谁先被取消进场资格
- 绝不会做的事：自称阴差/替死人收债；免费带生人逛核心库；在邓依镜头前承认「我们在拍卖人」

## 动机
- 要什么：**场子不塌、抽成不断、规矩仍由他解释**；必要时用「洗白合规」把灰市接进半官方管道多活几年
- 怕什么：拍品被证「卖方无处分权」导致连环流标；清算中心一刀切取缔；陈系把账市当弃子整锅端
- 底线：可帮易航、可卖易航；**不卖自己的规矩解释权**；不替任何人无代价洗白成圣人

## 能力/资源/把柄
- 能力（人间规则，非灵异）：
  - 打包债、分层债权、身份/信用抵押物的**撮合与拍卖主持**
  - 进场规矩考、门票债、瑕疵条款——可被智斗利用（卷四流标打法）
  - 「特殊资产掮客」话术：对接律师函、不良资产公司、形式合规材料
- 资源：旧码头场子、掮客网络、残页/凭证流转渠道；认识阿大旧圈（可互知半面）
- 把柄：曾经手与恩债/担保相关的残件；洗白路径依赖中心或宏远系接口——易航可卡他的命门

## 与易航
- 关系类型：**灰盟友 / 规则考官 / 可交易不可托付**
- 关键债务/人情：
  - 入市**门票债**（规则价，不可自选）：**物价约 3000** + **名价**（真名登记、外勤身份押场）；见 `设定/势力/免债会与门票债_简则.md`
  - 人价拍下后易秀忘子——崔七不负责安慰，只负责「价已结」
  - 可因场子利益向易航递规则漏洞；也可在陈系施压时临时关门
- 对手戏功能：
  - 卷四：入市规矩考 → 拍卖抢证物 → 用庄家自定瑕疵条款反杀流标
  - 卷五–七：灰市情报与洗白合规窗口；卷终可被上层点名波及
  - 禁止变阴司导师；禁止无代价忠犬

## 弧光（S1）
- **起点**：灰市看门人；「你想买规则，先付门票」
- **中点**：与易航交易型合作；目睹人价后果仍谈价；被洗白/取缔压力挤压
- **终点/挂线**：场子或收缩或并入半官方管道；可帮港湾提供「遮盖必须留痕」的反面教材；**不做卷十最终 BOSS**；S2 可外城账市接口

## 知情范围（开场 · 卷四）
- 知：打包债怎么标价；哪些残页能拍；进场谁带刀谁带U盘；春禾/信汇偶发货源
- 不知：易秀按签全貌；陈宏远完整受益链；黑页作者层真相
- 误信：只要价签清楚、双方签字，道德就不归他管；易航付得起人价就会一直是好客户

## 禁写（硬锁）
- **禁止阴司、阴差、鬼市阴魂、地府编制、死后收债**——崔七是**活人灰市掮客**
- 禁止超自然主动施法；拍卖的是**债权凭证、身份抵押、信用/关系代价的人间包装**，不是魂魄
- 禁止写成单纯搞笑丑角或无脑黑帮大哥
- 禁止卷四前人价主戏提前烧光；人价完整遗忘戏在卷四，不冲淡
- 遵守 P0：一次操作一种规则价；烧应收不烧第三方；无阴司世界观

## 短剧名场面（2）
1. **规矩考入市**（卷四开）：旧码头门禁，崔七只看价签与门票债——「你带证据还是带命？门票先结。」檀溪引路，易航第一次用灰市语言说话。
2. **流标反杀**（卷四中）：拍品残页被包装成「债权凭证+身份抵押」；易航用登记时间、双委托链与崔七场子自定的瑕疵条款，证卖方无完整处分权——崔七敲槌流标，价签当场作废，全场哗然而他只说：「规矩是我定的，也吃我自己。」
