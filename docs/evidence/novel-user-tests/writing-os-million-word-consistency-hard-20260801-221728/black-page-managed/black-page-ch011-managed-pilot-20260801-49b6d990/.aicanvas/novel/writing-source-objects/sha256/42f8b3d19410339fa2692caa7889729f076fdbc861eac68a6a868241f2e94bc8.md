# 肖龙

## 基础
- 姓名：肖龙
- 性别/年龄感：男 · 约 23–26，与易航同辈
- 身份职业：临川工职院/临川大学计算机相关（在读或刚毕业）；兼职网吧网管；技术外援
- 所属势力：无编制；普通人侧；可被清算中心接口「蹭到」但不入伙
- 首次出场卷/章：卷一 · 约第 007 章（来电/送泡面；承诺查公开信息）

## 外形记忆点（3条内，正文少堆）
- **偏瘦毒舌**（避「胖子工具人」模板）；黑眼圈、键帽油渍
- 常年泡面味；电脑包拉链坏了用扎带
- 说话快、损完自己再损易航；紧张时抠指节

## 性格
- 核心：正常人视角；嘴硬心软；信数据不信「我感觉」
- 口癖/习惯动作：
  - 「你别把人往死里算」
  - 「公开的我才碰；内网你自己死」
  - 敲键盘节奏当情绪；截图先存三份
- 绝不会做的事：
  - **不黑库、不社工、不越权入侵**（正典硬边界：只能查公开信息）
  - 不为「哥们义气」伪造证据
  - 不替易航付规则价（他付的是现实风险：身份暴露、网贷旧案被翻）

## 动机
- 要什么：还易航当年救命/挡债人情；证明「普通人也能用合法信息拆局」；自己别再掉进网贷坑
- 怕什么：再次被校园贷/网贷链条咬住；怕易航把人「算死」后自己也成帮凶
- 底线：公开信息能查尽查；一旦要碰非法入口就停，并明确说「我帮到这」

## 能力/资源/把柄
- **能力**：工商/裁判文书/招标/股权穿透/域名备案/公开社媒与批量账号画像；画节点图；半吊子反查黑帖（公开侧）
- **硬限制**：**只能查公开信息**；不能进清算中心内网、不能拖库、不能破解债纹系统
- **资源**：旧同学网、网吧机器与夜班窗口、多盘备份习惯
- **把柄**：本人被校园贷/网贷坑过；易航救过 → 人情债；反查黑帖时可能暴露旧网贷身份（名价/现实后果，≠规则价）
- **S2 挂线**：可进化为「数字账工具」原型（合规爬虫+证据哈希），非超自然

## 与易航
- 关系类型：旧同学 / 死党 / 可吵翻的技术眼
- 关键债务/人情：
  - 易航当年帮挡网贷或托人解套 → 肖龙欠「一命级」人情，但用技术分期还
  - 易航给他泡面钱/机时费；他给图与表
- 对手戏功能：
  - 卷一：春禾–信汇关联股、外包客服同源、黑帖反杀一半
  - 卷三–六：恩债农场数据链、节点图、烧光前排序辅证
  - 卷八：访问日志/公开侧时间线，与邓依程序链、黑页校验三线合一（仍不越权）
  - 吐槽锚：随时把超自然戏拉回「人会被算死」的普通人恐惧

## 弧光（S1）
- **起点**：送泡面的损友；「你像要去收债」  
- **中点**：越帮越深，半边黑帖反杀失败、旧身份暴露；仍坚持公开边界  
- **终点/挂线**：成为证据港技术外援原型；可与易航吵翻一次（为「算太狠」），再因母线/港湾和解挂线

## 知情范围（开场）
- 知：
  - 易航穷、急、护母；可能在「搞钱搞账」
  - 公开工商与网贷套路
  - 自己的旧坑与易航人情
- 不知：
  - 债纹/四价/黑页完整规则（最多听易航半句黑话）
  - 郭周堂废签与卷八母债伪签
  - 清算中心内部档案与改页手法（卷七可旁观，仍无内网权）
- 误信：
  - 起初以为易航只是「护工兼搞副业」
  - 可能误信「有公开股权就能直接报警结案」（低估程序与假壳）

## 禁写
- 黑客开挂、一键进内网、伪造电子签名
- 胖子丑角/纯工具人；要有嘴、有怕、有拒绝权
- 替代邓依的程序正义位（他是数据眼，不是合规办）
- 阴司、见债纹、替易航结算规则价
- 院校地名必须用**临川**工职院/大学；**禁止**「江城」

## 短剧名场面（2）
1. **泡面上门**：「公开的我才碰。」屏幕上弹出春禾与信汇同一地址/同一外包——「你真要去收债啊？」  
2. **黑帖反杀半边**：一半账号拿下，另一半同步指令指向清算中心外包接口；肖龙砸泡面桶：「我只能查到公开的……内网不姓我。」
