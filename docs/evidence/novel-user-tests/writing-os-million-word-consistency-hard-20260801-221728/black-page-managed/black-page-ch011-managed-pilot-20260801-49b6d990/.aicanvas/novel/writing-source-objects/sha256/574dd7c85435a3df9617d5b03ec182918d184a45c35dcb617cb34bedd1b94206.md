# 吴姐（护士长）

## 基础
- 姓名：吴姐（全名可「吴敏」）
- 女 · 四十上下 · 市三院肾内护士长
- 势力：医院（不作恶边界）
- 首次：卷一

## 外形记忆点
白大褂口袋便签、压低声音说话、站姿稳

## 性格
- 务实、护病人、烦医闹与催收
- 口癖：「不是我不帮你」
- 绝不会：因欠费拔管、把患者当筹码；**不知**外包窗卖名单（泄露源≠正式医护）

## 动机
- 要：病区秩序与患者基础治疗
- 怕：事故、被投诉、催收进治疗区
- 底线：急救不停

## 能力/资源
- 排班与家属沟通渠道；不能开后台财务

## 与易航
- 护工协作；可暗帮复印；不站队讨债

## 弧光
卷一人性锚；后可偶尔回访

## 知情
- 知：欠费与排班规则
- 不知：债纹/春禾黑幕
- 误信：以为只是钱的问题

## 禁写
写成圣母或医院反派

## 短剧
1. 拦催收在接待区
2. 塞给易航一张排班表当死线


## 扩展备注
