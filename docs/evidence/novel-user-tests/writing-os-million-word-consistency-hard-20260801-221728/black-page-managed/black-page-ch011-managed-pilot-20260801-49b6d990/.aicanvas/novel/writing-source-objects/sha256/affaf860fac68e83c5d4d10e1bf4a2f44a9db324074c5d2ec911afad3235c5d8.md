# 赵姐

## 基础
- 女 · 三十多 · 单亲/社区受助者或小节点
- 功能：恩债道德秤（烧应收/放过的演示位）
- 首次：卷一末或卷三

## 外形记忆点
廉价羽绒服、护着孩子、笑得小心

## 性格
- 要强又心虚；怕被揭穿「受恩」
- 口癖：谢谢你啊谢谢你
- 绝不会：主动害孩子

## 动机
- 要：活下去、孩子上学
- 怕：恩债到期、被社区指点
- 底线：孩子

## 与易航
- 易航可读她金纹；可能放过她付代价 → 读者疼

## 弧光
道德秤 → 可揭露她也是农场末梢 → 不全黑不全白

## 知情
- 知：自己签过救助
- 不知：上层如何打包
- 误信：慈善是好人

## 禁写
纯白莲或纯骗

## 短剧
1. 门口金纹变粗
2. 易航烧应收后自己疼


## 扩展备注
- 卷三主用；卷一可侧写领救助物资
- 金纹演示：善意变粗；易航若烧应收，自己必须当场疼
- 可有孩子戏一眼带过，不虐童
- 后期可揭她也是农场末梢「介绍人」拿过小回扣，复杂化
