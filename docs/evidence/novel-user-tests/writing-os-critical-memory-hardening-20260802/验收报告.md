## 性能风险

正确性通过，但 append-only checkpoint 的当前实现存在明显写放大：

- 原始 500 章循环 p50 `7,489.51 ms`，p95 `12,732.71 ms`，max `14,382.17 ms`。
- 200→500 shadow rebuild p50 `2,779.3 ms`，p95 `3,167.74 ms`。

因此本轮裁决不是无条件 `VERIFIED`，而是 `VERIFIED_WITH_PERFORMANCE_RISK`。这不阻断当前一致性功能，但在更长连载或并发 Agent 场景应把 checkpoint 去重/增量化列为 P1 性能任务。
