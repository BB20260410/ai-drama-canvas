## 1. 四价结算唯一口径

1. 四价**类别与额度由规则决定**，易航**不能**点菜单选最便宜。  
2. 操作前只见**模糊预警**（如「身价偏重」），不见完整价目表。  
3. **一次**超自然操作只结算**一种**规则价。  
4. 同场可有现实后果（被剪辑网暴），须标明≠第二笔规则价。  
5. **名价**＝信誉/身份/记录；**人价**＝亲缘遗忘/关系断裂（易秀忘他归人价）。  
6. 卷一前段代价阶梯：**身（试刀）→ 名（015/016 社死）→ 人（卷四）**。003 禁止付人价。

## 2. 操作唯一释义

| 操作 | 释义 |
|------|------|
| 看价 | 看见既有关系可能产生的代价，**不造债** |
| 认债 | 确认事实与凭证，**不改债** |
| 过手 | 把错挂/遮蔽的结算压力**显回真实责任节点**；不改金额、不塞无辜、≠卖债 |
| 烧应收 | **只烧自己依法/依事实享有的追讨权**；不烧证据与第三方债 |
| 吞账 | 经契约成为**并列承责**；原责任人不因此免责 |
| 烧光（卷六） | **多笔**烧应收+弃权限的**序列**，非新技能；每笔仍只付一种价；累计可称「全价」 |
| 归零 | 指可调用的应收与操作权限归零，**不是**个人债务清零；黑页与真实担保**烧不掉** |

成立条件：事实关系 + 责任主体可识别 + 至少一项可复核凭证。

## 4. 卷八真相（作者层 · 卷八前勿完整公开）

1. **原始事实债**：易航幼年致死危机，易秀清醒时自愿签**一次性、有限额、不得转让**的救命担保；原始标的＝**易航的命**。  
2. **身体根**：易秀承担持续性身价损耗，与后来透析线埋根；疾病仍按现实病程写，不纯诅咒。  
3. **伪造扩张**：陈宏远系在易秀意识受损时**托手按签**，扩成永久担保，并非法加入姓名/身份/收益权。  
4. **双层账**：债纹只认真实救命事实；中心账本执行被扩写伪债 → 黑页＝真实欠+非法遮盖。  
5. **郭周堂**：掌握废签/风险，招易航既为控也有翻案出口。  
6. **母子冲突点**：不是「救了儿子」有罪，而是她曾入清偿侧、长期隐瞒，并默许系统用**别人的代价**维持担保。

## 6. 港湾机制（卷十胜利条件）

港湾≠免债王国，四层：

1. **证据港**：纸档+哈希+多人见证  
2. **生存桥**：争议期治疗/租住/学费限期垫付  
3. **清算席**：受益穿透、异议、期限复核（多方签章）  
4. **权限笼**：任何涂黑必有遮盖者/理由/期限/日志  

胜利：冻陈系接口；公开受益链护隐私；私权→多方复核；易航交一人全城明细权；**黑页保留**作第一宗历史异议案。
