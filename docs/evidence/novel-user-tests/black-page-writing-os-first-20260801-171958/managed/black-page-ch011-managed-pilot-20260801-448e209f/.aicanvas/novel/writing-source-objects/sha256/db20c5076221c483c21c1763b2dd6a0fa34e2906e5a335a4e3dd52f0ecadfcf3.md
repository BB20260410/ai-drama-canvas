# 郭周堂

## 基础
- 姓名：郭周堂
- 性别/年龄感：男 · 约 48–55，体制中年
- 身份职业：**清算中心主任**（半官方壳的一把手脸）；签批外勤预登记、高风险档案、从业契相关
- 所属势力：清算中心 / 与风险办接口；上接更大庙堂（陈宏远系有渗透，他非纯走狗）
- 首次出场卷/章：
  - 卷一尾：名字/签批/电话声（约 061–065）
  - 卷二起：笑面招安，实体对手戏

## 外形记忆点（3条内，正文少堆）
- 笑眯眯；说话像开会，短句带「原则上」「口径」
- 左手可缺一指或指节畸形（**改律/旧伤可选**；用则卷一后侧写，勿早剧透）
- 工牌与签字笔永远在位；递文件先盖手再开口

## 性格
- 核心：**体制人格化**——非纯反派；把人当刀也给人壳；一切要「过会」
- 口癖/习惯动作：
  - 「你跟我们走一趟。」
  - 「原则上可以；材料齐了再说。」
  - 「现在，你只是个人——可账还在滚。」（能力清空后可用）
  - 点头笑、翻页不抬头、用签字代替情绪
- 绝不会做的事：
  - 不当场撕破「半官方」合法皮
  - 不把废签/卷八级真相一次喂给易航（分阶段给壳、给压、给出口）
  - 不亲自上街头催收（他是门，不是李强）

## 动机
- 要什么：
  - 控住见债/能算账的刀（易航）——**招安即紧箍**
  - 维持中心账本可运转（含被扩写的伪债接口）
  - 给自己留**翻案/止损出口**（见下「废签」）
- 怕什么：
  - 账本被外行当街拆穿；风险办/上级问责
  - 易航失控（黑化或公开化） simultaneous 废签窗口被陈系封死
  - 自己变成下一个「改律缺指」的标本
- 底线：中心不能崩在自己任上；必要时可牺牲外勤与脏单，但留一条「程序上能退」的缝

## 能力/资源/把柄
- **资源**：编制与编外名额；从业契；档案签批权；与邓依（派驻合规）的接口；外包系统与半官方多壳
- **关键权柄（P0 卷八真相 · 作者层）**：
  1. **掌握废签/风险**：知悉部分伪签、扩债、高风险担保卷存在「可废/可议」缝——包括易秀线相关风险卷
  2. **招易航动机双面**：
     - **控**：把见债者收编进从业契与权限笼，避免黑市刀失控
     - **出口**：需要一把能在证据链成熟时推动翻案/止损的刀——易航既是风险也是出口
  3. 卷八前：**勿完整公开**上述动机；正文只给「招安+施压+别深挖」的行为层
- **把柄**：改律旧伤（可选）；历史上默许改档/止损口径；与陈系接口说不清的签字
- **能力边界**：不一定见完整债纹；强项是**账本权与会务权**，不是街头狠

## 与易航
- 关系类型：上司 / 亦师亦压 / 体制门
- 关键债务/人情：
  - 给编制、药费窗口、合法外勤壳 ↔ 套从业契、脏单、违约金命价（F09）
  - 非父子、非师徒跪礼；是**签字关系**
- 对手戏功能：
  - 卷二：笑面招安；第一单合规小胜后塞脏单
  - 卷四–七：施压「别深挖担保人」；从业契催命；烧光后点破「你只是个人」
  - 卷七：账院——默认「止损」式改记；被易航用无挂办案反杀 procedural
  - 卷八：废签/风险材料在证据链成熟时成为翻案接口之一（与邓依程序、肖龙数据、黑页校验合流）——**他给门，不给全套良心**

## 弧光（S1）
- **起点**：把易航当刀——「跟我们走一趟」  
- **中点**：刀反咬会务；从「你深挖我就毁契」到「你要改账也得按我的会开」  
- **终点/挂线**：非最终反派；可被迫让渡部分解释权给港湾式多方复核；仍是体制脸，可恨可懂，不可洗成慈父
