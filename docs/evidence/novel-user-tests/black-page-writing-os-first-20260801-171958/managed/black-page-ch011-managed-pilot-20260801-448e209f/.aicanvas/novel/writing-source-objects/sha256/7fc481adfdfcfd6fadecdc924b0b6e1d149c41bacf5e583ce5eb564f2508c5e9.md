# 石头

## 基础
- 姓名：石头（小名；大名可后定「石磊」）
- 性别/年龄感：男 · 少年→青年（S1挂线，S2主对手苗）
- 身份：被打包坏账连累的遗属
- 势力：无→仇视清算体系
- 首次：卷四挂线

## 外形记忆点
瘦、盯人死、攥旧账本边角

## 性格
- 要强、记仇、先恨「系统」后恨具体人
- 口癖：少；关键句「我会学会算你的命」
- 绝不会：轻易原谅「为大局牺牲他家」的解释

## 动机
- 要：讨回公道/学会记账反杀
- 怕：再次被当数字抹掉
- 底线：不信免债会空话（可先信后醒）

## 能力/资源/把柄
- S1无超凡；有残账本/仇恨记忆
- 把柄：无；他是道德反噬

## 与易航
- 易航间接/直接参与过打包债后果 → 愧与被盯
- 功能：人价/吞账的「脸」

## 弧光
S1：出场挂线 → 卷九「算你的命」→ S2 宿敌

## 知情
- 知：家毁因债
- 不知：易航全部动机
- 误信：易航=收割者之一

## 禁写
工具人哭戏注水；童言说教

## 短剧
1. 拍卖夜门外盯人
2. 对易航说算你的命


## 扩展备注
- 卷四拍卖夜门外；卷九对线；S2升级
- 不要写成天生邪恶；恨来自被当数字
- 可捡易航掉落的收据学「记账」反派成长
- 与李飞：免债会线可能交叉利用
