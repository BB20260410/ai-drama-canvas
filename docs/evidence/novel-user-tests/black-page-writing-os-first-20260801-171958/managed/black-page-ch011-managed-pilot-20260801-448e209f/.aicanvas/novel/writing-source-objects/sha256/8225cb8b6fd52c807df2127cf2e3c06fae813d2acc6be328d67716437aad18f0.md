# 邓依 · 单卡（程序锚 / 第一女配）

> 功能一句话：**程序正义锚**——防易航黑化捷径；证据链把关；轻感情/战友感优先，不霸屏。  
> 口头禅对撞：她「**材料呢？**」↔ 他「您再想想。」

## 外形记忆点（3 条 · 正文少堆）

1. **工牌永远别在外套外侧**——审讯、外勤、开会都不摘；递材料时工牌会先撞进镜头/视线。  
2. **袖口常有一支按压笔**；对账时连点笔帽，不点头；皱眉只在眉心，几乎不扬声。  
3. **穿得干净到刻板**：深色外套 + 平底鞋，指甲剪短；加班后眼底一圈青，仍把文件角对齐再说话。

> 少写「清冷美女」形容词；用**工牌、按压笔、对齐文件**三个动作出场即可认人。

## 性格 / 口癖

| 项 | 内容 |
|----|------|
| 核心 | 清冷、话少、**重程序**；不信「好心」，只信**可复核的材料** |
| 决策习惯 | 先问证据链是否闭环；缺一环宁可不办，也不「先斩后奏」 |
| 对人态度 | 对弱者不端茶送水式同情，只给**合法路径**；对强权不跪，但也不街头侠义 |
| 口癖 | 「**材料呢？**」「谁签字？」「时间线对不上。」「按规定，现在不行。」 |
| 习惯动作 | 按压笔连点；把文件角对齐；拒签时把笔横放桌沿（「这条我不能签」） |
| 绝不会做的事 | 为「好人」伪造证据；为易航销毁物证；在镜头前演煽情；用感情绑架对方签字 |

## 动机

| 层 | 内容 |
|----|------|
| **要什么** | 1）让「清算」可公开、可复核，别变成另一家催收；2）保住自己编制与调查权（无编制=无刀）；3）查清风险办/清算中心与春禾账本是否同根（中后期） |
| **怕什么** | 1）自己签字的案卷日后变成收割令；2）程序被当枪使，她成刀把；3）易航捷径成瘾后，她被迫在「包庇」与「出卖」之间选 |
| **底线** | **不伪造、不销毁、不默许无主账**。可恨规则，但恨完仍要证据与公开；可帮易航挡程序刀，**不许**他拿她的名去黑吃黑 |

## 短剧名场面（2）

### 场面 A · 审讯室递工牌（卷 2）

- **场**：清算中心审讯/约谈室。易航刚收编，李飞在玻璃外。  
- **拍**：邓依进门不自我介绍，先把**工牌拍在桌面**，再推一沓未闭环材料：「你说你没黑吃黑——**材料呢？**」  
- **对撞**：易航慢声「您再想想。」她不接话，只把缺页用红笔圈出。  
- **功能**：建立程序锚声口；短剧 15s 可切「工牌特写 → 红圈 → 二人对视」。

### 场面 B · 挡程序刀（卷 5）

- **场**：停职/冻结听证会或现场执法交接。上头要用合规程序「合法弄死」易航一单。  
- **拍**：她把拒签笔**横在卷宗上**：「这条我不能签。」被调离/记过/挂伤（可瘸可不用命）——镜头给**工牌被摘或歪掉**一秒。  
- **收**：她对易航只一句：「下次把证据链补全。别让我第二次空签。」  
- **功能**：轻感情升温不告白；代价可见；服务主线（程序也是刀，她选挡在自己身上）。

## 写作速查

- 出场三件套：**工牌 · 按压笔 · 材料呢？**  
- 与易航一章最多 1 次立场对撞，够用；不要每场谈情  
- 她赢场面靠**链闭环**，不靠嘴炮感动  
- 挂伤/调离是资源损耗，写进后文权限变化
