# 顾棠

## 基础
- 女 · 青年 · 豪门旁支
- 势力：陈/宏远系边缘→叛出
- 首次：卷五（可选线，可后置）

## 外形记忆点
好衣服穿得随意、看合同比看人快

## 性格
- 冷静、交易感、不煽情
- 口癖：少形容词
- 绝不会：无契约帮闲

## 动机
- 要：拿回旁支被夺权益
- 怕：被当活抵押烧掉
- 底线：不卖自己人给炉子

## 与易航
- 用他「看见隐性债」；提供阶层内应

## 弧光
钥匙位 → 可去可留；不霸屏感情

## 知情
- 知：豪门打包债结构一半
- 不知：易航黑页真相
- 误信：钱能解决大部分

## 禁写
