# 日常 8 步操作卡（Agent / 人工通用）

> 无限画布主路径。偏离即旁路风险。证据目录可复用本卡。

1. **读进度** — `docs/当前开发交接.md` 顶段 + `STATUS.md` earliest（勿从零问目标）
2. **定工程** — `get_capabilities` → `get_active_managed_studio_context`（禁静默选列表第一项）
3. **红线自检** — 非隔离/未授权工程：只读；`dudu-s1e1-*` / codex 正式 PASS **不写**
4. **写前租约** — 多代理：`acquire_studio_project_write_lease`；有租约异主禁写
5. **正式环** — readiness → freeze（controlRefs≥1）→ dispatch(`provider=codex`) → prepare → **真生图** → `commit_agent_imagegen_result_bundle` → Review
6. **看片** — `getApprovedTimelineProjection`（UI/列表默认 **fastMode**）+ 缩略图；raw SHA 与 bond 对齐
7. **辅助** — 图文对照 / 四态一致性只读；机器**不**自动 Review PASS
8. **落盘** — 证据 JSON 新文件名 + 更新 STATUS/TASKS；禁句：formal ≠ 产品 100% 契合
