# 第003章 您再想想

李强离开接待区二十来分钟，又折回来一个人。

这二十分钟，易航回了趟病房。

病房里消毒水味压着膏药味。易秀睡着，呼吸浅。何叔那边鼾声轻，像怕吵醒谁。

易航把帆布包搁在膝上，拉链拉到底，抽出账本。指尖先摸到夹层那处凹痕——「担—」两个字没写全，纸背有压痕。他把春禾名片、缴费单、那条发件尾号093的担保链短信截图并排放平，手机拍了清晰照，存进加密相册，备注只打日期。拍完把手机翻过来，屏幕朝下压在膝上。

账本内页有几行数字：32700。门槛6800。1835实缴。预支2000。阿大借800。后面都没有勾。

他用指甲在缴费单服务费那行尾号上掐了道浅痕，和李强文件夹里被荧光笔涂过的位置对齐。

然后回接待区。不是等挨打，是等下一步。

联排椅凉。墙上的钟慢半拍。腕上那行黑字还在，-7贴着皮肤，像枚冷扣。李强袖口那截红缠灰还留在眼里。

来的不是李强。

小跟班，二十来岁，工牌歪着，名字磨得看不清。眼神飘，手里捏着半截表格，纸边被指节捏软了。

「李经理说了，今晚给个态度。」嗓子发紧，「转介条你收着也行。梁总那边……真会来。」

易航靠墙。名片在右手里捏得发潮，换到左手。背面是他自己写的两个字：口头。七天。身上像已经熬掉了七天。

「什么态度？」

「签字。或者先认分期。再不济——」小跟班咽了口唾沫，「私了也行。李经理说能帮你沟通。」

私了。

吃私收的人，来谈私了。

小跟班把表递过来：「签个『已知悉』。不签也行，就当态度恶劣，后续按程序加码。」

「已知悉不等于认账。」易航没接，「李经理个人收款码带来了吗？」

小跟班脸一白：「你胡说什么——」

「单据给我清晰版。涂过的服务费那行，重打。」

「你以为你是谁？」

易航看着他。

然后他想试一件荒唐事。

没有挥拳。先动的是眼睛。今晚才学会聚焦的那双眼，想把一笔脏账推回该担的人身上。

他盯住小跟班的手。纹浅，灰，碎。

注意力压过去。先划开那层浅灰，再往深处够——够李强左腕那截红缠灰。

世界猛地一滞。

像一根绳子从空桩上抽回来，绳头带倒刺，刮过虎口。桩是空的。凭证链是断的。力没处落，整根砸回他自己身上。

耳边嗡一声，像有人把铁盘摔在水泥地上。掌心炸开剧痛，麻顺着小臂往上爬。视野边缘的噪点乱了一下，又聚回来。

他闷哼，后退，肩撞在墙上。鼻血涌出来，咸，热，顺着唇缝往下淌。

他偏头。血滴在地砖上，没落衣襟。护工的毛病：脏血别带进病房。

小跟班后退半步：「你有病啊？突然流鼻血？」

易航想握拳。手指弯不拢，掌心像裂了道看不见的缝，麻到小臂。腕上那行黑跳了一下，又沉回去。-7还在。

疼是真的。丢脸也是真的。

更真的在电梯口。

李强没走远，卡在电梯门边探着半个身子。看见鼻血先愣了愣，随即笑出声。

「急眼了？自己急出病来怪谁？」他冲小跟班扬下巴，「走。」

小跟班逃似的跟上去。

李强迈进电梯，丢下最后一句：「你那点花样，没用。」

数字从1跳到3，停住。门合上。

李强脸上没有难受，没有慌，也没摸左腕。他只当这护工疯了。

易航靠着墙。

鼻血是真的。李强没事，也是真的。

怀疑有了，纹看见了，话术也对上了。可转账尾号、监控时间戳、能指认的第三人，一样完整的都没有。空着手去动别人的脏，先见血的是自己。

血落了两滴。他用鞋底蹭开，蹭成一片淡红的影。

接待区空了一阵。自动门开合，灌进夜风。

他坐回联排椅，仰头，拿纸巾塞住鼻孔。纸巾是从护士站顺的，粗，扎人。血往喉咙里倒，咽了两口，血味淡下去，铁味还在。

抬手擦唇角，手背沾了红。

手掌握了握，又松开。缺尾号，缺监控，缺第三人——就不能再碰那截红缠灰。

「……别硬。」

声音从侧面来，低，裹着烟味。

后门过道口，阿大靠着消防栓，没转脸。手里转一根没点的烟，指节粗，烟身被转得发白。那条微跛的腿斜伸出来，鞋底在地上蹭了一下。烟纸让指腹搓出细响。

易航擦鼻血，没接话。

「你也看见了？」他问。

阿大不答。打火机在口袋里咔了一声，没掏出来。

背影拐进暗处。胶底鞋声很快听不见了。

应急灯绿着，把那条过道照得很短。易航没追。一句「别硬」够他记到天亮。

洗手间。

冷水开到最大，水声盖住喉咙里那点喘。

镜子里眼白全是血丝，鼻孔下一道干红。他把右手按在裤缝上，试着伸直手指。伸直了，又抖。麻还在。

护工夜班不能垮在走廊。垮了，周主管有借口扣人，催收更有借口上门。

他用左手拧干纸巾，擦掉台面那点淡红，直到不锈钢盆干净得像什么都没发生过。

推门出来，撞上吴姐。

吴姐看他一眼，眉头拧紧，没问怎么了。她从口袋里抽出折好的排班表，塞进他手里。口袋里还有半截体温计，走一步磕一下。

「缴费处那边有人闹。」她压低声音，「八点后你别走那边。接待区就够烦了。」

「……好。」

「回去看你妈。明天我帮你问问，欠费确认窗口最早几点开门。」

「谢谢吴姐。」

「谢什么。」她已经走远，「别在走廊晕倒，我还得写事故。」

易航捏着排班表，指节发白，表角让汗洇软了一块。

周主管的扣款短信还在手机里。吴姐的事故也在。这院里人人都防着自己的事故；吴姐那本事故上，没有「易秀床位」这一项。

排班表上有红笔圈。一格旁注：欠费沟通/床位协调。

他折好，塞进内袋，和缴费单、名片叠在一起。

回病房前，在探视本上补了一笔：本人未离院，陪护中。

字歪了。右手不听使唤。

病房。

易秀仍闭着眼，手背贴着留置针敷贴，边缘翘起一点。易航在床边坐下，把袖口拉下来，盖住腕上那行黑字。

何叔的呼噜很轻。

他把排班表展开，指尖点着红圈那格，数从今夜到那天还有几晚。数完，和-7对上。

中间空着三格。没有窗口，没有缴费日，没有协调人。行政表上的空当，和那页黑账的跳法像：-7之后，下一次落点没准就是-4。

他把排班表折回去。

同夜未尽。李强的私收还在，梁总本人没来，春禾只有口头和一张名片。试过一次，败了，鼻血，对方无感。

「妈，费用我补上了——」他停住，「还没。我会补。」

易秀没有应。

他擦掉唇角那点血味。

「先算清楚。」

手机备忘录打开。手还麻，字打得慢，错两个，删掉重来。

「李强。左腕。红缠灰。毛边。疑私收。缺：尾号/监控。过手失败。身：鼻血。对方无感。」

按灭屏幕。

这点东西，算不上证据。

他盯着名片背面自己写的那两个字。

「您再想想。」

声音很轻。不是说给李强，李强听不见。是说给这张名片，说给口头援助，说给所有看上去能救命的便宜。

名片、缴费单、排班表，三样纸并排摊在膝上。

口头。欠费。窗口。

三条线。还缺第四条：凭证。

明天窗口开门，他要去问清楚「确认」到底确认什么。不是求情，是对账。能复印的复印，能要回执的要回执。流那一下血教会他的就一句：没有纸，就没有手。

窗外夜色沉着。排班表上那个红圈，和腕上的-7，并排放着。

还剩七天。

他用还能动的左手给母亲掖被角。右手仍麻。

「妈，明天窗口。」嗓子哑，「我带着纸去。」

易秀指尖动了一下。极轻。

他盯着看了很久。

手机忽然震了一下。

新短信，发件尾号093：【担保链】您关联的担保链出现异常，请于窗口期处理。

易航把屏幕扣在膝上。

他把排班表折进账本夹层，和「担—」那页隔着一层纸。32700、6800、1835、2000、800，这些数字挤在同一页上，像一排没钉牢的钉子。

闹钟已经定了。七时四十。备注：对账。

接待区地砖上的血，这会儿大概拖干净了。地砖会重新亮起来，腕上的-7不会。

他从帆布包里摸出半包饼干，掰一小块，嚼得很慢。甜腻。胃里压上点东西，手才不那么抖。

第一夜还没完，账本已经翻开了。

窗外天没亮。停车场的双闪又亮了一下，很快灭掉。

易航闭了闭眼，没敢真睡。

怕一睡过，窗口的号就没了。
