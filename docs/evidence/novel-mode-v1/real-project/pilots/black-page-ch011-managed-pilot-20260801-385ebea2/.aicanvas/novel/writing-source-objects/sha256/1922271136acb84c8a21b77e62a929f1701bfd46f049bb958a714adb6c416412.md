# 易秀

## 基础
- 姓名：易秀
- 性别/年龄感：女；约 48–52（儿子 23–25 时的母亲感，勿写「太年轻妈」）
- 身份职业：市三院肾内科/过渡病房长期住院患者；昏迷—浅昏迷间歇；规律透析依赖。年轻时曾入**清偿侧**（清算/担保相关岗位或合作方一线），笔迹与签章曾出现在官方/半官方担保文书上
- 所属势力：无现役归属。历史：清偿侧旧人；现被**陈宏远系**伪债链挂为永久担保节点；身体在市三院（医院不作恶）
- 首次出场卷/章：卷一 · 第 001 章（透析室/过渡病房床位；黄金三章必须在场）

## 外形记忆点（3条内，正文少堆）
1. **腕带 + 针眼 + 透析通路**：皮肤干薄，手背/前臂有反复穿刺痕；被单叠得极整齐的一边常压着**手写流水账本**（或病历夹里夹着旧收据）
2. **昏迷也像「在算」**：眉心微蹙，手指偶发抽动像要翻页；苏醒片段里目光先找**数字/单据**，后找人
3. **旧工牌式干净**：年轻照片里衬衫领口板正、与清偿侧门牌同框（卷7 可露）；病床上仍是短发或扎得很紧，不施脂粉

## 性格
- 核心：**记账癖 + 复杂母职**——爱儿子是真的，爱「账平」也是真的；非纯白圣母。清醒时冷静、克制、话少，习惯用流水账压情绪；对「免费好事」本能警惕，却又曾默认用系统规则（含别人的代价）维持担保结构
- 口癖/习惯动作：
  - 口癖（清醒/浅醒）：「记上。」「这笔……不圆。」「先别签字。」「航航，拿本子。」
  - 习惯：把每笔药费、透析耗材、人情往来写成**手写流水**（日期/事由/出入/余额感）；叠收据边角；昏迷前最后习惯是把笔塞进本子夹层
  - 对易航：极少肉麻夸奖；用「费用齐了吗」「班别旷」代替「我爱你」
- 绝不会做的事：
  - 不会把「救儿子」说成后悔（原始担保自愿，罪感来自**隐瞒与默许扩写后果**，不是悔救）
  - 不会在清醒时主动教儿子「用别人的命垫账」却不付自己的价（她怕的是这套逻辑被儿子继承）
  - 不会把医院当敌人或配合院内害人

## 动机
- 要什么：
  1. 易航活着、不被标成可转让资产
  2. 自己名下的账「能圆」——原始救命担保有限额、可审计；伪永久担保被废
  3. 若醒：要亲手把流水账对上黑页真相，而不是被当成只会躺着的苦难道具
- 怕什么：
  1. 易航为救她付**人价/名价**到不可逆（忘她、或她忘他）
  2. 被发现曾入清偿侧后，儿子只剩恨、不剩「还能一起算」
  3. 伪债链以她的身体当永动机，透析与昏迷变成收割接口
- 底线：
  - **原始一次性救命担保可认**；**按签扩写的永久/转让/收益权条款不认**
  - 禁止用「我是你妈」逼易航免掉别人的正当债；也禁止易航拿她当免罪金牌
  - 三章内禁止真死（活牵挂）；疾病按现实病程写，不纯诅咒

## 能力/资源/把柄
- **能力**：无超自然金手指。清醒期有**账目直觉**与文书习惯（何处该留底、何处是夹层条款）；昏迷期仍是债纹/伪债的**锚点身体**
- **资源**：
  - 手写流水账本（时间线、药费、早期担保相关备注的旁证）
  - 旧工牌/旧合影/废纸篓级按签颤笔迹（卷8 事实链）
  - 市三院在院事实 + 吴姐等人证（非作恶）
- **把柄（被别人捏）**：
  - 昏迷时**托手按签**形成的伪永久担保（陈宏远系）
  - 清偿侧旧履历可被梁景衡式公关歪曲成「她自愿卖命」
  - 透析依赖 = 经济死线（药耗/排班/生活费，**非**当场拔管）
- **作者层真相（卷8 前勿完整公开给读者/角色）**：
  1. 幼年易航致死危机 → 易秀清醒自愿签**一次性、有限额、不得转让**的救命担保；标的＝**易航的命**
  2. 她承担持续性**身价损耗**，与透析线埋根（疾病仍写现实病程）
  3. 意识受损后被**按签扩写**为永久担保 + 非法加入姓名/身份/收益权
  4. 双层账：债纹认真实救命事实；中心账本执行伪债 → 易航**黑页**＝真实欠 + 非法遮盖
  5. 母子冲突点：不是「救了儿子」有罪，而是她曾入清偿侧、长期隐瞒，并曾默许系统用**别人的代价**维持担保

## 与易航
- 关系类型：血缘母子；全书**北极星与情感死线**；卷8 后转为「共犯式坦白后的重建信任」
- 关键债务/人情：
  - 她付过的：原始救命担保（命/身价链）
  - 他付着的：透析与疗程的现实费用、为保母卷入清算与四价
  - 未揭开的：黑页明细涂黑处与母担保绑定；碰母时黑页会「跳」
- 对手戏功能：
  - 卷一–七：床边戏、浅醒、手指动、抓旧收据；驱动易航行动，禁止纯背景板
  - 卷四人价：可完整写「请问，你是哪位？」（遗忘一场写透，勿下章立刻冲淡）
  - 卷八：担保人真相的人证/身体反应链；与邓依程序链、肖龙数据链三线合并
  - 全程对撞句感：他「妈，费用我补上了」↔ 她「记上」「别拿命做抵押」（若醒）

## 弧光（S1）
- **起点（卷1）**：昏迷透析；被催收与假善意同时盯住；读者只知「要救妈」
- **中点（卷2–6）**：档案露出「担保人：易秀」→ 总表黑戳（她也曾入系统）→ 人价遗忘 → 烧光后她床边负数仍在；读者与易航压力同步上升
- **终点/挂线（卷8–10）**：按签与原始限额担保拆开；她非纯白被承认；易航建港湾不称王时，她的流水账/黑页异议案成为第一宗历史锚；S2 可挂：她清醒后如何面对自己当年默许的「别人的代价」

## 知情范围（开场）
- 知：（作者/潜意识层）曾签过救命相关文书；流水账习惯；对儿子有强烈保护欲；隐约知道「系统会吃人」
- 不知（昏迷期）：伪债如何扩写、谁在收她的账、易航已见债纹、黑页字段含义
- 误信（若浅醒片段）：费用「还过得去」；签字「只是手续」；以为瞒住履历就能护住儿子

## 禁写
- 三章内真死；长期写成公共透析大厅永久躺尸位（正典：肾内/过渡病房）
- 因欠费**当场拔管**；医院作恶；把市三院写成反派大本营
- 纯白圣母 / 纯黑卖子；把「救子」写成原罪
- 卷8 前完整公开担保标的、按签过程、黑页明细全文
- 阴司鬼神托梦交代真相；用诅咒代替肾病病程
- 工具人哭戏注水、口号式母爱、抢戏压过账本主线

## 短剧名场面（2）
1. **床边流水账（卷1）**：夜班易航叠缴费单，发现母亲夹层旧本——最后一笔字迹发颤只写到「担——」；监护仪滴答里，他腕上「到期 -7」与母腕带同框。无对白也可，钩在「担保」二字被切开。
2. **「你是哪位？」（卷4 人价）**：易航付人价赶回病房，易秀睁眼、礼貌、清晰：「请问，你是哪位？」他伸手，她缩回；黑页缺一角。整场写完遗忘，不靠下集秒好冲淡。
