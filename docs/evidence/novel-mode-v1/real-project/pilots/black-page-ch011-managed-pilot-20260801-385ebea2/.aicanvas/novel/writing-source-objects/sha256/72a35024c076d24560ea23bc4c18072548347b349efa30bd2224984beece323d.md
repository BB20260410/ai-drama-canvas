# 檀溪 · 单卡（灰区锚 / 第二女配）

> 功能一句话：**假善意内部地图**——恩债农场账本、危险盟友、信息差发动机。  
> 交易核：她要**豁免/干净身份**，他要**总账与名单**。可黑可灰，**禁止圣母洗白无代价**。

---

| 称呼 | 正文默认「檀溪」；基金内可「檀会计」；梁景衡当面可叫小名式昵称（虚伪亲近，她恨） |

## 外形记忆点（3 条 · 正文少堆）

1. **永远像刚开完会**：浅色衬衫/针织，包里有备用工牌绳（已作废的春禾挂件可当道具）。  
2. **笑先于回答**——嘴角先到，眼睛后到；紧张时用拇指搓**U 盘边缘**（金属壳磨手的那一下）。  
3. **指甲保养得过分干净**（会计手），却藏不住指腹计算器茧；天台风里头发乱了也先护口袋里的盘。

> 少写「御姐/狐狸精」标签；用**笑、搓 U 盘、护口袋**三个动作认人。

## 性格 / 口癖

| 项 | 内容 |
|----|------|
| 核心 | 笑面、**算得精**；怕死，但**更怕自己做过的账**被原样追讨 |
| 决策习惯 | 先算「谁出局、谁背锅、我换什么」；不谈理想，谈**对价** |
| 对人态度 | 对梁景衡式假善：表面配合、背地拆台；对易航：交易优先，心动是利息不是本金 |
| 口癖 | 「这笔怎么入账？」「免责条款在第几页？」「我要的是干净身份，不是你的英雄故事。」「小字你读了吗？」 |
| 习惯动作 | 搓 U 盘边；把合同翻到**最后一页小字**；笑着把录音笔当口红盒式随手搁（真假不定，制造紧张） |
| 绝不会做的事 | 无代价自白当圣人；为「感动」交出唯一备份；在梁景衡镜头前真哭求情（可演，不可真碎） |

## 动机

| 层 | 内容 |
|----|------|
| **要什么** | 1）**豁免**或等价干净身份（从春禾总表上摘名）；2）活命；3）把她经手的假救助账「有人接盘拆掉」——不是赎罪表演，是怕反噬落到自己头上 |
| **怕什么** | 1）U 盘失控（落到梁/陈/李飞手里=死）；2）被当弃子灭口；3）易航把她当一次性钥匙用完就扔；4）自己账上的金纹/人价被追索 |
| **底线** | **不交唯一原件换空头支票**；可脏可叛，但不做「免费圣母」；若易航卖她，她可以反卖——**灰，不是白** |

## 能力 / 资源 / 把柄

| 类型 | 内容 |
|------|------|
| 资源 | **U 盘**：春禾/恩债农场关键账本、救助确认书模板、部分名单与导流催收路径；基金内部流程与公章使用习惯；梁景衡发言稿与合同夹层知情 |
| 能力 | 会计眼：假救助如何入账、金纹如何包装成「捐赠/助学」；会录音、会留备份、会谈条件 |
| 把柄（别人捏她） | 1）她本人就是假账经手人（共犯证据链上有她）；2）叛逃后无编制、无保护；3）梁景衡掌握她签字页/工号 |
| 她捏别人 | 梁景衡直播话术与合同夹层对照；春禾节点名单；「易秀在总表」类碎片（卷 3 卷钩级） |
| 与债纹 | **无**见债；她用数字与条款理解世界；可被金纹/人价间接卷进，身体记忆是**怕**不是炫技 |

### U 盘纪律（写作硬锁）

- U 盘是**引擎道具**，不是万能钥匙：分卷释放，禁止一卷倒光。  
- **分层**：L1 农场名单 / L2 确认书模板与公章路径 / L3 更深受益链（总表碎片等）；每层交盘有**独立对价**。  
- 「唯一原件」指**当前层她仍控的主盘**，可有加密分层与校验码；**禁止**「交完又刚好全备份无代价」；假盘/调包/灭口 = 名场面燃料。  
- 卷三交盘 ≠ 交光；卷五「更深一层」必须是未交过的层。

## 与易航

| 项 | 内容 |
|----|------|
| 关系类型 | **交易型危险吸引**；可拉扯、可共入险地；不是白月光，不是纯爱线 |
| 关键债务 / 人情 | 卷 3：U 盘换豁免承诺；卷 4–5：共入灰市/活抵押险地；易航可付**名价**保她（卷 5）；她欠他命与名，他欠她总账入口 |
| 对手戏功能 | 信息差发动机；教他「善意如何入账」；逼他在脏与更脏之间选；卷 6 主张更狠解法制造分裂 |
| 称呼对撞 | 她：「你要账还是要当好人？」他：「您再想想。」——想的是价，不是情话 |

**感情纪律**：可暧昧、可险地体温，**禁止洗白成纯白**；与邓依冲突只打**账与立场**（公开程序 vs 灰区效率），不打修罗场。

## 弧光（S1 · 分卷节点）

| 卷 | 节点 |
|----|------|
| **1** | **侧影**：名片、电话、基金后台声音；不露全脸也可；埋「内部有人」 |
| **2** | 可电话/匿名料；正式戏仍压；让读者知「春禾内有缝」 |
| **3** | **交易登场**；叛逃带 U 盘；拆恩债农场关键内应；卷钩：**「你妈名字在总表第一行」** |
| **4** | 共入灰市；人价后**内疚**（她知情不足或算错价）；不圣母，用行动补盘/补名单 |
| **5** | **险被灭口**（梁景衡/陈系外围）；易航付名价保她；她交更深一层账；关系最烫也最险 |
| **6** | 主张**更狠解法**（与邓依公开路径对撞）；与易航争执；可暂时冷离 |
| **7** | 供出更多内部；空窗期她是「活地图」不是战力；可被体制或灰市同时追杀 |
| **8** | 担保人真相期：**可叛可守**——为自保可能压一页，或为总账交出；**禁止无代价洗白** |
| **9** | 免债会边缘**摇摆**；可助攻拆销账话术，也可差点被「豁免」收买——写成选择，不写成天生善良 |
| **10** | 去向**二选一**：跟港湾做公开账的脏手清洁工，或**自我流放还债**；不包办 HE |

**弧光一句话**：从「分赃的人」→「拆台的人」→ 仍须为经手假账付价；灰到底，或灰里求一条不灭口的路。

## 禁写

1. **无代价圣母洗白**（突然纯爱、突然无私献盘）  
2. 与邓依**修罗场注水**（争风吃醋章）；冲突必须落在账/立场/手段  
3. U 盘一卷倒空或反复「刚好还有备份」无损耗  
4. 工具人报幕：只负责递情报没有自保与恐惧  
5. 阴司/鬼差人设；真实公众人物套皮  
6. 用身体交易当默认手段（可暗示行业脏，不写剥削向擦边主戏）  
7. 把她写成「第二女主抢编制恋爱线」——她的主戏是**账与命**

## 短剧名场面（2）

### 场面 A · 天台交 U 盘（卷 3）

- **场**：春禾附近或清算中心可视范围外的天台/消防通道。风大，监控死角。  
- **拍**：她笑着把金属 U 盘放在栏杆上，**不递到手**：「豁免条款，你先说清楚。盘是利息，命是本金。」易航伸手时她拇指仍搓盘边。  
- **对白核**：「我要的是干净身份，不是你的英雄故事。」  
- **功能**：锁定交易型关系；道具特写；短剧 15s：笑 → 搓盘 → 盘落他掌心 → 远处梁景衡海报/喇叭声。

### 场面 B · 小字与墙角（卷 3 或卷 5）

- **方案 B1（声口建立）**：封闭空间，她把「救助确认书」念出**小字**：感恩代缴、债权转让、违约名价——念到自己签字处声线仍稳，手在抖。  
- **方案 B2（危险高点）**：梁景衡逼到墙角（发布会后台/停车场）：「盘呢，檀会计？」她背对镜头护口袋，笑着说「在合规室啊」——实际盘已在易航或假盘调包。  
- **功能**：假善拆穿靠**条款声**；危险盟友的怕死与算计同框；服务梁线与灭口危机。

> 短剧选用：A 必写；B 按集数选 B1 或 B2，勿同集两场都注水恋爱。

## 写作速查

- 出场三件套：**笑 · U 盘 · 小字**  
- 每出场先问：她这局**换什么 / 怕什么**  
- 给情报必带**价**与**反噬**  
- 与邓依同场：一个要材料闭环，一个要活路与盘——吵立场，不吵男人
