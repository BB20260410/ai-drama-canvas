> 本文件是 **`/goal` / Grok 长任务模式** 在「无限画布」项目的 **北星合同**。

## 一句话

**一边用 Grok（及 Codex）按剧本生图，一边把无限画布做成对生图真正有用的生产 OS**——角色一致、场景一致、站位/构图一致，以及其它剧本驱动一致性——最终两边 **互补到高契合**，大幅辅助代理完成生图，而不是「账本 PASS 了但导演仍在旁路拼 prompt」。

---

## 双轨（每一轮 Goal 都必须意识到）

| 轨 | 做什么 | 当前主载体 |
|----|--------|------------|
| **A · 产线生图** | 隔离工程内按剧本 unit-grid 有序：readiness→freeze→dispatch→prepare→**真实**生图→commit→Review | S1E2 U15–U25；`mcp-only-runner` / 租约写入口 |
| **B · 画布辅助力** | 把画布/MCP/CAS/Binding/连续性/审片/一致性投影，做成 Grok·Codex **离不开** 的辅助 | 写租约、earliest 同一真相、controlRefs、一致性评价、门禁、审片台 |

**禁止二选一**：只堆 formal 单元而不改进辅助面 = 偏离北星；只改软件而不真生图 = 无法验证契合。

## 画布必须提供的「关键帮助」（验收方向）

对 Grok / Codex 按剧本生图，画布侧目标是 **可机械 + 可人审** 地稳住：

1. **角色一致性** — 权威图 / BindingSet / controlRefs / 身份漂移门；禁止 silent text-only 顶替已知资产  
2. **场景一致性** — 场景锁、连续性格、跨单元场景回指  
3. **站位 / 构图 / 空间一致性** — 连续性格、宫格序、运镜与时间轴；前后镜可追溯  
4. **未点名但同级的一致性** — 道具、光色、风格锁、15s 单元节拍、打断格/破格规则等  
5. **生产辅助** — 冻结包可复现、写租约单写者、earliest 人机同下一步、六图闸、unknown 只对账禁重派、一致性四态辅助 Review（机器不自动 PASS）

**互补完成态（远期）**：代理几乎不必在画布外另建平行事实源；剧本→单元→绑定→冻结→生图→写回→审片 全在受管工程闭环，且视觉一致性可审计。

### 剧本驱动产品环（owner 2026-07-23 增补 · 与 L4 同级）

4. **15 秒分镜设计** — 从剧本到 15s×2–6 格建议→物化 unit→接生图

## 表述防火墙（防假契合）

| 可以说 | 禁止说 |
|--------|--------|
| formal 有序链 PASS / 某单元证据齐 | 「已与无限画布产品 100% 完美契合」 |
| 某一致性辅助已落地、可复验 | 「角色/场景/站位已完全解决」 |
| 契合度分数段 + 缺口清单 | 把 MCP 工具数或单元数当成契合完成 |

**有序链 PASS ≠ 产品完美契合。** 北星是双轨收敛，不是单轨刷绿。

## Goal 完成门（整目标；未齐不得 completed）

同时满足才可 `update_goal(completed=true)`：

1. **产线**：用户点名集/单元关账（或书面降级），formal 证据 + 关键检齐  
2. **辅助**：角色/场景/站位（及登记的其它一致性）在隔离工程上有 **可演示的辅助路径** + 真实验证  
3. **互补**：至少一轮「画布辅助直接约束了一次真实 Grok/Codex 生图」的闭环证据（非空壳文档）  
4. 红线未破；未写禁写工程 PASS  

切片完成只更新 STATUS/TASKS + `update_goal(message=…)`。

## 每轮执行默认策略

1. 读 `STATUS.md` earliest  
2. **优先** 推 earliest 产线一步（A 轨）  
3. 若本步暴露画布缺口（卡 WAL、无租约、一致性盲区、审片不同步、controlRefs 弱）→ **同会话 B 轨修/落** 再回 earliest  
4. 更新磁盘；禁止只聊天总结
