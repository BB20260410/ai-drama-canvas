## 数据与求值合同

`EditKeyframe` 新增可选 `bezier`，未升级 `EditProject.schemaVersion`，旧项目缺省 easing 仍规范化为 `linear`。

| easing | 公式 / 语义 |
| --- | --- |
| `linear` | `p` |
| `ease_in` | `p²` |
| `ease_out` | `1-(1-p)²` |
| `ease_in_out` | `p²(3-2p)` |
| `hold` | 到目标帧前保持 0 |
| `cubic_bezier` | 先解 x 参数，再求 y；目标关键帧持有控制点 |

核心拒绝缺失控制点、非有限值、越界值、非 custom easing 携带休眠控制点、超过 200 个关键帧、重复 ID、量化到同一帧、变换越界和主画面轨道无法兑现的动画。time=0 的真实关键帧替换静态基值，预览与渲染不再分叉。

## 核心、持久化与编辑安全

- `src/core/keyframe-curve.ts` 是预览和渲染的共享曲线定义；
- `src/core/editor.ts` 在保存前规范化六位小数控制点，关键帧 frame 仍按项目有理时间基量化；
- `saveEditProject`、`applyEditOperation(update_clip)`、undo/redo 继续保存完整工程快照，过期 revision 仍拒绝；
- 主画面轨道尚未接入逐片段变换渲染，因此核心明确拒绝主轨关键帧，避免“可保存但成片忽略”；
- 任意区间的曲线重参数化尚未实现；带关键帧片段只能在已有关键帧边界分割或裁切，避免静默改变动画。
