# 产品计划 · 剧本库 + 阅读 + 图文对照 + 15 秒分镜（2026-07-23）

> owner 想法：**已有大量剧本** → 无限画布增加  
> ① **存放剧本** ② **阅读剧本** ③ **一键看到剧本对应哪些图** ④ **对剧本做 15 秒分镜设计**  
> 本文件 = 分析结论 + 可执行分阶段计划；纳入 `/goal` 北星与长期羁绊（**L4 产品 UX 核心包**）。  
> 进度镜像：`STATUS.md` / `TASKS.md`。formal 产线 PASS ≠ 本产品包完成。

---

## 1. 想法拆解（你要什么）

| 能力 | 用户语言 | 产品含义 |
|------|----------|----------|
| **存** | 存放很多剧本 | 受管工程内剧本库：导入/登记/修订/版本，不散落在 Downloads |
| **读** | 阅读剧本 | 桌面可读视图（章节/场/单元导航），不是只 dump JSON |
| **对照** | 一键自动：剧本对应哪些图 | 剧本 span / 单元 / 宫格 ↔ raw·labeled·媒体 的 **只读投影**；一点开就看见「这段文配了哪些图」 |
| **拆** | 15 秒分镜设计 | 从剧本文档 → 建议/物化 15s×2–6 格单元（景别/运镜/对白/资产线索），可审可改再冻结生图 |

四者串成主路径：

```
剧本入库 → 阅读定位 → 15s 拆格设计 → 绑定资产 → 冻结生图 → 图文对照回读
```

这与「生图×画布羁绊」一致：画布成为 **剧本驱动的生产 OS**，而不只是 CAS 账本。

## 2. 现状盘点（已有 vs 缺口）

### 2.1 已有（可复用，禁止重建平行系统）

| 能力 | 位置 | 说明 |
|------|------|------|
| 剧本文档 + revision CAS | `create_studio_script_document` / append revision / list | 合同层「存」已有 |
| 15s 拆格建议 | MCP **`suggest_studio_storyboard_draft`（P20）** | 严格 15s、2–6 格；extension 规则已定 |
| 生产单元 | `create_studio_production_unit` + scriptRevisionId + panels | 分镜物化入口 |
| 图文追溯 | **`get_studio_trace`** `script-revision-impact` / by-pack | 反查 revision→单元→包→结果 |
| 单元快照 | `get_studio_production_unit_snapshot`（可历史 unitRevision） | 读当时绑定 |
| 驾驶舱 | `get_studio_production_dashboard` | 集进度只读 |
| 小说→15s 改编链 | novel-analysis / adaptation / fusion 分镜 | 偏「分析合同」，非导演阅读台 |
| 外部只读剧本包 | 如 `SOURCE_SCRIPT_READONLY/episodes/*.md` | 产线事实剧本，**未**产品化为库 UI |

### 2.2 缺口（产品层，才是你感受到的「没有」）

| 缺口 | 表现 |
|------|------|
| **剧本库工作台** | 无「我的剧本」列表/导入向导/标签/集季；多剧本并存难浏览 |
| **阅读体验** | 无舒适阅读布局、场导航、与当前 earliest 单元高亮联动 |
| **一键图文对照** | 有 trace/API，无「点某段剧本 → 右侧缩略图墙」的一键产品面；代理外也难用 |
| **一键 15s 设计闭环** | `suggest_*` 只读建议；**未**串成「建议→人工改→一键创建 unit→进生图队列」向导 |
| **多剧本×多图批量映射** | 缺「整集剧本 vs 已有 media」对照报告（哪些段有图/缺图/stale） |
| **导入你已有的大量 md 剧本** | 缺批量导入 + 去重 + 与 episode/sequence 对齐策略 |

**结论：** 合同与 MCP **半齐**；缺的是 **导演向产品环**（存-读-对照-拆 一条龙）。实现策略 = **投影 + 向导叠在既有 owner 上**，禁止新造平行剧本 DB。

## 3. 目标架构（事实源不变）

```
文件系统 / 剧本 revision CAS  ──┐
生产单元 / Binding / 冻结包     ├──►  剧本库·阅读·对照·拆格「投影层」（UI + 只读 MCP 聚合）
结果 raw/labeled / Review       ──┘
                │
                ▼ 写入仍只走 execute_command + 写租约
```

- **读**：可聚合 `list_script_*` + dashboard + trace + media 缩略  
- **写**：创建 revision / 物化 unit / 冻结 — 仍 CAS + 租约  
- UI **禁止**自建 nextAction；earliest 仍 Core 投影

## 4. 分阶段计划（S-Script Library · SSL）

### SSL-0 · 合同对齐与索引（1 切片，先于 UI）

| 项 | 验收 |
|----|------|
| 盘点每工程剧本 document 列表 API/缺口 | 文档 + 若缺则最小 list/get |
| 定义 **ScriptLibraryIndex** 投影（只读）：documentId、title、revisions、linked unitCount、coveredMediaCount | JSON schema + 单测 |
| 定义 **ScriptSpanMediaMap**：scriptRevisionId + span → unitId/panel/raw/labeled SHA 列表 | 纯函数/查询 + 单测 |
| 批量导入策略草案 | 外部 md → script document；不覆盖用户权威只读目录 |

**不做：** 大 UI；不写正式工程。

### SSL-1 · 存放 + 导入（库）

| 项 | 验收 |
|----|------|
| 导入：选文件/文件夹 md/txt → 创建 script document + rev0 | 隔离工程可复验 |
| 列表：标题、更新时间、关联集/单元数 | MCP 或桌面列表 |
| 修订：append revision CAS | 旧 revision 可 trace |
| 保护：不回写 `SOURCE_SCRIPT_READONLY` 用户权威包（只读引用或复制入库） | 红线测试 |

### SSL-2 · 阅读（读）

| 项 | 验收 |
|----|------|
| 阅读视图：正文 + 章节/场跳转 | 桌面可读 |
| 与 production unit 高亮：当前 earliest 单元对应 span 标记 | 与 `get_studio_episode_earliest` 同源 |
| 只读；编辑走「新 revision」明确动作 | 无静默覆盖 |

### SSL-3 · 一键图文对照（核心产品点）

| 项 | 验收 |
|----|------|
| **一键**：打开剧本 revision → 展示「段落/单元 → 缩略图」 | 无图段显示「缺图」 |
| 数据来自 ScriptSpanMediaMap + media 代理缩略 | 不扫全盘 DOM |
| 点击图 → 打开 unit/pack/run 诊断（trace） | 可点穿 |
| 导出对照报告 JSON（缺图清单） | 给代理/人工补产 |
| 与六图闸/Review 状态角标 | 可选 P1 |

**验收金句：** 不打开 SQLite、不手翻 quarantine，**一点**就知道这段剧本有没有图、是哪张。

### SSL-4 · 15 秒分镜设计（拆）

| 项 | 验收 |
|----|------|
| 向导：选剧本 revision（或选中 span）→ 调 `suggest_studio_storyboard_draft` | 返回 15s 2–6 格建议 |
| 人工可改格：时长/景别/运镜/对白/资产线索 | 建议不自动变正式 |
| **一键物化**：create unit + panels + scriptRevision 锚定 | CAS 可追溯 |
| 接生图：readiness →（已有）freeze 链；不跳过 Binding | 与 mcp-only 对齐 |
| extension 格规则保持 P20 | 不锚原文冒充原镜 |

**验收金句：** 从「一篇剧本文档」到「可冻结的 15s 单元」**不靠手写 uNN-run 脚本**。

### SSL-5 · 与生图羁绊闭环

| 项 | 验收 |
|----|------|
| 对照页「缺图」→ 一键对该 unit earliest 生图 | 带租约。2026-08-26：只读计划 MCP `ssl5-missing-to-gen-plan` + 对照横幅 + create-plan 只读草稿已落地；已取回的 `revisionImpact` 可传入（省略不自动查）；create-plan/dispatch 写路径对同一 hint unexpected 失败关闭；readiness/plan 只读 next 对同一 hint unexpected 改 Review；2026-08-27：向导 Core 物化按规范资产真实 category/name 落盘（不再一律 character）；歧义未裁决禁止物化（须显式选用/排除）；**不**自动 dispatch |
| bond-loop：拆格建议字段进入冻结提示词可审计 | 证据 JSON |
| 多剧本库不影响写租约/单主写 | 回归 |

### SSL-6 · 成型关账（本产品包）

| 项 | 验收 |
|----|------|
| 存/读/对照/拆 四条路径各至少 1 次隔离工程真实验证 | 报告 |
| 关键路径无阻塞级 BUG | 清单清空或降级 |
| 表述：产品包 PASS ≠ 整 Goal L5；≠ formal 全集绿 | 防火墙 |

## 6. 风险与纪律

| 风险 | 对策 |
|------|------|
| 新建平行「剧本 JSON 库」 | 禁止；revision CAS + 投影 |
| 一键拆格静默选资产 | 歧义停手；与 Binding 合同一致 |
| 把 suggest 当已冻结 | 建议态 ≠ generation-ready |
| 大剧本文本进 MCP 上下文爆炸 | 分页 section；不一次吐全书 |
| 与正式 codex 工程混淆 | 默认隔离工程；禁写 PASS 工程 |
| 夸大完成 | SSL-6 单独验收；不写 100% 契合 |
