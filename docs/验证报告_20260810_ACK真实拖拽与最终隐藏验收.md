## 截图报错的原因与修复

用户截图显示：

```text
Uncaught Exception: TypeError: Object has been destroyed
at BrowserWindow.<anonymous> (.../out/main/index.js:105988:70)
```

精确根因是 BrowserWindow 的 `closed` 回调执行时窗口对象已经销毁，旧代码仍读取 `currentWindow.webContents.id`。这不是图片、视频、音频文件损坏，也不是 Finder 拖出复制语义错误。

修复方式：

- 在窗口仍存活时捕获 `webContents` handle 和 id。
- close request 的 pending 身份、延迟发送与 `closed` 清理都使用捕获值。
- `closed` 回调不再访问已销毁的 BrowserWindow。

同一轮还修复了 ReviewStudio ACK 竞态：不再在 BrowserWindow `close` 同步栈内立即发送 renderer 请求，而是在下一事件循环发送，并复核 requestId、窗口和 webContents 仍为当前 pending 身份。
