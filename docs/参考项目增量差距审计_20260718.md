## 4. 分项要点

### 4.1 ArcReel — LICENSE_BLOCKED

- **参考**：Agent 小说→成片、多供应商、队列、Web UI。  
- **本库对应**：`studio-generation*`、Binding、continuity、dashboard 已覆盖身份/冻结/回写。  
- **缺口**：云端一键流水线产品壳。  
- **风险**：AGPL 网络义务；HTTP 适配不自动消除义务。  
- **建议**：不并入；仅作流程研究。

### 4.2 Toonflow — LICENSE_BLOCKED（补充协议）

- GitHub SPDX 显示 Apache-2.0，但 LICENSE **补充协议**要求向 ≥2 独立第三方以产品分发时书面商业授权。  
- 「无限画布」为另一套事实源/桌面产品，**不得**建立第二真源。  
- 本库 P8 驾驶舱已 PASS，≠ 复制其 UI。

### 4.3 Huobao — LICENSE_BLOCKED

- README 标明 CC BY-NC-SA 4.0。  
- 宫格/多厂商/自动成片属产品层重叠，**无**可进核心源码。

### 4.4 BigBanana — LICENSE_BLOCKED

- BigBanana Community License 1.0：非商用、禁 SaaS/OEM/商业生产。  
- Script-to-Asset-to-Keyframe 叙事与 BindingSet 目标对齐，但**实现不可搬**。

### 4.5 tldraw — RESEARCH_ONLY

- 生产环境无商业协议禁止；含 license key。  
- 仅借鉴视口/分页/LOD 需求（已有 `canvas-scale-performance` skill）。  
- **禁止**复制 SDK 作为 Studio 权威画布。

### 4.6 Kitsu / Zou — ADAPTER_ONLY / DEFERRED

- 2026-07-13 审计已落地本地审片批注。  
- 完整服务 = 第二事实源 + AGPL。  
- 多人协作场景未出现前不接。

### 4.7 ComfyUI — ADAPTER_ONLY + ALREADY_IMPLEMENTED

- 已有 `comfyui-local` 本机适配器。  
- 正式生图面为 **agent-imagegen（Codex/Grok）**，Comfy 非正式主链。  
- GPL 禁止源码并入。

### 4.8 StoryToolkitAI — DEFERRED

- 成片转写/语义检索，偏离 15s 单元 CAS 生产主路径。  
- GPL。

### 4.9 Storyboarder — RESEARCH_ONLY / NOT_NEEDED

- 手绘分镜；与 AI CAS 短剧目标弱相关。  
- 禁止复制源码。

1. **哪些能力本项目已实现？**  
   CAS/Authority、BindingSet、连续性 Review、freeze-dispatch-register、raw/labeled 合同、驾驶舱、备份 v2、build-identity、Comfy 适配器、审片坐标批注。

   多云供应商一键流水线 UI（ArcReel/Toonflow/Huobao）；多人制片协作（Kitsu）；画布 SDK（tldraw，但许可挡生产）；节点扩散生态（ComfyUI，已适配）。

3. **哪些只是界面不同？**  
   「无限画布」营销表述、各短剧 Web 控制台布局、手绘分镜 UI。

4. **哪些会建第二事实源？**  
   嵌入 Kitsu/Zou DB、并入 ArcReel/Toonflow/Huobao 工程库、tldraw 文档当真源。

5. **哪些值得独立适配器？**  
   ComfyUI（已有）；未来可选 Kitsu 单向预览；ArcReel 仅独立服务讨论。

   「先锁角色设计再分镜」需求已对齐 Binding/Authority；无可许可证安全的可搬实现。

7. **哪些不必继续研究？**  
   Storyboarder、StoryToolkitAI（当前目标）、Huobao/BigBanana 作为源码来源。

8. **下一唯一最高优先级？**  
   **Electron 驾驶舱 + 大规模数据 cold start / 翻页 / 切工程 smoke + 截图证据**；或 **P9 command-bus 全写入口故障矩阵**（扩展 `studio-reliability` / command-bus，不重建 P8）。
