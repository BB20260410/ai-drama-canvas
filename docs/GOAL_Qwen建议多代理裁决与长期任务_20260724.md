## 1. 总判决（一句话）

Qwen 的诊断在 **「上帝组件 + 核心巨文件 + 缺全局快捷键」** 上 **基本属实**；在 **「先 ESLint/Pinia/router/拆 command-bus 再谈产品」** 的排序上 **与本仓合同和北星冲突，不可原样采纳**。

本仓应走：

```
A 轨 formal（U19–U25）+ 单元复盘闸
    │ 同会话卡点
    ├─ B 轨：一致性四态 / controlRefs / 场景站位
    ├─ SSL：剧本存读对照 15s（产品主价值）
    └─ 工程/前端：壳层增量（composable、列表虚拟化、受闸快捷键）— 永不压过 formal
```

## 2. 事实校验（Qwen 评分 vs 实况）

| Qwen 说法 | 实况 | 判定 |
|-----------|------|------|
| 上帝组件 8 个千行+ | ManagedStudioCanvas **~3930**、MaterialStudio **~2497**、App **~1914** 等 | **对**（且画布比旧表更胖） |
| command-bus / ledger 过大 | bus **~3568**、ledger **~7848**、generation **~4845**、types **~2689** | **对** |
| 无 ESLint/Prettier/CI | package 无 eslint/prettier/husky；无 `.github` | **对** |
| 脚本 211 平铺 | **~213** 脚本，含 s1e2/validate/smoke | **对数量**；**错**当「脏代码」——大量是产线证据链 |
| 无 pinia/router/composables | **均无**；有手写 dashboard-store 等 | **对** |
| 缺 debounce | 布局 450ms、投影 200ms 单飞、搜索 debounce **已有** | **偏/过时** |
| 缺虚拟滚动 | 画布 **视口剔除+分页**；侧栏列表弱 | **偏** |
| 核心数据安全一流 | 幂等 bus+CAS+账本 | **同意** |
| 工程化 2/10 | typecheck+223 tests+validate 关账 | **过贬**——缺的是 lint 套件，不是质量真空 |

## 3. 分项裁决

### 3.1 必须拒绝 / 延后

| 建议 | 裁决 | 原因 |
|------|------|------|
| 拆 `command-bus` / `studio-generation-ledger` 写路径（阶段 3 主线） | **拒绝（产线窗口）** | 关账 owner；拆错 = 重建写合同 |
| Pinia 持有 nextAction / 工作流真相 | **拒绝** | UI 不得推导 nextAction |
| vue-router 做生产主轴 | **拒绝** | 活动工程/MCP 上下文是正式导航 |
| 通用插件系统 / 插件市场 | **拒绝** | 扩展面 = MCP + Skill，已存在 |
| 跨平台 + electron-updater 进当前 Goal | **延后** | local-only mac；偏离北星 |
| husky 默认拦截 commit + 全量 test | **拒绝** | 摩擦产线；git 纪律另有红线 |
| 脚本物理重组 rename | **拒绝** | 绑定证据路径，回归成本高 |
| coverage 徽章当 KPI | **拒绝** | 与 formal≠契合同构 |
| 主题系统重做 | **拒绝** | P25 已有 light/dark/paper |
| 开放 imagegen 供应商插件化 | **拒绝** | 正式面 codex\|grok 闭集 |

### 3.2 改写后采纳（高价值）

| 建议 | 改写为 | 优先级 |
|------|--------|--------|
| ESLint | **极薄**、先 renderer、不阻断 formal | L5 空窗 |
| 拆 App / 画布 God Component | **composable 抽展示/会话**；props/emits 不变；不碰 envelope | 改画布文件时顺带 |
| 虚拟滚动 | **侧栏/列表** 增强；画布沿用剔除+分页 | 规模体验 |
| 快捷键 | **受闸注册表** + earliest/审片/对照 | 并入 SSL-2 / L4 |
| Command Palette | **导演动作定位面板**（打开 earliest/trace/缺图），非任意 execute | L4 |
| 批量审片 | 并入 Review/六图闸，**不新账本** | L4 |
| Markdown 编辑 | **SSL-1/2 revision CAS**，禁静默覆盖权威只读源 | SSL |
| 导出 | **SSL-3 缺图对照报告** | SSL-3 |
| debounce | 已有则 **补缺口列表**，不重做落盘语义 | 低 |
| 拆 command-bus | 仅 **handler 注册表物理搬家** 且在 S1E2 稳定后；写路径最后 | 远期 |
| 供应商 registry | 旧 generation 队列可策略化；**正式面不开放** | 远期 |

### 3.3 直接对齐北星（应优先于 Qwen 阶段 1–3）

| 项 | 来源 |
|----|------|
| A 轨 U19–U25 formal + 单元复盘闸 | 现 STATUS |
| B 轨 controlRefs / 四态 / 场景站位 | 羁绊 L3 |
| SSL-0→3 剧本对照（一键图文） | 剧本库计划 + owner 痛点 |
| SSL-4 15s 向导减半旁路 create | 剧本库计划 |
| mcp-only + 写租约默认 | 已部分落地 |

## 6. 执行纪律（写进 Goal）

1. **A 轨 earliest 不被工程化插队。**

3. 产品功能优先问：是否服务 **角色/场景/站位** 或 **剧本存读对照 15s**？否 → 后置。  
4. formal PASS、lint 绿、coverage 数字 **均 ≠** 产品契合 / L5 completed。  
5. 本裁决落盘后，以 `STATUS.md` / `TASKS.md` 勾选推进；不另开平行「Qwen 工程化 Goal」。
