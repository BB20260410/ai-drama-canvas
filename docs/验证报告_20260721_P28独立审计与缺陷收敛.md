### Core、SQLite、CAS、备份

- `project-backup.ts`：no-follow 稳定哈希、唯一 staging、原子恢复、失败现场保留。
- `material-studio.ts`：未来 schema 写前拒绝、CAS 目录链接/逃逸保护。

- `studio-consistency-evaluator.ts`：实物 SHA、realpath/symlink、缓存与并发资源约束。
- `studio-media-protocol.ts`：SQLite WAL/SHM 消失竞态只对精确“伴随文件缺失”容错，链接和逃逸继续失败关闭。

- renderer 导航从“localhost”收紧为精确开发 origin 或安装 bundle entry。
- `aicanvas-asset` 使用规范路径、媒体白名单、同句柄读；旧根缓存随注册表 revision 失效。
- shell open/reveal 拒绝链接和非白名单目标。
- watcher 与 renderer 异步请求增加 sequence、projectId/root、mounted 守卫。
- MCP 响应路径脱敏，trace selector 改严格判别联合。
