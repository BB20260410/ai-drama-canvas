# 参考项目与小云雀界面对表实施（P15）

> 日期：2026-07-19  
> 结论：**已完成 clean-room 交互对表；没有复制第三方源码、品牌素材或私有接口。**

## 1. 用户可见终态

画布前台只保留四个主要入口：

1. **添加**：选择角色、场景、道具、剧本、提示词或 15 秒分镜；
2. **素材库**：按类别搜索并把素材放到当前工作区；
3. **连线**：拖动连接点，或依次点击输入节点与目标宫格；
4. **开始**：后台重新核验正式 BindingSet、连续性和冻结包，再派发给 Codex。

素材库默认收起，节点详情只在选中时打开；项目统计、内部 ID、revision、SHA、命令和诊断信息均收进折叠区。底部只保留适配、隐藏连线、隐藏小地图、查看全部/回到工作流和清空工作区等视图动作。

## 2. 与小云雀 / Pippit 的界面对表

| 小云雀式体验 | 本项目实现 | 安全差异 |
|---|---|---|
| 中央无限画布 | Vue Flow 自由拖拽、缩放、框选、视口剔除 | 画布只是投影，不是数据真源 |
| 左侧添加工具 | “添加 / 素材库 / 连线 / 帮助”浮动工具 | 素材来自受管资产库 |
| 主动作突出 | 顶部金色“开始” | 开始前由正式 owner 重新预检 |
| 节点连接输入 | 角色、场景、道具、剧本、提示词可连到宫格 | 草稿线不能越权改 BindingSet |
| 结果接在流程后 | 宫格 → raw → labeled → 审片 | 没有真实回图时只显示等待，不伪造结果 |
| 次要设置收起 | 高级操作、诊断详情、项目统计默认弱化 | 技术字段仍可在诊断区追溯 |

本项目没有照抄小云雀的像素、图标、文案或品牌，只对表“少入口、中央画布、节点连接、一个主动作、结果就地回流”的操作模型。

## 4. 后台真实执行链

```text
画布节点/草稿连线
→ 一次性预检全部目标宫格
→ 对照正式 BindingSet（必须精确一致）
→ 由既有 owner 重建冻结包
→ provider=codex 派发
→ Agent 单图生成
→ 原子写回 raw/labeled
→ 用户审片
```

任何宫格出现资产、剧本、提示词、项目 token、构建身份或冻结包漂移，整次“开始”在产生副作用前失败关闭。画布草稿不会静默成为正式绑定。

## 5. 规模边界

- 当前画布一次最多投影：6 资产、36 单元、6 宫格、18 个结果/审片节点、8 份文稿；总 DOM 硬上限 74。
- 素材媒体每页最多 36 项，滚动不累加旧页。
- 固定资产恢复走最多 6 个主键精确查询；不会因素材库切换类别而丢失已钉角色、场景或道具。
- 1288 单元 / 4235 宫格 / 77 资产 / 10000 媒体安装版烟测已通过。

## 6. 明确边界

- “开始”在本轮验收中只验证到**正式冻结与 Codex 派发**；未消耗额度生成图片。
- 没有 Agent 在线消费队列时，任务会保持已派发/等待回图，不会伪造 raw、labeled 或视觉通过。
- 未调用浏览器供应商、Grok、上传、付费、发布或自动更新。
- 未执行 Git stage、commit、push 或 PR。
