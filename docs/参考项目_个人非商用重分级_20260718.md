# 参考项目 · 个人非商用重分级（2026-07-18）

> 用户声明：**个人使用，非商用**。本文件修正此前审计中「一律不得复制/落地」的过严结论。  
> 仍遵守：不建第二事实源、不覆盖 final-validation、优先 clean-room 扩展既有 owner。

## 政策

| 原则 | 说明 |
|------|------|
| 个人非商用 | 可更积极地**研究、借鉴、落地需求与交互**；部分许可证明确允许个人学习/修改 |
| 仍优先 clean-room | 不把第三方 monorepo 整库并入本仓库；避免第二 SQLite 真源 |
| 若日后商用 | 必须重新跑许可证审计；BigBanana/Huobao NC、Toonflow 补充协议、tldraw 生产限制会重新生效 |
| AGPL/GPL | 个人本机**独立运行**可；**整段源码并入本桌面应用**仍不推荐（日后分发会感染） |
