P7 已完成并通过完整纵向验收。软件现在以逐宫格或逐原镜的半开时间跨度保存服装、伤势、持物、位置、朝向、情绪、布局、光线和参考 SHA 九项连续性事实；跨度之间的空档不会自动补齐，未知值必须显式保持 `unresolved` 或 `not-applicable`。连续性 observation、correction、冲突、Review 和六图停检均使用追加历史、Head CAS、内容寻址身份和可恢复 operation receipt。

生成闭包已经升级为 v4：每个允许出画资产都必须在目标宫格的九字段连续性上 ready；可显式引用同集相邻上一格、当前仍通过 Review 的 raw 结果；身份与连续性参考合计仍不得超过 6 项。每完成 6 个唯一生产槽必须通过内容寻址一致性停检，第 7 个新槽的真实 dispatch 会失败关闭且不写 dispatch 行。

## 2. 九字段连续性与冲突账本

- 固定字段为 `costume / injury / heldObject / position / facing / emotion / layout / lighting / referenceSha256`。
- scope 支持逐宫格与逐原镜，时间范围使用 `[startMilliseconds, endMilliseconds)` 半开区间。
- 不连续跨度按证据逐段保存；查询命中空档时返回缺口，不使用最早/最晚值填满中间范围。
- observation 与 correction 只追加，Head 使用 expected revision CAS；同 operationId 异载荷被拒。
- 冲突保持可查询历史；只有显式 correction 才能解决指定冲突，陈旧修正不会移动当前 Head。
- 提交前故障整体回滚；业务 receipt 已提交但调用方未收到响应时，可在重启后仅凭 receipt 恢复，不重放写入。

## 3. 生成闭包、上一格 raw 与 schema 演进

- 新冻结包和生成请求只允许 schema v4；历史 v3 可以读取，但不能继续 dispatch、登记结果或提升。
- 每个 allowed 资产必须拥有与当前 unit、panel、秒段和 Authority SHA 一致的九字段 readiness fingerprint。
- generation pack、request、参考依赖和结果全部冻结 continuity fingerprint；任一依赖漂移会使输入过期。
- `previousApprovedRawReviewId` 只接受同集真实相邻上一格、当前 pack 的 raw/labeled 对、当前 pass Review 与实际媒体 SHA。
- 上一格 raw 进入 `continuity-frame`，与身份参考合计最多 6 项；不会静默丢弃或把路径当权威。
- 未解决连续性缺口、冲突、旧 schema 或未通过六图停检时，真实 dispatch 失败关闭。

## 4. Review 与六图一致性停检

- Review observation/correction 绑定真实 generation run、raw/labeled 结果、文件 SHA、冻结 pack fingerprint 和 pack 内实际 continuity fingerprint。
- 调用方伪造 continuity fingerprint 时零 Head 写入；陈旧 Review 只追加历史，不改写 CanonicalAsset、AssetBindingSet、剧本或 generation pack。
- 每个 checkpoint 以 `unitId + panelId` 作为唯一生产槽；raw/labeled 配对只计 1 张生产图，同槽返工不伪增计数。
- 6 个槽形成内容寻址 checkpoint snapshot；必须显式 attest 为 `pass` 或 `rework`。
- Review correction 会使引用旧 Review Head 的 checkpoint/attestation 过期；重新 refresh/attest 后才可继续。
- 第 7 个新槽真实 dispatch 被拒且零写入；已有槽返工与同一不可变 dispatch 幂等回放仍允许。
- refresh/attest 的命令在模拟“业务已提交、命令回写前崩溃”后可凭不可变业务 receipt 恢复。

## 5. Core、命令总线、MCP 与桌面端

- 五条写操作只通过统一 `execute_command`：追加连续性 observation、追加 correction、提交 generation Review、刷新 checkpoint、提交 checkpoint attestation。
- public payload 不暴露 operationId、headKey、receiptId 或 request fingerprint；命令总线使用 request hash 形成内部幂等身份。
- Electron 强制 `reviewer=user`；MCP 强制 `reviewer=codex`。
- 新增只读 MCP `get_studio_continuity_review_control`；compiled MCP 精确为 181 tools，没有暴露五条具名写工具。
- Material Studio 新增惰性“连续性 / Review”页，直接显示 Core 的九字段 readiness、开放冲突、Review、六图 checkpoint 和唯一下一动作。
- 空工程或伪 unit 明确返回 generation blocked；只有真实已绑定且九字段 ready 的宫格才显示 `freeze-generation-pack`。
- UI 返回窗口有界；数据库级连续性 keyset 分页下推仍属于 P9 规模整改，P7 没有把前端切片冒充底层全量不载入。
