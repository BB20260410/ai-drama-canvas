## 漏检发现与修正

第一次 P2 final-validation 虽然内部自洽，却只检查了
`semanticAssets ↔ referenceSlots`，没有反查当前宫格合同。独立只读复核发现
`EP01_008` 宫格 03–06 的合同均显式携带 P01
`continuityReferenceAssetIds`，旧 resolution 却只有 C01/C02，P01 既未进入语义资产和
引用槽，也没有排除记录；四格仍被错误标成 `generationReady=true`。

修正后：

- `panel.continuityReferenceAssetIds` 被纳入解析基集合，并拥有独立 provenance 和调和记录。
- parser reconciliation 不得再排除宫格合同显式连续性参考。
- 核心审计与 final validator 都反向验证：
  `(panel.assetIds - excludedAssets) ⊆ semanticAssets`，以及
  `panel.continuityReferenceAssetIds ⊆ semanticAssets`。
- 允许连续性轨带来的 1306 个合法额外语义绑定，不错误要求两个集合完全相等。
- 旧 store 因缺少 `contractCoverageVersion` 自动进入
  `current=false / resolver-contract-coverage`，不能继续被生图或分页接口使用。
- EP01_008 宫格 03–06 现在均持有 P01 semantic asset、canonical slot 和正式硬锁 SHA
  `907e96df267d3520c302ea2dad36afa5f6c42181f28492bd35a22450e5ad70a5`。

因此，未带 `corrected` 的第一次 P2 final、迁移、MCP 和 UI 文件只保留为历史缺陷证据，
不能再作为 P2 完成依据；本报告只引用下方 corrected 证据。
