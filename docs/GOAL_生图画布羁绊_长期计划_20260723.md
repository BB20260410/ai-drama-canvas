## 1. owner 终局（唯一理解锚）

| 维度 | 终局 |
|------|------|
| 谁出图 | Grok 与 Codex（隔离/正式以 STATUS 为准）按**剧本**出图 |
| 画布是什么 | 不是旁路账本，而是生图 **关键辅助 OS**：角色/场景/站位/道具/光色/风格/节拍一致性 + 冻结/租约/审片/earliest |
| 互补 | 代理主要靠画布合同完成出图，不必另起平行事实源 |
| 产品 | **功能齐全、关键路径无 BUG、可演示成型**（桌面+MCP 同真相） |
| 非目标 | 刷绿单元数、工具数、空壳文档关账 |

## 2. 阶段定义（L0–L5）

| 层 | 名称 | 完成判据（全真才勾） |
|----|------|----------------------|
| **L0** | 续跑 OS | Stop 闸 + durable scheduler + STATUS/TASKS + 禁止假 completed；本层已基本具备 |
| **L1** | 唯一写入口 | require 写租约 + MCP 单主写 + 产线走 mcp-only/command-bus；半旁路标注为过渡 |
| **L2** | 剧本有序产线 | S1E2 U01–U25 formal 有序链 + 六图闸 + 关键 Review；隔离工程证据齐 |
| **L3** | 一致性辅助可演示 | 角色/场景/站位（+同级）各有 **可复验路径**：controlRefs/Binding/连续性/一致性四态 至少一轮「约束了真实生图」证据 |
| **L4** | 产品 UX 成型 | 审片台与 earliest 同真相；拖入拖出可用；Commit 不因 WAL/token 常规卡死；桌面与 MCP 同工程 |
| **L5** | 羁绊关账 | L2–L4 齐 + 缺口清单清空或书面降级 + 无挂起可自动下一步；才可 `update_goal(completed)` |

**当前基线（2026-07-23）**

- L1：合同已落，产线切换 mcp-only 进行中  
- L2：U01–U14 formal；U15 bind；欠 U15–U25  
- L3–L5：未关账

## 3. 每轮硬协议（做完一步 → 分析下一步）

```
1. 读 STATUS earliest + 本计划当前层
2. 执行 earliest 一步（优先 A 轨产线；卡点则 B 轨修软件）
3. 真实验证（命令输出 / formal 证据 / 测试）
4. 写 STATUS：最近验证 + earliest 下一步（唯一入口）
5. 勾 TASKS；必要时更新本计划「当前层进度」
6. 分析：本步暴露的产品/一致性缺口是否进入下一步（写进 STATUS，勿只聊天）
7. 若仍有可自动推进项 → 立刻工具继续；禁止只列清单收尾
8. 仅 L5 全真 → completed
```
