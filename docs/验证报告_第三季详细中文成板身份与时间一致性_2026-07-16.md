## 1. 解决的问题

### 1.1 布局预览可能被误认成正式成片

新增 `FusionStoryboardSheetRenderPurpose = formal | layout-preview`：

- `formal` 仍只接受同一当前合同下 succeeded、已 Publication、raw/labeled 成对的逐格图；
- `layout-preview` 在表头、每格画面和页脚写入“版式预览·非成片”；
- SVG metadata、返回值和 evidence JSON 同时写入 `formalProductionEligible:false`；
- 正式生产成板函数显式复验 `formal`，preview 不能创建正式 production receipt；
- preview 只写 `docs/evidence`，不写生产单元输出目录。

### 1.2 可见秒数曾出现 15.1s

EP01_008 的三个中间格精确时长约为 1.667 秒。旧显示把三格分别四舍五入为 1.7s，导致可见合计 15.1s，但页脚仍写 15.0s。

新增策略 `one-decimal-boundaries-then-difference-v1`：

- 先把连续边界量化到一位小数；
- 再由相邻可见边界相减得到显示时长；
- EP01_008 六格显示为 `4.0 / 4.0 / 1.7 / 1.6 / 1.7 / 2.0`，合计 15.0s；
- 策略进入合同 payload、sheet 校验、UI 展示和 IPC 幂等键，禁止 command-ledger 回放旧 15.1s 合同。
