## 实施内容

1. 新增默认关闭的 units 请求级阶段探针：
   - 仅在 `AI_CANVAS_T23_PERF_PROBE=1` 且 Dashboard `operation="units"` 时启用。

   - 正常生产请求不创建探针上下文、不读诊断时钟、不附加诊断字段。
2. 为 Main、managed project、generation ledger、production DB、binding owner 与 Dashboard 映射增加匿名阶段/计数接线；原业务并发、顺序、异常和 fingerprint 保持不变。
3. Preload 只接受最新一次 units 请求的有界时间线；新请求先清旧值，最新失败保持空，旧成功不得迟到恢复。
4. T23 在同一 Renderer 文档内原子读取 units 时间线、raw/reference span、IPC 与 UI 快照，并验证 `78 = 6 + 2 × 36` 查询闭包。

   - 运行时仍用完整 URL 完成真实解码；持久证据只保留 unitId、SHA、verification/type 与 `thumbnailAvailable`。
   - 成功和失败报告均使用同一脱敏函数；失败证据不再持久化 page URL、页面正文或原始异常。
