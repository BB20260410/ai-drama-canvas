## 3. 无限画布到底起了多大作用？

| 作用 | 贡献 |
|------|------|
| **事实源 + CAS** | 高：结果可寻址、可重验 |
| **门禁（停检/有序/drift）** | 高：挡过错误与越界 |
| **回写合同** | 中高：raw/labeled 成对 |
| **可视化/驾驶舱** | 低：本任务几乎不用点 UI |
| **MCP 零说明环** | 低–中：脚本等价，非 stdio 主路径 |
| **拖入拖出** | 尚未验收贡献 |

**一句话：** 画布是**制片账本与门禁机**，不是本任务的**无限白板导演台**。没有它，有序链与隔离证据会塌；有它但只走脚本，则「产品闭环」叙事不能写 PASS。
