# 多 Agent 并行协议（Grok / Codex）

> 生效：2026-07-18  
> 决策：**波次 A 强制串行**；仅文件面互斥的任务可并行。  
> 原因：当前仓库几乎全 untracked、无稳定 Git 基线；A1→A5 写面重叠（layout / canvas / command）。硬并行易互踩，合并成本高于串行。

## 选定方案

| 层 | 方案 |
|----|------|
| **默认** | **串行流水线**：STATUS 标明「当前唯一执行者 + 当前切片」；另一 agent **只读**主仓或只做互斥切片 |
| **将来（用户授权首 commit 后）** | 升级为 **Git worktree + 分支**，按切片并行 |
| **不做** | 无 commit 时整树双副本长期双写（合并易丢） |

## 认领规则

1. 开干前读 `STATUS.md`：若 `当前执行者` 不是自己且切片未完成 → **停手**或只改自己认领路径。  
2. 在 `TASKS.md` 写：`@owner` + `in-progress`。  
3. 完成：勾选、写 evidence、更新 STATUS「当前执行者 = 空 / 下一刀」。  
4. **禁止**两人同时改：`docs/当前开发交接.md` 全文、`package-lock.json`、同一 `src/**` 文件。

## 写面互斥表示例

| 切片 | Owner | 允许路径 | 禁止 |
|------|--------|----------|------|
| A1 | Grok | `studio-canvas-layout*.ts`、对应 tests、`docs/evidence/absorb-a1-*` | Vue 画布、dashboard |
| A2 | 下一任 | `ManagedStudioCanvasView.vue`、canvas store 接线 | 改 layout 合同语义（除非修 bug） |
| B2 | 可并行* | dashboard 投影只读字段 | layout-store |

\* 仅当 A 波次无 in-progress 或路径确认无交集。

```text

若 STATUS「当前执行者」不是你且切片未完成：不要改其允许路径；可只读或做 TASKS 中无交集项。
波次 A（A1–A5）串行：A1 完成后才能 A2。
禁 Git stage/commit/push（无用户授权）；禁覆盖 final-validation；禁污染正式空库。
完成：勾选 TASKS、更新 STATUS、写 docs/evidence/absorb-*-*.json。
```

## 合并

- 串行时无「合并」：主仓即真相。  
- 若曾隔离目录干活：只拷贝**文件清单**到主仓，再 typecheck + 相关 vitest。  
- 冲突：业务 CAS/ledger 优先；layout 坐标可丢一方后 autoLayout。
