> 2026-07-28 补充：本报告当时只把 457 个资产实体放入全局画布，用户指出的 549 张版本图片尚未逐张展示。该缺口现已补齐，真实 549 张图片、552 条版本关联和 Electron 证据见 `docs/验证报告_20260728_全剧本549张版本图片进入剧本资源.md`。本报告保留为修改前库存与边界记录。

## 结论

**部分完成。**

无限画布源码端已经提供“当前剧本 / 全部剧本”素材范围切换，可把所有已登记受管剧本中的规范资产统一按人物、场景、道具和风格分页展示。每张卡片显示规范名称和来源剧本；跨剧本详情按来源工程读取，全部剧本模式保持只读。

当前真实注册表已聚合 26 个可读受管工程，共 457 条有名称的规范资产：

- 人物：338
- 场景：65
- 道具：51
- 风格：3
- 空名称：0

尚未把 8,244 张普通图片逐图做视觉多实体分类。这些图片包含分镜、RAW/labeled、生成结果和复合画面；一张图可能同时出现人物、场景和多个道具，因此本次没有按文件名把整图强塞进单一类别。

## 已实现

1. 新增跨剧本只读聚合 Core：
   - 复用完整工程注册表和各工程现有 `material-studio.sqlite`。
   - 不建立第二数据库，不复制原媒体，不扫描原媒体目录。
   - 单页上限 36，使用不透明 keyset cursor。
   - 支持分类、名称、别名、说明和 SHA 搜索。
   - 返回来源剧本、分类计数、图片覆盖率和不可读工程数。

2. 新增桌面端 UI：
   - 人物、场景、道具、风格区显示“当前剧本 / 全部剧本”。
   - 卡片显示名称与来源剧本。
   - 全部剧本详情严格使用来源工程 locator。
   - 缺少来源 locator 时失败关闭，不回退当前工程。
   - 创建、导入、追加版本、Review、Primary 提升、关系写入和跨项目包在全局模式隐藏或禁用，方法层再次拦截。

3. 大规模边界：
   - 每页最多 36 项，翻页替换 DOM。
   - 缩略图继续使用 lazy/async。
   - 列表和详情异步结果绑定 `projectRoot + scope + query fingerprint`，切工程、切范围或改查询后旧响应不能覆盖新状态。
