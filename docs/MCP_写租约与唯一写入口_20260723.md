# MCP 写租约与唯一写入口（2026-07-23）

## 定位

无限画布 MCP = **项目生产 OS + 唯一写入口**（非「谁都能同时操作的远程按钮」）。

```
Codex / Grok / 其他代理
        ↓
  无限画布 MCP（单主写进程守护）
        ↓
写租约（require）→ 资产锁 → 生图账本 → Review → 画布投影
```

**边界：** 有序链 / formal PASS ≠ 与无限画布产品完美契合。

## 1. 强制「无租约不准写」

| 模式 | 环境变量 | 行为 |
|------|----------|------|
| **require**（生产默认） | `AI_CANVAS_WRITE_LEASE_MODE=require` | 生图相关写 **无租约硬失败** `lease-required` |
| compat（测试默认） | `compat` 或 未设且 tests/setup | 无租约放行；**有**租约时挡异主 |
| 关闭 | `AI_CANVAS_DISABLE_WRITE_LEASE=1` | 全关（仅急救/单测） |

MCP server 启动时若未设 mode → 强制 `require`。  
桌面 UI：`execute-studio-command` 对受闸命令 **自动** acquire `desktop-ui-main` 租约。

### 硬闸命令（`STUDIO_WRITE_LEASE_ENFORCED_COMMANDS`）

`freeze/dispatch/prepare/register/commit/rebind/fail/cancel/retry/plan/review/checkpoint refresh|attest/abandon_*`

- 只读永不要求租约  
- 有租约且异主：硬失败 + 中文 `denialHint`

### MCP 工具

| 工具 | 作用 |
|------|------|
| `get_studio_project_write_lease` | 只读投影 |
| `acquire_studio_project_write_lease` | 获取/续租 |
| `heartbeat_studio_project_write_lease` | 续期 |
| `release_studio_project_write_lease` | 释放 |
| `get_studio_generation_unknown_disposition` | 不明态只读；**allowRedispatch 永远 false** |
| `get_studio_episode_earliest` | 人机同一 earliest |

`execute_command` / 命名写工具可选 `writeLeaseHolderId` + `writeLeaseToken`。

## 2. 单 MCP 进程守护

| 项 | 说明 |
|----|------|
| 锁文件 | `~/.aicanvas/mcp-os-writer.lock` |
| 实现 | `src/core/mcp-process-guard.ts` |
| 默认 | MCP 启动时 acquire；他进程存活则 **exit 1** |
| 多开调试 | `AI_CANVAS_MCP_ALLOW_MULTI=1`（桌面内嵌 + 代理并存时） |
| 关闭 | `AI_CANVAS_MCP_SINGLETON=0` |
| 启动 | `npm run mcp:daemon`（require + singleton） |

**写权限仍以写租约为准**；进程守护只防「一机多 MCP 主写」争 WAL。

## 3. 产线收进 MCP-only runner

| 路径 | 用途 |
|------|------|
| **`scripts/s1e2-mcp-only-runner.ts`** | 正式：prepare/commit/attest/earliest/status；freeze/dispatch/prepare/commit 走 **executeIdempotentCommand + 租约** |
| `scripts/s1e2-ordered-runner.ts` | 半旁路兼容；默认也 require 租约 |
| `scripts/s1e2-uNN-run.ts` | **仅** create+bind（非 lease 闸命令） |
| `scripts/s1e2-commit-prepared-state.ts` | state 含 `writeLease` 时走 command-bus；否则 core 半旁路 |

```bash
# 状态 / 租约
npx tsx scripts/s1e2-mcp-only-runner.ts status
npx tsx scripts/s1e2-mcp-only-runner.ts acquire

# unit 已 create+bind 后
npx tsx scripts/s1e2-mcp-only-runner.ts prepare --unit S1E2-U15
# → gen 写入 quarantine →
npx tsx scripts/s1e2-mcp-only-runner.ts commit --state productions/.../05_canvas/_scratch/s1e2-u15-ordered-state.json

npx tsx scripts/s1e2-mcp-only-runner.ts earliest
npx tsx scripts/s1e2-mcp-only-runner.ts attest-batch --batch 2
```

推荐代理顺序：

1. `get_capabilities`  
2. `get_active_managed_studio_context`  
3. `acquire_studio_project_write_lease`  
4. readiness → freeze → dispatch → prepare → 单次生图 → commit（写命令带 lease）  
5. Review / checkpoint  
6. `release_studio_project_write_lease`  

generation_unknown：只对账 / abandon / fail；**禁止 re-dispatch**。

## 核心文件

- `src/core/studio-project-write-lease.ts` — require/compat + assert  
- `src/core/desktop-write-lease.ts` — 桌面自动租约  
- `src/core/mcp-process-guard.ts` — 单主写进程  
- `src/core/command-bus.ts` — 写闸  
- `src/mcp/server.ts` — 工具 + 启动守卫  
- `scripts/s1e2-mcp-only-runner.ts` — 产线 MCP-only  
- `tests/studio-project-write-lease.test.ts`  
- `tests/mcp-process-guard.test.ts`  

## 仍非完美契合（刻意）

- create/bind 仍可半旁路 per-unit  
- 桌面审片 UI 未全量 Vue 工作台  
- 拖入拖出、Commit 向导 UI 未做  
- formal 有序 PASS **不得**写成产品完美契合
