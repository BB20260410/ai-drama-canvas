## 2. 分项

### 2.1 LocalMiniDrama — NET_NEW_HIGH_VALUE（个人首选）

- **License**：[MIT](https://github.com/xuanyustudio/LocalMiniDrama/blob/main/LICENSE)  
- **栈**：Vue3 + Electron + SQLite 本地优先 + **@vue-flow/core**（与本库同代）  
- **画布计划**：[2026-06-15-drama-canvas-workflow-plan.md](https://github.com/xuanyustudio/LocalMiniDrama/blob/main/docs/plans/2026-06-15-drama-canvas-workflow-plan.md)  
  - **真源不变**；`canvas_layout` / `workflow_groups` 仅 metadata  
  - 列表/画布双视图同源  
  - 竖排分镜流水线；框选整组重跑；节点内操作面板  
- **本库对应**：`ManagedStudioCanvasView.vue` + dashboard + Binding；**缺** 生产向「分镜流水线画布」与 workflow 组合同  
- **真实缺口**：视图层布局持久化合同 + 工作流组引用（已用 clean-room 落地合同）  
- **禁止**：整仓复制；把 Vue 节点当 CAS 真源  

### 2.2 Jellyfish — REUSE / RESEARCH

- **Apache-2.0**  
- 镜头准备态：`breakdown → preparation → ready → generation`  
- 本库已有 Binding / continuity readiness / freeze pack  
- **缺口**：更细的「候选确认/忽略」UI 状态机（可扩展 binding workbench，非新库）  

### 2.3 LumenX Studio — RESEARCH_ONLY

- **MIT**（Alibaba）  
- Studio 全流水线 + Playground 独立生图台  
- 与本库 CAS/Review 深度重叠；价值在产品壳与多模型 catalog  
- **不**替换 agent-imagegen 正式面  

### 2.4 TwitCanva — RESEARCH / NOT_NEEDED

- **Apache-2.0**  
- 节点画布 + 多模型 + **发 X/TikTok**（偏离本仓库红线：社交发布）  
- 节点连线类型校验可作交互研究  

### 2.5 Vue Flow — ALREADY_IMPLEMENTED

- **MIT**  
- 本库：`package.json` → `@vue-flow/core@1.48.2`、background、controls  
- 已用于 `ManagedStudioCanvasView` / `StoryWorkbenchView`  
- LocalMiniDrama 同用 1.48 系列 → **直接补强现有依赖**，无需换库  

### 2.6 OpenAssetIO — RESEARCH_ONLY（已审）

- **Apache-2.0**；见 `docs/开源项目借鉴审计_2026-07-13.md`  
- 预检/注册语义已映射 Publication；**不**引 Python Manager 运行时  

### 2.7 OpenTimelineIO — ALREADY_IMPLEMENTED

- **Apache-2.0**  
- 本库：`export_edit_otio` / `import_edit_otio`、`aicanvas.otio-*` 合同、剪辑台 OTIO  
- 无需再嵌官方 C++/Python 运行时  

### 2.8 OpenCut — DEFERRED

- **MIT** 但官方写明 **ground-up rewrite**，classic 归档  
- 观察 Editor API / MCP 稳定后再评；**不**重写本库剪辑核心

## 3. 八问

1. **已实现？** Vue Flow、OTIO 交换、资产 CAS/Binding、驾驶舱、Publication 预检思路。  
2. **更成熟？** LocalMiniDrama 短剧画布工作流 UX；LumenX Playground 多模型台；Jellyfish 准备态产品化。  
3. **仅界面？** LumenX/TwitCanva 大量为壳差异；TwitCanva 社交无关。  
4. **第二真源风险？** 整并 LocalMiniDrama/Jellyfish SQLite 会双真源。  
5. **适配器？** OpenAssetIO 仍可选 sidecar（远期）；Comfy 已有。  
6. **一致性？** Jellyfish/Local 的实体复用与本库 Binding 同向；无新可搬核心。  
7. **可停研？** OpenCut 重写期、TwitCanva 社交部分。  
8. **下一优先级？** **把 `studio-canvas-layout` 接到 ManagedStudioCanvas / 驾驶舱**（列表↔画布、workflow 组 UI）。
