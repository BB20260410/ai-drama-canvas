## 2. 本轮发现并修复的实际问题

### P9 可靠性与规模

1. 旧连续性/冲突热路径先取最多 500 条再在内存过滤，深页会漏项。现已下推 SQL，并对筛选结果做精确 count 与稳定 keyset。
2. 旧媒体规模证据可由重复或伪造载荷凑数，无法证明 CAS 与缩略图可用。现强制逐对象 SHA/size/唯一路径核对，并实际解码 1000 张缩略图。
3. 旧 UI smoke 没有证明 Electron 在 1 万媒体和全季规模下滚动、换页、切工程。现用实际 Electron 产物完成，并保留截图和机器证据。
4. 原 Material Studio 只有库/列表视图，缺少可视化的受管生产画布。现新增资产与时间线图、2–6 宫格展开、连续性边、筛选分页和有界 DOM。
5. 画布布局代码把 Node `crypto` 间接打入 renderer，production build 会失败。现拆分浏览器安全的布局类型/几何/节点 ID 边界。
6. 工作区重置后的 immediate watcher 会把有 dashboard 的默认“无限画布”切回“资产库”。现按 dashboard 能力恢复正确默认页。

### P10 构建、备份与真实 canary

1. 旧 buildId 会随查询时间变化，不能作为稳定产物身份。现分离 artifact build time 与 query time，同一产物的 buildId/fingerprint 保持稳定。
2. 旧 source digest 漂移只对部分调用提示，仍允许旧构建执行写操作。现除 `get_capabilities` 外全部 MCP 工具全局失败关闭。
3. 旧备份直接复制活跃 SQLite/WAL，无法证明一致性。现按固定顺序建立 `BEGIN IMMEDIATE` 屏障、检测复制前后漂移、在 staging 验证后原子发布。
4. 旧真实生图流程可自动 PASS 视觉验收，且曾有 JPEG 内容误用 PNG 扩展名的风险。v2 流程强制正确魔数/扩展名、冻结包与 prompt/raw attestation、一次直接工具调用、独立原尺寸视觉审查和 raw/labeled 成对留存。
