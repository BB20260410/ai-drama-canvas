## 用户路径（跟到函数）

### A 节点操作面板
1. 单击节点 → `DramaCanvas` focusedNodeId  
2. 渲染 `CanvasStoryboardPanel`（props: storyboard）  
3. 动作：saveMeta / 生图 / 生视频 → API + `nodeStatus.set(nodeId,{step,message})`  
4. 结束 → `nodeStatus.clear`

### B 状态 overlay
1. `createCanvasNodeStatusStore()` → provide 给 context  
2. 节点组件内 `CanvasNodeStatusOverlay` :nodeId  
3. `status = map[nodeId]` 有则盖 spinner  

### C 框选建组（既有）
`onSelectionChange` → storyboard ids → `createWorkflowGroup` → PUT canvas-layout  

## 数据模型
