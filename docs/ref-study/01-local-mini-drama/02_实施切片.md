## LMD-1 · 工作流组从选择创建（核心合同）

### 目标

对齐 LocalMiniDrama `canvasWorkflow.js` 的可测行为，映射本库 `panelIds` + `StudioCanvasWorkflowStep`：

1. `normalizeStudioCanvasPipeline(steps)` — 过滤非法步骤；空则默认 `['image']`（本库 runner 仅 image 有副作用；默认不含 video/audio 以免 silent fail 串）  
2. `createStudioCanvasWorkflowGroup(existing, { title?, panelIds, pipeline? })` — 去重 panelIds、生成 id/createdAt  
3. `deleteStudioCanvasWorkflowGroup(existing, groupId)`  
4. `getPanelWorkflowGroupMap(groups)` — panelId → group  
5. `extractStudioCanvasPanelIdsFromSelection(selected)` — 从画布选中项抽取 panelId（支持 `panel:{id}` 节点 id、`{kind:'panel',id}`、裸 panelId）  
6. `applyStudioCanvasWorkflowGroupsToLayout(layout|null, groups)` — 经 `normalizeStudioCanvasLayout` 写回 workflowGroups  

**不**改 P0–P10 owner 真源；**不**引入对方源码文件。
