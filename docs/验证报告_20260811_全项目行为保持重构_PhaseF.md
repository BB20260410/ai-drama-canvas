## 已完成改动

1. `StudioCommandRequest` 改由权威 `StudioRuntimeCommandRequest` 派生，修复旧手写集合只覆盖
   48 条、权威实际为 56 public + 2 internal 的类型漂移。
2. 新建 `studio-command-executor.ts`，机械承载 58 条 Studio 业务 case；新建
   `studio-command-errors.ts` 承载共享纯错误合同。
3. command bus 继续掌握 schema/actor、managed shell、两次 lease、幂等 ledger/replay、
   Studio lock、operation context、managed recheck、三条 active fence、busy retry、一次性
   结果投影及 terminal ledger/event。
4. 独立审查实测发现并修复两条 Higgsfield active-context 冲突误记 `unknown`：现在稳定落
   `failed / project_context_conflict / committed=false`，且无 owner 写入或外部调用许可。
5. 新建 `studio-global-resource-read-ipc.ts`，抽出 7 条全局人物/场景/图片/音视频资源只读
   handler；默认复用既有 Core owner，不建立第二缓存或数据库。
6. registrar 只接收 gate 安装后的 decorated handle；Main 显式使用
   `ipcMain.handle.bind(ipcMain)`，消除未来 receiver 语义变化风险。
