## 数据合同与界面

- 图片身份：`来源工程 + media SHA-256`。
- 名称语义：一张图片可以对应 1 至多条资产/版本关联，卡片与详情均展示名称。
- 分类：人物、场景、道具、风格继续使用既有 Material Studio 规范资产分类，不另建第二数据库。
- 详情：使用来源工程根和图片 SHA 读取，不回退到当前工程。
- 状态：552 条关联中 `approved=242`、`pending=310`、`rejected=0`，其中 Primary 关联 148 条。
- 只读：全部剧本范围禁止创建、导入、追加版本、Review、提升 Primary、关系写入和跨工程复用。
- 规模：单页最多 36 张，真实 549 张共读取 17 页；缩略图继续 lazy/async。
- 异步隔离：列表指纹包含 `projectRoot + scope + representation + category + search + cursor + limit`，切换范围、表示层或分页后旧响应不能覆盖当前状态。
- 复合身份：卡片选择键同时包含来源项目 ID、来源根和来源条目，避免不同根复用同一 project ID 时发生 Vue key/选择碰撞。
