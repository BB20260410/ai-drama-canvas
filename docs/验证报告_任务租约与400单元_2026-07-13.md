# AI 漫剧画布验证报告：任务租约与 400 单元画布

验证日期：2026-07-13

## 结论

本轮已把“多个 Codex/桌面窗口不会重复领取同一批任务”“远程生成不会在未知回执时重复付费提交”和“400 个生产单元可在真实 Electron 窗口中流畅浏览”落实为可重复验证的能力。

这不是整个产品的最终验收。真实项目导入、真实生图网站、真实图生视频网站仍需在用户提供项目和网站后做现场校准与端到端验收。

## 任务包与租约

- TaskPack 使用 schema v2，包含 revision、owner、lease ID、心跳、到期时间、释放原因与批次结果。
- 领取、心跳、释放、批次结束都在跨进程项目锁内执行。
- 活跃租约不能被其他执行者覆盖；同一执行者的重复领取返回原租约；过期租约允许审计接管。
- `finish_batch` 必须提交正确 lease ID 与 revision，并完整归档任务包内每个节点。
- 机械验收通过后只进入 `awaiting_review`；关联视觉验收全部通过后才自动转为 `completed`。
- 两个独立 Node 进程并发领取同一任务时，仅一个执行者获得租约。

## Codex 写命令恢复

- 所有 MCP 命名写工具都必须携带 `requestId` 和 `idempotencyKey`，并统一进入持久化命令总线。
- 命令在副作用前写入 `running`，成功后写入 `succeeded`。
- 副作用后进程中断或回执异常会保留为 `unknown`，原幂等键不会自动重放。
- 业务副作用完成后会写专用终态证据 `command.side-effect-committed`；`reconcile_command` 只在请求哈希、命令和幂等键全部匹配时对账成功，中间事件不能冒充完成，且绝不重新执行副作用。
- 两个独立 Node 进程使用相同幂等键并发执行时，只产生一个任务包和一个账本条目。

当前 MCP 对外暴露 133 个工具；新增 `get_generation_provider` 和 `upsert_generation_provider`，生成配置支持无副作用读取、修订 CAS 与幂等增量写入。同时包含 `cancel_generation_job` 和 `cancel_task`，旧的同步剪辑导出工具已移除，长导出使用可轮询、可取消、可恢复且带发布回执的后台作业。

## 本轮可靠性与真实导入加固

- 所有关键侧车写入使用带心跳和 PID 存活检查的跨进程锁，长操作不会因超时被另一个进程错误抢锁。
- 关键 JSON/Markdown/剧本/Skill 写入在原子替换前刷盘并在替换后刷目录，审计事件追加后刷盘；损坏 JSON 会停止写入并保留原文件，不会回退为空状态。
- `cancel_task` 要求当前修订和真实原因，仅允许取消待领取或租约已过期任务；活跃租约、验收中和终态任务全部拒绝。
- 视觉验收先持久化记录，再推进派生状态；批次验收绑定精确素材 ID、SHA-256 和本批时间，旧验收不能完成新版本。
- HTTP 生成先保存提交意图；回执不明时进入 `submission_unknown`，重启不会自动重提。远端取消必须调用供应商真实取消接口，否则拒绝标记取消。
- 素材使用相对项目根的稳定身份和 `aicanvas://` URI，整体移动项目目录后身份不变。
- 导入支持自定义正则与人工路径映射；没有识别出生产节点时预检直接报错，不会建立错误的空项目。
- 分镜成为任务包和生成任务的强约束：必须已确认、引用真实节点与素材、单板最多 6 镜且总时长不超过 15 秒；分镜修订漂移后旧任务不可继续。
- 网页任务必须按预检、上传、提交和下载顺序推进；预检结构化验证域名、登录态、页面模式、余额和付费授权，不能只写一句“已检查”或直接跳到提交。
- 剪辑预览同步视频、叠加层、音频、裁切、速率、音量和淡化；片段支持时间线上直接拖动、左右裁切和多来源吸附；OTIO 正确换算不同时间基，并拒绝静默丢弃不支持的转场/嵌套结构；后台导出可在重启后探测并恢复最终状态。
- 当前全量自动化测试：27 个测试文件、132 项测试全部通过。

## 400 单元 Electron 实测

测试夹具包含 10 集、400 个 15 秒生产单元和 400 张有效 PNG 缩略图。真实 Electron 窗口加载后测得：

| 指标 | 结果 |
|---|---:|
| 扫描耗时 | 114 ms |
| 显示全部分集 | 330.9 ms |
| 精确筛选第 400 单元 | 208.5 ms |
| 清除筛选 | 267.3 ms |
| 62%→80% 放大 | 212.2 ms |
| 80%→62% 缩小 | 155.3 ms |
| 平移至第 400 单元 | 31.0 ms |
| 帧间隔 P50 | 8.3 ms |
| 帧间隔 P95 | 9.2 ms |
| 最大帧间隔 | 9.4 ms |
| JS heap | 17.1 MB |

探针确认 400 个逻辑节点无重复坐标、无自动布局重叠。初始视口只渲染第 1–6 单元；真实平移到 `main-ep10-unit040` 后，DOM 只保留第 397–400 单元，第 1 单元已卸载。最终 4 张缩略图全部完成解码，避免同时创建 400 个重型图片节点。
