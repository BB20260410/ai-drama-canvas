# 验证报告 · P16 左右加号连线与“点击连线卡住”修复

> 验证日期：2026-07-19  
> 结论：**源码与工作区构建已完成并通过真实 Electron 验收。**  
> 安装边界：遵循本轮要求，**未制作安装包、未替换 `/Applications/AI 漫剧画布.app`**；当前安装版仍是 P15，不包含本次 P16 修复。

## 1. 原始问题与根因

用户反馈两项直接交互缺陷：

1. 点击“连线”后画布像卡住；
2. 图片左右两侧没有类似小云雀的“＋”，无法通过“＋ → ＋”点击连线。

真实源码与正式工程布局共同确认根因：

- 历史 `toggleConnectMode()` 在开启连线时强制把 `workspaceMode` 改为 `workflow`，随后调用 `rebuildGraph()`；
- 正式布局当时是 `workflow + pinnedNodeIds=[]`，因此点击后所有投影节点会消失，形成“卡住”的直接观感；
- 原 Handle 只在连线模式重建后出现，且只有 12×12 像素：输入节点仅右侧、宫格仅左侧，没有常驻左右加号。

## 2. 实际修复

### 节点连接点

- 角色、场景、道具、剧本、提示词和宫格等允许参与生产输入的节点，左右两侧常驻 26×26 的圆形“＋”。
- 左右端点分别有明确的无障碍名称、焦点态、悬停态和点击提示。
- Vue Flow 使用 `ConnectionMode.Loose`，允许从任一侧开始点击；业务层仍将反向连接规范成“输入 → 宫格”。
- 连线仍只允许角色/场景/道具/剧本/提示词到宫格，不让自由线绕过 BindingSet、连续性或冻结 owner。

### 卡顿与空画布保护

- “连线”按钮现在只切换轻量视觉提示，不再修改工作区模式、不再重建节点。
- `nodes-connectable` 常开，因此不打开按钮也能看到和使用加号；打开按钮仅突出连接点。
- 旧布局若为 `workflow` 但没有任何已固定节点，加载时自动安全回退到可浏览的 `projection`。
- 无已固定节点时点击“回到工作流”会给出操作提示，不再进入空白视图。
- “清空工作区”完成后回到投影视图，仍能看见可添加内容，不再显示一张空画布。
- Esc 关闭连线提示时不再重建整张画布。

### 真实操作路径

1. 点击“添加”或“素材库”把素材和 15 秒分镜放到工作区；
2. 点击一张素材右侧的“＋”；
3. 点击目标宫格左侧的“＋”；
4. 草稿线出现并落盘；点击“开始”时仍由后台用正式 BindingSet 重新核验。
