## 6. 怎么调动其他外部模型

Cursor **不会**内置切到千问/豆包/GLM/DeepSeek/Grok/Codex。要调就 **Bash 跑本机入口**。密钥只 source，禁止把完整 Key 贴进对话或 commit。

权威合同：

| 文件 | 用途 |
|---|---|
| `~/.grok/NOVEL_MULTI_MODEL.md` | 席位、通道、参数（以文首最新状态为准） |
| `~/.grok/DECISION_PROTOCOL.md` | 决断：多模型互评 → 主审合成 → 直接执行 |
| `~/.grok/env.local` | 密钥（chmod 600；只 source） |
| `~/.grok/bin/novel_chat.py` | **统一 CLI**，默认无客户端超时 |

### 6.1 先加载密钥

```bash
set -a && source ~/.grok/env.local && set +a
```

### 6.2 `novel_chat.py`（写作 / 审校 / 互评）

```bash
# 主笔正文 → 千问 3.8
python3 ~/.grok/bin/novel_chat.py --role qwen --file task.md \
  -o /tmp/qwen.txt --meta /tmp/qwen_meta.json

# 结构审校 → GLM（火山 Plan，低温）
python3 ~/.grok/bin/novel_chat.py --role glm --temperature 0.3 --file review.md \
  -o /tmp/glm.txt --meta /tmp/glm_meta.json

# 犬声口 / 备笔 → 豆包 evolving
python3 ~/.grok/bin/novel_chat.py --role doubao --file task.md \
  -o /tmp/doubao.txt --meta /tmp/doubao_meta.json

# 去 AI 味 / 探针 → DeepSeek V4 Pro
python3 ~/.grok/bin/novel_chat.py --role deepseek --temperature 1.0 --top-p 0.95 \
  --file task.md -o /tmp/ds.txt --meta /tmp/ds_meta.json

# 中文语感审校 → 文心 5.1（必须 Token Plan Person 通道，脚本已配）
python3 ~/.grok/bin/novel_chat.py --role wenxin --file task.md \
  -o /tmp/wx.txt --meta /tmp/wx_meta.json

# Kimi K3（火山 Agent Plan；不要用 kimi-latest）
python3 ~/.grok/bin/novel_chat.py --role kimi --file task.md \
  -o /tmp/kimi.txt --meta /tmp/kimi_meta.json
```

也可以 `--prompt "..."`。`-o` 写正文，`--meta` 写耗时/token。`--timeout-sec 0` 是默认，**禁止**短超时当默认。

| `--role` | 默认模型 | 通道 | 用途 |
|---|---|---|---|
| `qwen` | `qwen3.8-max-preview` | Token Plan `QWEN_*` | 主笔正文；一章一主笔 |
| `glm` | `glm-5.3` | 火山 `/api/plan/v3` + `DOUBAO_*` | 结构审，出问题表，不直接贴成稿 |
| `doubao` | `doubao-seed-evolving` | 同上火山 Plan | 犬声口 / 备笔 |
| `deepseek` | `deepseek-v4-pro` | 与千问同 Token Plan | 去 AI 味 / 探针；不接默认主笔 |
| `wenxin` | `ernie-5.1` | 千帆 Token Plan Person | 中文语感；`ernie-x1.1` 会 403 |
| `kimi` | `kimi-k3` | 火山 Agent Plan | 第二读感；勿用 `kimi-latest` |

**禁止**把各厂 Key 混成同一路、禁止同章拼盘正文。
