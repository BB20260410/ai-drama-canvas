- 相关位置：`src/main/index.ts:1742`、`src/main/index.ts:4308`、`src/main/index.ts:4316`。

- ACK 后 editor/watcher/generation/runtime/scan cleanup 聚合没有总时限。
- 真实 packaged App 已复现正常退出超过 10 分钟且只能人工终止。

最小后续：显式 `waiting_renderer → cleaning → exiting/cancelled` 状态；ACK/每类 cleanup 阶段日志与有界期限；clean editor、dirty novel、renderer 不响应、cleanup 阻塞四类确定性测试。Harness 的超时强杀只能记失败，不能记 PASS。

### P1-B：远端成功后本地提案写失败可允许重复 POST

- 相关位置：`src/core/novel-analysis-provider.ts:801`、`:851`；`src/core/novel-analysis.ts:314`。
- 触发：远端收到 POST 并返回合法提案 → 本地 `proposal.json` 写失败 → 状态记 `failed` → replacement 无远端对账即可 prepared。
- 独立只读隔离复现：posts=1、outcome/task=failed、checkpoint=request_dispatched、replacement without reconciliation=prepared。

最小后续：只要 dispatched=true 且提案尚未成功进入 reviewing，本地/解析/持久化错误均进入 `submission_unknown`；注入本地 proposal write failure，断言 replacement 无人工确认被拒绝且 POST 始终为 1。
