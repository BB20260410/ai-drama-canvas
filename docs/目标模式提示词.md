## 日常续作短提示词

同一开发窗口后续通常只需发送：

```text
继续当前“AI 漫剧无限画布”长期目标模式。

从当前工作区、docs/长期目标模式总提示词.md、docs/当前开发交接.md、最新验证报告和永久证据摘要恢复真实状态。自动选择并完成当前最高优先级且无需新增授权的纵向切片，实际修改、测试和留证。

每轮先证明交接中的唯一优先级仍未完成；完成后按源码、测试、运行和 evidence 重新排序。同一时刻只保留一个优先级，闭环必须包含代码、测试、真实运行、永久证据和交接。

除非本消息明确新增授权，否则继承 docs/当前开发交接.md 已记录的正式项目只读范围，并保持网站登录、上传、付费、素材覆盖、代码发布和公开分发边界不变。
```

```text
- 允许创建或更新 .aicanvas：是 / 否
- 允许修改原项目文件：是 / 否
- 网站域名：https://……，或无
- 允许上传目录：/绝对路径，或无
- 允许付费：否 / 是，最多 X 次或 X 元
- 下载目录：/绝对路径，或无
- 视觉验收后暂停：是 / 否
- 允许发布或公开分发：是 / 否
```
