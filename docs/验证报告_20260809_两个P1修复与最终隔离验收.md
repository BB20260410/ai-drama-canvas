## 新根因

1. Effect smoke 把 Chromium profile 放在 `project/electron-user-data`；legacy watcher 又递归监听整个 project。第二次启动复用 profile 时，chokidar 实际碰到 `SingletonSocket` 并产生 `UNKNOWN`。
2. main 的 staged cleanup 还不是唯一幂等 owner：没有 editor/scan 时可绕过有界清理；进入 `exiting` 后仍可能再次 fire-and-forget 关闭同一批 watcher，拒绝未统一收口。
3. Playwright `ElectronApplication.close()` 会调用 `app.quit()` 并等待真实根进程退出；20 秒超时是真实挂起，不是只关页面。隐藏进程不会改变该语义，也不是本次失败原因。
