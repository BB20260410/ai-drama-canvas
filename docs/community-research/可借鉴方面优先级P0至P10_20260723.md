# 可借鉴方面总表 · 优先级 P0–P10（2026-07-23）

> **不限 5 款**。综合：本仓架构（受管 Studio / MCP / CAS / Binding / Review / 15s 宫格）、源码深读（火宝 / Jaaz / InvokeAI / Storyboarder）、闭源产品面（LTX / Boords / Krea / Kling / Runway / Storyflow 等）、以及 `开源复刻借鉴全景调研_20260719.md` 中约 110 项零件调研。  
> **原则**：借交互与合同，不拆账本红线；个人用可本机跑 GPL/CC-NC，正式并库优先 MIT/Apache + clean-room。  
> **读法**：每一级是「方面」清单，不是必须做满才进下一级；同级内可并行。

**本仓已强、不必当缺口重做**：CAS/修订、冻结包、binding 门禁、generation ledger、nextAction、quarantine、trace、MCP 189、Codex 主供应合同、P0–P14 关账边界。
