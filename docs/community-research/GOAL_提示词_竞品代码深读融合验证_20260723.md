> **用途**：复制下方「执行提示词」全文，作为 `/goal` 或长任务首轮用户消息。

四、工作方法（每一项融合必须走完 6 关）
════════════════════════════════════════════════════════

对 TASKS 中**每一个**落地项 T*，强制循环：

### Gate 0 · 立项卡（未写卡禁止写码）

在 `docs/evidence/fusion/<date>-<slug>-card.md` 写清：

| 字段 | 要求 |
|------|------|
| 方面 ID | 如 P0.5 / P1.1（来自优先级表） |
| 用户可感知价值 | 一句话：做完后用户多了什么 |
| 对方源 | 仓库路径 + 文件:行 或符号名（必须打开读过） |
| 本仓源 | 将改/将接的文件与 owner 名 |
| 策略 | COPY_WITH_LICENSE / CLEAN_ROOM / UX_ONLY / EXTERNAL_PROCESS |
| 非目标 | 明确不碰什么 |
| 验收命令 | 可复制的 shell / npm / tsx 命令列表 |
| 风险 | 是否触碰关账 owner；如何只增量 |

### Gate 1 · 双边代码真读（禁止只读 README）

1. **对方**：用 read/grep 打开实现文件；摘录关键函数签名、数据字段、状态机边、错误路径。  
2. **本仓**：打开将改模块 + 调用链上游/下游各至少 1 层。  
3. **差异表**（写入 card 或同目录 `diff.md`）：

```
| 维度 | 对方 | 本仓现状 | 融合决策 |
| 数据身份 | URL/自增ID | CAS+revision | 保留本仓身份，只借字段语义 |
| 写入 | 直接 UPDATE | command-bus CAS | 必须走本仓写入 |
| UI | … | … | … |
```

未完成差异表 → **禁止写业务代码**。

### Gate 2 · 设计对齐本仓合同

融合设计必须回答：

- 新媒体/新字段如何进 **CAS + 侧车**？  
- 失败时如何 **fail-close**（不静默选第一候选）？  
- 是否污染 **正式 Review 终态**？（探索结果默认 quarantine）  
- nextAction / dashboard 是否只读投影、不自建？  
- 与 unit-grid 15s 2–6 格合同是否冲突？

冲突时 **以本仓合同为准**，缩小范围，不扩大重写。

### Gate 3 · 最小增量实现

- 优先：新纯函数 + 单测 → 接线既有 owner → 再 UI  
- 禁止：为借一个 UX 新建平行 generation/binding 系统  
- 复制 MIT/Apache 代码：保留版权与许可头  
- clean-room：只写自己的 TS/Vue，对照行为测试

### Gate 4 · 机械验证（真跑）

最低集（按改动选择，不可空）：

```
# 类型
npx tsc --noEmit -p tsconfig.json   # 或项目既有 typecheck 脚本

# 定向单测（示例：改哪个跑哪个）
npx tsx --test tests/**/*related*
# 或 npm run test -- <pattern>

# 合同/身份（若动 MCP/release）
# 按仓库既有 validate-*.ts / build:mcp / identity 脚本
```

**有用性验证（强制，至少 1 条）**：

| 类型 | 示例 |
|------|------|
| 正向 | 新路径返回预期结构 / UI 数据testid 可测 / 文件写入 CAS 可 hash |
| 反向 | 重复执行幂等；非法路径拒绝；空输入 fail-close |
| 对照 | 融合前无法做的事，融合后 1 条命令/1 次 UI 可做 |

live Codex 生图：仅当 STATUS 允许且 owner 未禁止；否则标 **NOT_RUN** 并写证据，禁止伪造 PASS。

### Gate 5 · 证据与交接

每个 T* 完成后立刻：

1. `docs/evidence/fusion/<date>-<slug>-result.json`（status/pass|fail、commands、paths、digest 可选）  
2. 勾选 TASKS.md；更新 STATUS「下一步」与「最近验证」  
3. 若改变用户可见行为：`docs/当前开发交接.md` 增加短节（不删历史关账）  
4. 禁止覆盖旧 final-validation JSON

### Gate 6 · 无用则回滚

若验证无法证明「对本项目有用」（仅多了死代码、重复能力、或违反合同）：

- **回滚改动**或 `#ifdef` 式隔离  
- card 标记 `DROPPED_NOT_USEFUL` + 原因  
- 不得为交差留下半截接线
