# 竞品深度对比与后续迭代方向（2026-07-23）

> **范围**：同类「AI 漫剧 / 分镜 / 无限画布 / 本地生产」产品  
> **方法**：开源与闭源各取热度前 5；开源已 **浅克隆源码** 并读核心实现（非 README 扫一眼）；闭源按产品文档/评测/功能面拆解  
> **立场**：个人用、非商用 → 可放宽到 GPL/AGPL/CC-NC 的**本机独立进程**与**思路重写**；正式进本仓库仍优先 MIT/Apache 与 clean-room  
> **本仓基线**：Electron + Vue3 + MCP(189) + CAS/SQLite + 冻结包/Binding/Review + Codex 主供应；P0–P14 关账；L33 半成品接线  

本地克隆：`.tmp-competitor-study/{huobao-drama,jaaz,InvokeAI,storyboarder}`

## 0. 本仓在赛道中的真实位置（先立坐标）

| 维度 | 本仓优势 | 本仓短板（相对爆款） |
|------|----------|----------------------|
| **生产账本** | 修订 CAS、冻结包、binding 门禁、generation ledger、nextAction、quarantine、trace | UI 空态多、说服力弱；「唯一下一步」偏系统语言 |
| **Agent 合同** | MCP 189 工具、provider 一致性、commit 原子写回、run cancel/retry | 不如火宝「一句话全自动」；不如 Jaaz「画布内聊天即生成」 |
| **画布** | 受管节点 + 时间线排布 + 视口/分页意识 | 非自由涂鸦画布；无选区→生图；无实时预览 |
| **成片** | OTIO/续接/视频包骨架 | 单镜 TTS+字幕+拼接链路未产品化到火宝级一键 |
| **一致性** | 硬锁资产、权威图 SHA、continuity 侧车 | 缺少 LTX Elements 级「项目级可复用组件」产品叙事与 UX |
| **学习成本** | 零说明桌面闭环已关账 | 步骤条/空白页多，爆款 Demo 节奏不足 |

**结论一句话**：本仓是「制片账本 + Agent 合同」赛道的重型机；竞品多数是「出片爽感 / 画布交互 / 实时反馈」轻型机。后续迭代应 **借轻型机的路径与交互，不拆账本红线**。

## 2. 开源深读结论（按仓库）

### 2.1 火宝短剧 `chatfire-AI/huobao-drama`（最直接竞品）

**栈**：Nuxt3/Vue3 + Hono + Drizzle + better-sqlite3 + Mastra Agents + fluent-ffmpeg + Sharp  

**数据模型（`backend/src/db/schema.ts`）** — 值得对照：

```
dramas → episodes → storyboards
       ↘ characters / scenes（多对多 episode_*）
storyboards 字段：shotType/angle/movement/action/result/atmosphere
  + imagePrompt / videoPrompt / bgmPrompt / soundEffect / dialogue
  + firstFrameImage / lastFrameImage / referenceImages
  + videoUrl / ttsAudioUrl / subtitleUrl / composedVideoUrl
```

**Agent 拆分（5 个 + SKILL.md 外置）**：

| Agent | 职责 | 可借鉴点 |
|-------|------|----------|
| `script_rewriter` | 小说→剧本 | 与本仓 novel-analysis 对齐 |
| `extractor` | 角色+场景去重提取 | 去重+归属 episode 的校验 |
| `storyboard_breaker` | 剧本→分镜 | **镜头 16 要素 + video_prompt 3 秒分段标签** |
| `voice_assigner` | 音色分配 | VoiceIdentity 产品化 |
| `grid_prompt_generator` | 宫格提示词 | 宫格整板 prompt + cell_prompts JSON |

**关键实现细节**：

1. **`storyboard-tools.ts`**：`createStoryboardTools(episodeId, dramaId)` 工厂注入上下文；`validateStoryboardBindings` 强制 scene/character 必须属于当前集（与本仓 binding 门禁同构，实现更「Agent 可调用」）。
2. **`grid.ts`（22KB）**：`mode=first_frame | first_last | multi_angle`；`buildGridPrompt` + `collectGridReferenceAssets` + legend；Agent 失败可回落规则 prompt；**`grid-split.ts` 用 Sharp 均匀切 NxM 宫格** 再分配到镜头。
3. **`ffmpeg-compose.ts`**：单镜 = 视频 + TTS 轨 + SRT 烧录（检测 `subtitles` filter）；整集 `ffmpeg-merge` 拼接。
4. **Provider Adapter**：`ImageProviderAdapter` / `VideoProviderAdapter` 统一 `buildGenerateRequest / parsePoll / extractUrl`；多厂（OpenAI/Gemini/MiniMax/火山/阿里/Vidu）——本仓 Codex/Grok 双供应可对照扩展为 **adapter 注册表**（不必绑浏览器）。
5. **单集工作台**：`episode/[episodeNumber].vue` **~195KB 单文件** 把配音/镜头图/视频/合成/导出全堆一页——交互「一站」，工程「难维护」。本仓已拆多 View，应 **借其信息架构，不借巨石文件**。

**对火宝的取舍**：

| 可融合（clean-room / 个人本机） | 不要照搬 |
|--------------------------------|----------|
| 分镜 16 要素 + video_prompt 3s 分段标签 | CC-NC 代码直接并库 |
| 宫格生成→切分→分配闭环（本仓已有 labeled 布局，缺自动切分分配 UX） | 无 CAS/无 revision 的 URL 字符串资产 |
| 单镜 compose（视频+TTS+字幕）产品路径 | SQLite 自增 ID 当唯一身份 |
| Mastra 式「工具工厂按 episode 注入」 | 195KB 单页巨石 |
| Adapter 注册表扩展视频/TTS 厂 | 默认「一句话全自动」绕过人工 Review |

### 2.2 Jaaz `11cafe/jaaz`（画布 Agent 形态）

**栈**：Electron + React + Excalidraw + Python FastAPI + LangChain tools  

**许可**：**双许可 / Community 禁止改源码再分发** → 个人用可跑，**禁止把 Jaaz 代码并入本仓**；只借鉴交互与事件协议。

**深读要点**：

1. **`CanvasExcali.tsx`**：Excalidraw 为无限画布；`handleSave` **debounce 1s** 落盘；`lastImagePosition` 记录新图落点（多图自动排格）；监听 `image_generated` / `video_generated` **事件总线** 直接 `addFiles` + `updateScene`。
2. **`Chat.tsx`**：流式 tool_call / tool_call_arguments 增量 / tool_call_result；**tool 待确认**（`tool_call_pending_confirmation`）；会话绑定 `canvasId`。
3. **`write_plan` tool**：先写步骤计划再执行——与本仓 P21 generation plan 同族，Jaaz 是 **聊天可见计划**。
4. **工具海**：Seedance / Kling / Flux / Midjourney / Veo… 按 `tool_service` 注册表挂载；`comfy_dynamic` 动态 Comfy 工作流变 tool。
5. **`pngMetadata.ts`**：读 PNG tEXt 元数据（生成参数回流）——本仓 CAS 侧车可补「导出图内嵌 packId/runId」。
6. **Comfy 一键安装**：`electron/comfyUIInstaller.js` 大段进程管理——本仓正式链禁 ComfyUI，但 **「外部引擎生命周期托管」** 可映射到本机 Codex/MCP 子进程健康检查。

**可融合**：

- 画布侧 **生成结果事件 → 节点落位**（本仓 commit 后已有 pipeline 节点，缺「自动落在视口旁」的布局启发式）
- **聊天内 tool 进度 + 确认闸门**（强化现有 Agent 连接页，而不是另起聊天岛）
- **write_plan 可见化**（`get_studio_generation_control` 已有 plan，UI 应像 Jaaz 一样给用户看步骤）
- PNG 元数据嵌入身份（诊断与二次导入）

### 2.3 InvokeAI（统一画布 + 专业队列）

**许可**：Apache-2.0（代码可借鉴；模型权重另论）  

**深读要点**：

1. **`controlLayers`**：Konva 分层（raster / control / inpaint mask / regional guidance / ref images）；**`.invk` 工程包** `canvasProjectFile.ts`：manifest + 递归 `collectImageNames` 打包依赖图——与本仓「工程 CAS + 侧车」同构，可学 **导出自包含工程包**。
2. **`canvasStagingAreaSlice`**：生成结果进 **staging 区**，用户 accept/discard 再进画布；`canvasSessionId` + `destination` 把队列结果路由到会话——本仓 Review 已有类似语义，但 **缺「画布内 staging 预览条」**。
3. **`session_queue`**：Batch 笛卡尔积、`origin`/`destination`、graph 初始化、suspend/resume/cancel、workflow 父子链——远比简单 FIFO 成熟；可映射到 generation plan 的 attempt/lineage。
4. **Gallery + Board + Metadata**：图库看板、元数据回流参数——本仓媒体库可增强「按 run/pack 过滤」。

**可融合**：

- Staging 接受区（生成完成不直接污染正式节点，直到 Review/Accept）
- 工程导出「清单 + 依赖图 + 版本」
- 队列 origin/destination 显式字段（MCP 回写 UI 路由）
- Regional guidance 思路 → 映射为「宫格/区域绑定参考图」（不是 inpaint 本体）

### 2.4 Storyboarder（Wonder Unit）

**形态**：Electron 手绘分镜 + Shot Generator(3D) + 导出全家桶  

**深读要点**：

- `exporters/`：FCP / FCPX / ffmpeg / PDF / cleanup  
- `shot-list.js`：按相机 setup 聚类镜头（fov/height/rotation 容差）→ **拍摄 setup 单**  
- undo-stack：board/scene 双轨快照  
- 项目文件旁路 exports 目录、cleanup 未用图  

**可融合**：

- 导出 animatic / PDF 分镜板 / FCPXML（本仓 OTIO 已有，可补 **PDF 审片板 + 竖屏 animatic**）
- Setup 聚类思路 → 「同一机位的多宫格」分组视图  
- Cleanup 未引用媒体（在 CAS 引用图安全前提下做 GC 报告，不自动删）

### 2.5 ComfyUI / Fooocus / A1111（生态与 UX 参照）

| 项目 | 借什么 | 不借什么 |
|------|--------|----------|
| **ComfyUI** | 工作流 JSON 合同、队列、API history、节点图可序列化 | 作正式生图供应；GPL 并库 |
| **Fooocus** | 「零参数也能出好图」的默认预设哲学 | 绕过冻结包与 binding |
| **A1111** | 扩展生态心智、ControlNet/Adetailer 参数面词汇 | WebUI 本体进产品 |

> 闭源无公开 stars；排序综合：品类 MAU/下载讨论热度、专业评测榜单、创作社区出现频率（2026 分镜/短剧语境）。

| # | 产品 | 热度代理 | 核心卖点 | 对本仓启发 |
|---|------|----------|----------|------------|
| 1 | **Kling AI** | 短视频创作者装机率极高 | 故事板排序、原生音频、长镜 | **时间线式分镜排序 + 单镜 5–15s 视频合同** |
| 2 | **Runway** | 专业 AI 视频标杆 | Motion Brush、Director Mode、细粒度控制 | **单镜细控面板**（本仓冻结字段已有，UI 未产品化） |
| 3 | **LTX Studio** | 剧本→分镜→视频一体 | **Elements** 角色/道具/场景/风格可复用；**Retake** 局部重做 | **Elements≈本仓 Canonical Asset + Binding**；Retake≈rework run |
| 4 | **Boords** | 传统分镜 SaaS 龙头（1M+ boards） | 评论、animatic、脚本并排、客户审片链接 | **帧级评论 + animatic 导出 + 并排脚本** |
| 5 | **Krea / Storyflow**（并列取其一为第 5：Krea 实时画布更火） | 实时生成心智占领 | Krea：&lt;50ms 实时画布；Storyflow：脚本+情绪板+分镜同画布 | **反馈延迟与上下文共置** |

### 3.1 LTX Studio — 最值得「产品叙事」对齐

- **Elements**：角色 / 物体 / 地点 / 风格 四类可标签、跨镜复用  
  → 本仓已有 `prop-d01-golden-mask` 权威硬锁、BindingSet、连续性时间线；缺的是 **Elements 面板 UX**（「拖一个 Element 到格上」而非 MCP 术语）。
- **Retake**：不整段重生，只改时段/局部  
  → 映射 `retry_studio_generation_plan_nodes` + 局部 rework；UI 要叫「重拍」而不是「retry node」。
- **Script→Board 同屏**：本仓有剧本工作台 + 画布分离，可做 **可选分屏**。

### 3.2 Boords — 审片与协作 UX

- 帧下评论、密码分享、animatic 导出、脚本-板并排  
- 本仓 Review 偏「机器+人工决策态」；可补：**批注锚到 panelId+revision**、**animatic 本地预览**（无需协作云）。

### 3.3 Krea Realtime — 交互延迟哲学

- 实时反馈适合 **探索草图**；本仓正式生产必须冻结  
- 可做 **「探索模式」**（非正式 CAS 路径，结果默认 quarantine）与 **「正式模式」** 双轨，避免污染账本。

### 3.4 Kling / Runway — 视频段合同

- Kling 故事板序列 vs Runway 单镜细控  
- 本仓 15 秒 2–6 宫格合同更接近 **Kling 序列 + 每格冻结**；视频提示词可吸收 Runway 运镜词汇表（已有 cinematic skills）。

### 3.5 Storyflow — 上下文共置

- 分镜、脚本、角色卡、情绪板 **同一无限画布**  
- 本仓信息在多 Tab；可做 **画布上挂 script strip / binding chip**，不必合并数据模型。

## 5. 可借鉴 / 可融合 / 可优化（按优先级）

### P0 — 3 个月内，直接抬「个人日用爽感」（不拆账本）

1. **单镜成片最小闭环（火宝 compose 路线，clean-room）**  
   - 输入：已 Review 的 panel 视频或静帧序列 + 对白  
   - 输出：TTS + SRT + ffmpeg 合成 `composed` 资产登记 CAS  
   - 映射：`studio-video-package` / ffmpeg 配方；状态进 ledger  

2. **宫格「生成→切分→分配」UX（火宝 grid-split + 本仓 labeled）**  
   - Sharp/本地裁切 NxM → 写入各 panel raw 候选 → 仍走 quarantine + Review  
   - 已有 `studio-labeled-layout`；补 **自动 cell 分配 UI**  

3. **Staging 区（Invoke staging）**  
   - commit 后先进入「待接受」条，Accept 才挂正式 pipeline 节点  
   - 与 Review 态对齐：pending / approved / rejected  

4. **Elements 面板（LTX 叙事 = 本仓资产库 UX）**  
   - 角色/场景/道具三栏；拖到单元/宫格 = 显式 binding 决策  
   - 文案去 MCP 化：「硬锁」「权威图」保留，按钮叫「固定到本格」  

5. **驾驶舱/Agent 页去空态（产品视频已暴露）**  
   - 无数据时展示 **下一步卡片 + 最近结果缩略图**，禁止大白页  
   - 「继续」主按钮绑定真实 nextAction  

### P1 — 账本增强与 Agent 体验

6. **分镜 schema 对齐火宝 16 要素 + video_prompt 3s 分段**  
   - 扩展 `suggest_studio_storyboard_draft` 输出字段；不破坏 15s 2–6 格合同  

7. **Generation Plan 可视化（Jaaz write_plan）**  
   - 侧栏步骤条：冻结 → 派发 → 回写 → 审片；失败节点一键重拍  

8. **Provider Adapter 注册表（火宝 adapters）**  
   - 在「应用不内嵌模型」前提下，把 Codex/Grok/未来本机引擎统一为 adapter 接口  
   - 视频/TTS 作为 **可选 adapter**（个人用可接 MiniMax/火山等，密钥仅本机）  

9. **工程导出包（Invoke `.invk` 思路）**  
   - manifest + image name 闭包 + revision 清单 → zip 备份/迁移  

10. **PNG 元数据嵌入 packId/runId（Jaaz pngMetadata）**  
    - 导出 labeled/raw 时写入 tEXt；导入可反查 trace  

### P2 — 导出、性能、探索双轨

11. **Animatic + PDF 分镜板（Storyboarder/Boords）**  
12. **帧级批注 W3C xywh（既有社区调研 Annotorious）**  
13. **探索模式 quarantine 实时草图（Krea 哲学，非实时模型）**  
14. **画布性能**：rbush 空间索引 + 缩略图 LRU（既有 20260719 调研）  
15. **Setup 聚类镜头表（Storyboarder shot-list）**  

### 明确不做 / 缓做

| 项 | 原因 |
|----|------|
| 把 ComfyUI/浏览器自动化接入正式供应 | 项目红线；个人用可外挂但不进 ledger 主路径 |
