# 开源复刻/借鉴全景调研（2026-07-19）

> 目的：个人非商用前提下，从开源社区找出可复刻、可复制、可借鉴的项目与具体内容。
> 方法：14 路并行子代理调研（画布引擎/小说转漫画/推文自动化/分镜/AI 视频/角色一致性/剪辑内核/MCP 编排/TTS/字幕发布/审片/Electron 工程化/LLM 改编/AI 画布 Agent），每个候选项目逐一打开 GitHub 仓库或 LICENSE 原文核实许可证与活跃度。

## 许可证分级

- **✅ 可复制**：MIT / Apache-2.0 / BSD / ISC / WTFPL / MPL-2.0（作依赖）——可直接复制代码或引入依赖（保留版权声明）。
- **⚠️ 仅借鉴/独立运行**：GPL / AGPL / CC-NC / 无 LICENSE / 自定义限制——只读思路、本机独立部署为外部进程，**不整段并入本仓库**。
- 仍遵守项目红线：不建第二事实源、不覆盖 final-validation、优先 clean-room 扩展既有 owner；受限许可代码不进仓库。

## 最值得先做的 P1 组合（全部宽松许可）

1. **画布性能**：rbush 空间索引 + quick-lru/p-queue 缩略图管线 + xyflow MiniMap areEqual 技巧 → 支撑 3246 宫格 + 10000 媒体。
2. **租约/幂等**：graphile/worker 租约三字段 + durable-execution-the-hard-way 事件账本 + MCP 官方 SDK progress/cancelled。
3. **分镜 schema**：Storyboardify 中文 Shot schema + FilmAgent 镜头衔接规则 + Shotbuddy 插镜命名。
4. **首尾帧视频**：Wan FLF2V 合同 + kijai WanVideoWrapper 续接节点图 + Salad comfyui-api 的 TS 队列。
5. **推文链路**：VideoLingo 逐句 TTS 静音插值 + MoneyPrinterTurbo 句级 SRT + NarratoAI screen_matching schema。
6. **一致性打分**：ViStoryBench CIDS/CSD + Hungarian 匹配 → `assetConsistency.ts`。
7. **审片**：Annotorious W3C xywh selector + xSTUDIO 十二种对比模式（官方 compare_modes.rst 实为 12 种）中的四态（Off/A-B/Wipe/Difference）+ TACTIC note↔task 回链。
8. **剪辑增量**：CcClip 时间轴组件 + animation-timeline-js 关键帧交互 + mediabunny/WebAV 逐帧预览。
9. **TTS**：GPT-SoVITS api_v2 服务化 + CosyVoice instruct2 情感指令 + whisperX 词级对齐。
10. **工程化**：qmd busy_timeout 配方 + proper-lockfile + write-file-atomic + chokidar awaitWriteFinish。
