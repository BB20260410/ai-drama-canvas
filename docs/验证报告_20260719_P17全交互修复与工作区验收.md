## 2. 本轮实际修复

### 无限画布

- 左右两侧“＋”常驻可见，可正向或反向点击完成输入 → 宫格连线。
- 连线模式不再重建空画布；重复边、非法边、自环和半成品连线失败关闭。
- 支持选线删除、重连、隐藏/显示、Esc 取消与清空视图二次确认。
- 图片禁用原生拖拽，节点拖动不再被缩略图抢走。
- 缩放按钮读取并持久化真实 Vue Flow viewport；中键平移、适配和重启恢复通过。
- 工程切换和卸载前先 flush 布局；旧工程或旧单元异步响应不能覆盖当前工程。
- 当前单元即使不在 36 条当前页，也能进入有界投影并展开 2–6 宫格。
- “开始”始终以全部目标宫格为准；相同输入重复点击复用既有工作流与运行 ID，不重复冻结/派发。
- 修复重复“开始”返回 Vue Proxy 导致 Electron IPC `An object could not be cloned`。
- 生成历史支持 newest-first，画布读取最新结果而不是旧记录。

### 桌面壳、项目、Agent 与备份恢复

- 项目切换会重置旧 overview、焦点和绑定状态，切换期间禁用竞争导航。
- 项目中心增加焦点闭环；未保存工程名需二次确认后才能关闭。
- Agent 页面初始状态改为“检查中”；开发版只检查、不修改客户端；Codex 为主连接，Grok 不构成硬门禁。
- 备份 SHA 改为流式读取，避免大工程整文件进入内存。
- 恢复拒绝 v1、符号链接、目录重叠、不安全 projectId、活动工程/源工程覆盖；所有检查在 staging 前完成。
- 恢复写屏障持续到 renderer 校验并激活新工程，失败保持原工程可用。

### 并发可靠性

第一次全量回归真实发现 `command-bus` 双进程同幂等键用例失败。根因是命令账本每次打开 SQLite 时，先执行 `journal_mode=WAL`、后设置 `busy_timeout`；在全套压力下，第二进程可能在等待策略生效前收到 `database is locked`。

已把 `busy_timeout` 提前到 WAL 与 DDL 之前。修复后相关 19 项测试通过，同一双进程用例连续压力运行 20 次全部通过，随后完整 804 项测试也全部通过。
