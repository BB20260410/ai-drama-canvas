## 本轮修复说明

1. 生成队列先对完整 bucket 计算 totals/inFlight，再截取最多 36 个可见任务。
2. Vue Flow 内置控件用可见图标 + 屏幕阅读文本保留原行为；小地图使用无业务 `id` 的节点投影。
3. 删除缩略图容器对 click 的错误截断，使点击图片主体也能选中画布节点。
4. 长列表行增加 `content-visibility:auto` 与 `contain-intrinsic-size`，减少离屏布局/绘制成本。
5. 图片统一异步解码，列表缩略图保持懒加载；图标按钮补齐名称。
6. 10k 规模测试显式点击“剧本”入口并使用独立 user-data，避免默认页变化造成 90 秒空等和用户状态污染。

## 复盘与边界

- “测试所有按键”采用两层定义：547 个静态按钮全部做合同检查；对 22 条核心真实路径做实际点击。没有为了凑数量去执行会删除、上传、付费、正式生成或覆盖真实项目的危险按钮。
