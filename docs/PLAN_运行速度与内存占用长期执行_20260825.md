## 1. 一句话目标与整包完成门

**目标**：导演每天打开受管画布 / 驾驶舱时，**默认走快路径**；列表与缩略图**不拉原图**；MCP/主进程**冷域不预加载**；任何波次都**不重建**已关账 owner。

同时满足才可称本计划「阶段完成」（非整仓产品终局）：

1. 生产 UI / earliest / 列表调用时间线投影时，**默认 `fastMode: true`**；函数默认不再是 `false`。  
2. `full` 只出现在诊断菜单或显式 CLI，并带耗时提示。  
3. 画布/驾驶舱展示 36 单元时，**不为这一屏物化整集 2500 槽位**（或有等价有界投影）。  
4. MCP 冷启动不因「连上 Agent」就解析 editor / adaptation / 小说分析整图（或有证据证明已懒加载）。  
5. 缩略图 LRU 仍只缓存 URL；列表请求原图次数合同为 0。  
6. 既有 T23 严格门（首卡 ≤1.5s、units 请求 ~42ms、投影 IPC ≤4）**不回退**。  
7. 每波新证据 `docs/evidence/runtime-perf-memory-*.json`；不覆盖 2026-08-11 final。  
8. **红线**：不写正式工程旁路；不重建 ledger/production/dashboard；不全盘扫 `codex-ai-drama-studio`；不弹窗 GUI 除非 owner 点名。
