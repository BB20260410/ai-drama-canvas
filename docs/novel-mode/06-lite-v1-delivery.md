# 轻量小说工作区 V1 交付说明

## 交付结论

已完成一个可运行的本地小说纵向切片：导入受管副本、卷章读取与管理、正文编辑和 CAS 保存、自动历史快照、按章全文搜索、绑定原文区间的手工记忆，以及既有受管工程备份/恢复入口。

## 使用入口

1. 打开项目中心，新建时选择“小说创作”；空工程点击“初始化正文库”。
2. 已有小说可在顶部选择“导入文件”或“导入目录”，支持 TXT、Markdown、DOCX；导入创建受管副本，不修改原始来源。
3. 左侧选择卷章或搜索全文，中间编辑并保存，右侧选中正文后加入记忆。
4. 顶部“备份”和“恢复”沿用受管工程的一致备份/恢复到新目录能力。
