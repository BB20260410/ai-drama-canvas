## 已修复的审查问题

### P1

1. Higgsfield connector 的 `claimed / authorized / submitted / submission_unknown` 不再永久占槽：claim/nonce 有 TTL，过期状态按安全语义恢复或进入人工对账，远端终态可释放队列。
2. authorize 前原子复验正式图片/视频 owner；旧 run 已成功、取消、失败或被新 owner 接替时，不再发放外部调用许可。
3. VideoEditor 对单项目时间线建立 6 小时核心上限，并按横向视口虚拟化标尺和片段，避免极端时长造成巨量数组、DOM 或 OOM。
4. 嵌套时间线预览改为并发 2 的可失效任务队列；切工程和卸载后不再继续启动旧工程排队任务。
5. 受管画布缩略图派生改为并发 2，并以工程 root/generation 取消旧任务。
6. 隔离包不再复制工作区 `node_modules`，改为依据 `package-lock.json` 执行隔离 `npm ci`；直接生产依赖身份纳入 package/lock/stage/packaged 多方核验。

### P2

1. Higgsfield 预检过期后返回已持久化的 `blocked_by_provider`，不再把业务拒绝误记为 command `outcome_unknown`。
2. 总资源目录对 `SQLITE_BUSY / LOCKED` 与瞬时 I/O 做有界重试；瞬时失败不再缓存成结构损坏。
3. 小说 FTS 增加进程内文件身份缓存和有界并发；热查询不再每次串行 stat 全部章节，命中候选仍复验，漂移时失败关闭回退。
4. 画布节点缩略图与原生拖出准备增加 generation token，A 请求的失败/finally 不再覆盖 B 媒体状态。
5. 默认进入画布时不再预加载未显示的素材库第一页；首次打开素材库才取列表。
6. 旧版画布搜索采用 latest-only 延迟合并，事实/beat/计划关系使用预建 Map/Set，移除主要 O(n²) 扫描。
7. VideoEditor 移除工程级深度 watch，建立 clip/media/snap 索引；播放、拖动与转场预览不再反复全表查找。
