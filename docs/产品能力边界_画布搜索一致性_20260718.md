## 3. 一致性强约束 ≠ 模型零漂移 — **永久产品事实**

| 软件能保证 | 软件不能保证 |
|------------|--------------|
| 同一权威图 SHA / 版本 | 模型脸型、服装、纹样、布局 100% 不漂 |
| 同一提示词锁 / BindingSet | 供应商输出与参考像素级一致 |
| 连续性状态与 Review 门 | 跳过机械检查与视觉 Review |

**闭环仍必须：** 冻结 → 生成 → 机械检查 → 视觉 Review → 失败返工。
