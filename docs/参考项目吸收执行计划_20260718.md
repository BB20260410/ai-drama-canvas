## 0. 一句话原则

**吸收「对自己有用的能力与交互」，不是把别人仓库搬进 monorepo。**  
真源永远是：文件系统 CAS + SQLite 索引 + `execute_command`；画布/驾驶舱只是视图。

| 可以 | 不可以 |
|------|--------|
| clean-room 重写合同与 UI 行为 | 整库 clone 进 `src/` |
| npm 正式依赖（MIT/Apache 库） | AGPL/GPL 源码并入核心 |
| 对照运行别人的 exe/Docker（数据不写本库） | 第二套 SQLite 当真源 |
| 扩展既有 owner | 重建 P0–P10 |
| 个人非商用借鉴 NC 项目**需求** | 日后商用仍用 NC 源码不重审 |
