## 根因与修复

锁定的 `electron@43.1.0` npm 包没有 `postinstall`，`npm ci` 只安装 Electron 的 JS 包与 `install-electron` 命令，不会自动生成 `node_modules/electron/dist/Electron.app`。旧 smoke 在 binary 不存在时直接调用 `ditto`，因此失败。

已实施：

- 隔离 `npm ci` 后显式调用由同一 lockfile 安装出的 `node_modules/.bin/install-electron`。
- 从本机 Electron 官方缓存中只选择 SHA-256 与 Electron 自带 `checksums.json` 完全匹配的归档，复制到本轮临时缓存；无有效缓存时仍保留官方下载退路。
- 强制 `darwin / arm64`，清除 mirror 与跳过脚本类环境覆盖。
- 同时核对 package direct spec、lock entry、installed package、dist version、`path.txt`、Mach-O 架构、可执行权限、ZIP 名称/大小/布局。
- 新增无窗口 fixture：完整执行 `npm ci → verified cache seed → install-electron → ZIP → 解包`，并比较打包前后可执行文件 SHA。
