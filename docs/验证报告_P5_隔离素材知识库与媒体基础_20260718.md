## 3. 规范资产知识库

- `CanonicalAsset` 显式支持 `character / scene / prop`，不再依靠路径或中文关键词猜类别。
- 别名、定义、版本、审核收据、Authority、正负锁、适用范围和组合成员关系均进入唯一规范模型。
- 新资产版本只能以 `pending` 创建；通过追加式审核收据后才能成为 Authority，禁止伪造 `approved` 状态或原地改历史。
- 资产定义、版本、别名、Authority、审核、媒体身份和导入来源均受不可变约束保护。
- 关系采用 v2 追加式修订链；current、stale、superseded 可区分，过期关系只能用双 revision CAS 显式 rebase。
- 适用范围可精确到项目、季、集、15 秒单元、本地秒段和集内绝对秒段；不适用或未知时生成冻结失败关闭。
- 同一媒体 SHA 只保存一份 CAS 对象，但每次明确导入都保留独立来源记录；MCP 不暴露 CAS 内部路径或媒体字节。

## 4. 大媒体、分页与流式读取

- 图片使用缩略图；视频使用 poster 与 720p proxy；音频使用 waveform 摘要，派生物均可重建且按需生成。
- 64 MiB 原件通过流式 SHA 与 Range 读取；32 MiB 视频连续 Range 在身份未变时只做一次整文件哈希。
- 文件身份缓存同时核验 realpath 链、device、inode、size、mtime 与 ctime；身份漂移后重新校验。
- 10,000 条媒体、资产或单元元数据使用 SQLite keyset 分页，不把媒体本体装入 JSON。
- 真实 Electron 规模烟测加载 10,000 份剧本元数据和 1 份提示词，ready 490 ms，页面最多保留 36 个素材 DOM 节点；前后翻页与类型切换均通过。
- 100 个视频和 100 个音频的列表查询只读取轻量元数据，不在列表阶段启动派生进程。

上述规模结论不等于已经证明 10,000 次高吞吐命令写入。当前 JSON command ledger 的全数组重写在超大写入量下可能退化为 O(n²)，已明确留到 P9 迁移为增量、事务账本并做故障矩阵验收。

## 5. 剧本、15 秒单元与 Codex 生成闭包基础

- 剧本与提示词是不同的正式文档类别，均保存不可变修订和冻结正文。
- 15 秒单元显式携带季、集、季内单元顺序；每单元只接受 2–6 格且总时长严格为 15 秒。
- 单元 sequence 在同一季和集内唯一；旧数据可迁到显式 legacy season，冲突时失败关闭。
- 生成包只冻结已审核 Authority、当前关系 head、资产适用范围、宫格槽位、正负锁、参考媒体 SHA、季、集、单元和双时间轴。
- 单格控制参考超过 6 项时拒绝冻结，必须先创建并审核组合派生资产，禁止静默丢参考。
- raw/labeled 是同一 generation run 下两个显式变体；同 runId + variant 禁止静默换图。
- 结果登记后可回溯到冻结请求包、资产版本、提示词、时间线与 SHA；媒体漂移时失败关闭。

P5 只建立这些基础能力。剧本实体提取、歧义消解和内容寻址 `AssetBindingSet` 属于 P6，尚未宣称完成。
