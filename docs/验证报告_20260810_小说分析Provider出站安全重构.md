## 核心重构

- 新建独立 `novel-analysis-transport`：域名只解析一次，冻结 IPv4/IPv6 地址快照，真实连接只能消费该快照。
- 每个 probe/POST 使用独立 Undici Agent；不设全局 dispatcher，不跨请求、Provider 或任务复用连接。
- URL 保留原 hostname，因此 Host、TLS SNI 与证书 hostname 校验保持一致；Agent 显式 `rejectUnauthorized: true`，不受宿主关闭 TLS 校验的环境变量影响。
- 环境代理变量不参与这条敏感正文通道；所有 3xx 均手动拒绝且不访问 `Location`。
- IPv4 覆盖 loopback、RFC1918、CGNAT、link-local、benchmark、文档、multicast 与保留地址；IPv6 先解析 embedded IPv4，其余只允许 `2000::/3` 中非特殊保留段作为公网，其他空间失败关闭。
- 公网或混合公网目标只能 HTTPS；HTTP 只允许 `allowPrivateNetwork=true` 且全部地址均为本机/私网/非公网。
- 成功响应完整消费后关闭 Agent；超时、超限、TLS 或网络异常销毁 Agent 与连接。
- URL、DNS、协议和凭据均在 execution intent 前校验。门禁失败时任务保持 `prepared` 且无 execution；`request_dispatched` 后的网络、HTTP、解析或本地提交失败继续进入 `submission_unknown`，禁止自动重提。
- 非 2xx 响应不再把远端正文或 statusText写入任务；未知本地错误只落稳定安全摘要，避免 API Key、小说正文和绝对路径进入项目、事件或 Renderer。

## 兼容与依赖

- Provider schema、IPC、MCP、`analysis-providers.json` 均保持版本 1，无数据迁移。
- 本机/私网 OpenAI-compatible HTTP 仍可用，但必须显式开启私网授权。
- 旧公网 HTTP 配置不删除；下次保存、探测或执行会明确拒绝，用户需改为 HTTPS。

## 覆盖的关键场景

- DNS 重绑定、混合公网/私网、空/非法/family 错配 DNS。
- IPv4、IPv6、`[::1]`、ULA、site-local、link-local、CGNAT、保留空间、IPv4-mapped loopback。
- 公网 HTTP 开关两态拒绝；私网 HTTP 仅显式授权成功。
- Host/SNI 保持；自签名、hostname mismatch 和宿主 TLS 降级均不能绕过证书校验。
- 301/302/307/308 不跟随；代理 trap 收包为 0。
- 成功、超时、响应超限、TLS 与网络异常后的 Agent/连接收口。
- 安全门禁失败保持 `prepared`；POST 后断连、500、非法 JSON、业务 schema 错、本地 proposal 写失败均保持一次提交与 `submission_unknown`。
- 500 响应回显 Bearer/正文不会进入任务；本地文件错误不会落绝对路径。
