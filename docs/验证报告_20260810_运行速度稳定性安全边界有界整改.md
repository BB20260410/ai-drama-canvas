## 实际完成

### 1. 小说分析 Provider 安全边界

- DNS 只解析一次，经过校验的 IPv4/IPv6 地址快照被固定到每请求独立的 Undici Agent，真实连接不会再次走系统 DNS。
- 公网及公网/私网混合目标强制 HTTPS；HTTP 只允许显式授权且所有地址均为本机/私网。
- 保持原 hostname、Host、SNI 和证书校验；显式拒绝 TLS 环境降级、所有重定向与环境代理。
- URL、DNS、协议和凭据校验发生在 execution intent 前；策略失败保持 `prepared` 且不创建 execution。
- 外部 POST 后的连接、HTTP、响应解析和本地落盘错误保持 `submission_unknown`，禁止自动重提。
- pre-dispatch、intent 落盘窗口、post-dispatch、`markExecution` 再失败及 `executeNext` 前后进度读取均使用稳定安全错误投影；命令账本、事件和 Renderer 不再收到原始路径、正文、token 或远端回显。

### 2. 受管画布投影并发

- 深层时间线投影 worker 从 4 调整为 3，为当前单元详情保留一个 IPC 槽。
- 真实隐藏 T23 证据中 `peakOutstandingProjectionIpc` 从 5 降为 3，预算要求为不超过 4。
- 深 raw `4488ms`、全部参考 `5245ms`，仍满足 `5000ms / 8000ms` 预算。

### 3. 同目标选择合并

- 不同目标仍采用 latest-wins；切工程和卸载会使队列及 identity 失效，不跨工程复用。
- P17 隐藏实测中选择并展开由 `10126.97ms` 降至 `8648.52ms`，降低 `14.6%`；最终只发出一次 production projection bundle。
