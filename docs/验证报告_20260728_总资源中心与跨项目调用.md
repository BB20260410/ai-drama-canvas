## 使用入口

1. 打开任一受管项目。
2. 点击页头第二行的“总资源”。
3. 选择人物、场景、道具、风格、音频或视频。
4. 搜索名称、来源项目、文件名或 SHA。
5. 点击“调用到当前项目”。
6. 资产回到“2 资产”后按当前项目规则独立 Review / 提升 Primary；音视频再由用户明确挂接到具体时间线或画布。

在任一受管项目新增并锁定的资产，或导入的音视频，会自动进入总资源目录，无需再执行一次“导入总库”。

## 边界与风险

- 2 个登记项目当前不可读取；界面明确显示，不把 26 / 28 冒充成完整覆盖。
- 8,244 张未关联规范资产的普通图片没有被静默猜成人物、场景或道具；它们必须先有明确名称和分类，才能进入具名资产目录。
- 大部分正式音视频尚无 ready 波形/封面/代理；总资源中心只消费既有派生，不会为了浏览而改写来源项目。
- 本轮未修改正式源素材，未执行外站上传、付费、发布、公证、Git 暂存、提交、推送或 PR。
