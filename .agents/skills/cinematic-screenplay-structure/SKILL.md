# 电影级剧本结构优化

## 适用场景

- 用户要求优化/改写/重构短剧剧本
- 从小说/故事/创意梗概改编为结构化剧本
- 检查现有剧本的结构完整性
- 为 15 秒单元宫格生产提供上游剧本输入

## 与本项目权威链的关系

- 本 Skill 只负责**剧本文案层**的结构优化
- 优化后的剧本仍需走 `material-studio` → `BindingSet` → 15s 单元拆镜
- 不发明未绑定资产，不绕过 `studio-asset-binding` 消歧
- 角色/场景/道具命名必须与既有 `CanonicalAsset` 一致

## 一、Syd Field 三幕式结构（基础骨架）

| 幕 | 占比 | 功能 | 关键节点 |
|----|------|------|----------|
| 第一幕：建置 | 25% | 建立人物、世界、核心矛盾 | 激励事件（Inciting Incident）→ 第一转折点（Plot Point 1） |
| 第二幕：对抗 | 50% | 升级冲突、试炼、中点反转 | 中点（Midpoint）→ 第二转折点（Plot Point 2） |
| 第三幕：解决 | 25% | 高潮对决、情感升华、收束 | 高潮（Climax）→ 尾声（Resolution） |

### 短剧适配（1.5–3 分钟/集）

```
第一幕（前 30 秒）：钩子 + 人物/矛盾快速建置
第二幕（中间 60–120 秒）：冲突升级 + 中点反转
第三幕（后 30 秒）：爽点/悬念爆发 + 下集钩子
```

## 二、序列法（Sequence Approach）

将剧本拆为 **8 个序列**（每序列 10–15 分钟，短剧按比例缩放）：

| 序列 | 对应幕 | 核心任务 | 情绪走向 |
|------|--------|----------|----------|
| Seq 1 | 第一幕前半 | 日常世界 + 激励事件 | 平稳→打破 |
| Seq 2 | 第一幕后半 | 犹豫/拒绝→跨越门槛 | 抗拒→接受 |
| Seq 3 | 第二幕A前半 | 新世界探索 + 初步胜利 | 好奇→小胜 |
| Seq 4 | 第二幕A后半 | 升级挑战 + 中点反转 | 紧张→震撼 |
| Seq 5 | 第二幕B前半 | 后果扩大 + 盟友/敌人 | 压力→抉择 |
| Seq 6 | 第二幕B后半 | 至暗时刻 + 一切丧失 | 绝望→触底 |
| Seq 7 | 第三幕前半 | 觉醒/新方案 + 集结 | 希望→冲刺 |
| Seq 8 | 第三幕后半 | 终极对决 + 新平衡 | 高潮→余韵 |

### 短剧 80 集适配

- 起势期（1–8 集）≈ Seq 1–2
- 攀升期（9–36 集）≈ Seq 3–5
- 风暴期（37–64 集）≈ Seq 6
- 决战期（65–80 集）≈ Seq 7–8

## 四、人物弧光设计

### 弧光三要素

```
外在目标（Want）：角色以为自己要什么
内在需求（Need）：角色真正缺什么
致命缺陷（Flaw）：阻止角色获得 Need 的性格弱点
```

### 弧光变化曲线

| 阶段 | 角色状态 | 驱动力 |
|------|----------|--------|
| 开局 | 被 Flaw 支配，追求 Want | 恐惧/惯性 |
| 中点 | 开始质疑 Want，隐约触碰 Need | 事件冲击 |
| 至暗 | Flaw 导致最大失败 | 自我否定 |
| 高潮 | 放弃 Want，拥抱 Need，克服 Flaw | 顿悟/牺牲 |
| 结局 | 新平衡，内外统一 | 成长完成 |

### 短剧角色速建模板

```yaml
角色名: 
外在目标(Want): 
内在需求(Need): 
致命缺陷(Flaw): 
口头禅/语言习惯: 
标志性动作: 
视觉锚点(服装/道具/发型): 
人物弧光一句话: "从___到___"
```

## 五、对白写作标准

### 电影级对白五原则

1. **潜台词**：角色说的 ≠ 角色想的（禁止直白陈述情感）
2. **动作性**：每句台词必须推动剧情或揭示人物（无功能台词删除）
3. **个性化**：遮住角色名也能分辨是谁在说话
4. **简洁性**：单句不超过 15 字为佳；短剧对白 3 句一个回合
5. **冲突性**：对话即博弈，每轮对话都有攻守转换

### 对白格式（本项目适配）

```
【角色名】（表情/动作指示）
"台词内容。"
（旁白/内心OS标注）
```

### 旁白使用规则

| 类型 | 适用 | 禁忌 |
|------|------|------|
| 第一人称旁白 | 悬疑揭示、时间跳跃 | 代替画面叙事（能用画面就不用旁白） |
| 第三人称全知 | 史诗感、命运感 | 解释角色心理（应通过表演呈现） |
| 无旁白 | 动作戏、对话戏 | — |

## 六、剧本优化检查清单

对任何输入剧本，按以下顺序检查并输出修改建议：

- [ ] **结构完整**：三幕比例是否合理？转折点位置是否正确？
- [ ] **激励事件**：前 10% 是否有打破日常的事件？
- [ ] **中点反转**：50% 处是否有认知颠覆？
- [ ] **至暗时刻**：75% 处主角是否跌入谷底？
- [ ] **人物弧光**：主角 Want/Need/Flaw 是否清晰？是否有变化？
- [ ] **对白质量**：是否有潜台词？是否个性化？是否有无功能台词？
- [ ] **视觉化**：是否所有情感都通过可拍动作表达？（禁止"他感到悲伤"）
- [ ] **节奏曲线**：是否每 5 集/每 30 秒有明确爽点或高潮？
- [ ] **钩子设计**：每集结尾是否有强力悬念/反转/情感锚点？
- [ ] **主题统一**：Opening Image 与 Final Image 是否形成对照？

## 七、输出格式

优化后的剧本必须包含：

```markdown
## 剧本结构卡

- 类型：[霸总/战神/重生/悬疑/甜宠/家庭伦理]
- 总集数：[N]
- 单集时长：[1.5–3 分钟]
- 结构模型：[三幕式 / 序列法 / Save the Cat]
- 主题一句话：[___]
- 主角弧光：从[___]到[___]

## 逐集/逐场大纲

### 第 N 集
- 序列归属：Seq [X]
- 情绪强度：[1-5]
- 本集功能：[建置/升级/反转/高潮/收束]
- 开场钩子：[___]
- 核心冲突：[___]
- 结尾钩子：[类型 + 内容]
- 关键对白：[1-3 句核心台词]
- 视觉锚点：[本集标志性画面]
```

## 八、明确不做

- 不生成正式 imagegen 提示词（那是 `ai-drama-production-prompts` 的职责）
- 不绕过 BindingSet 发明新资产
- 不把社区 Seedance 语法写进软件 Core
- 不覆盖既有 final-validation 或权威交接
- 不替代人工创意判断——本 Skill 提供结构框架，最终创作决策归用户
